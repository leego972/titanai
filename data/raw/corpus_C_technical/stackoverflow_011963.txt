Question: <p>How can I call an external command (as if I'd typed it at the Unix shell or Windows command prompt) from within a Python script?</p>

Answer: <p>If what you need is the output from the command you are calling you can use subprocess.check_output since Python 2.7</p>

<pre><code>&gt;&gt;&gt; subprocess.check_output(["ls", "-l", "/dev/null"])
'crw-rw-rw- 1 root root 1, 3 Oct 18  2007 /dev/null\n'
</code></pre>
