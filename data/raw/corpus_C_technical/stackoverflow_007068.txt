Question: <p>Is it possible for me to see the amount of processor usage (% of maximum) that the current, python, app is using?</p>

<p>Scenario: 
My host will allow me to run my app as long as it does not consume more then X% of the CPU power, so I would like it to 'keep an eye on itself' and slowdown.  So how can I know how much CPU the app is using?</p>

<p>Target platform is *nix, however I would like to do it on a Win host also.</p>

Answer: <p>Use <code>time.clock()</code> to get the CPU time.
To get the percentage of CPU usage do CPU time elapsed/time elapsed</p>

<p>For example, if CPU time elapsed is 0.2 and time elapsed is 1 then the cpu usage is 20%.</p>
