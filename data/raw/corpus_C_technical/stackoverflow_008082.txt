Question: <p>I have a list of arbitrary length, and I need to split it up into equal size chunks and operate on it. There are some obvious ways to do this, like keeping a counter and two lists, and when the second list fills up, add it to the first list and empty the second list for the next round of data, but this is potentially extremely expensive.</p>

<p>I was wondering if anyone had a good solution to this for lists of any length, e.g. using generators.</p>

<p>This should work:</p>

<pre><code>l = range(1, 1000)
print chunks(l, 10) -&gt; [ [ 1..10 ], [ 11..20 ], .., [ 991..999 ] ]
</code></pre>

<p>I was looking for something useful in <code>itertools</code> but I couldn't find anything obviously useful. Might've missed it, though.</p>

<p>Related question: <a href="http://stackoverflow.com/questions/434287/what-is-the-most-pythonic-way-to-iterate-over-a-list-in-chunks">What is the most âpythonicâ way to iterate over a list in chunks?</a></p>

Answer: <p>I like the Python doc's version proposed by tzot and J.F.Sebastian a lot,
 but it has two shortcomings:</p>

<ul>
<li>it is not very explicit</li>
<li>I usually don't want a fill value in the last chunk</li>
</ul>

<p>I'm using this one a lot in my code:</p>

<pre><code>from itertools import islice

def chunks(n, iterable):
    iterable = iter(iterable)
    while True:
        yield tuple(islice(iterable, n)) or iterable.next()
</code></pre>

<p>UPDATE: A lazy chunks version:</p>

<pre><code>from itertools import chain, islice

def chunks(n, iterable):
   iterable = iter(iterable)
   while True:
       yield chain([next(iterable)], islice(iterable, n-1))
</code></pre>
