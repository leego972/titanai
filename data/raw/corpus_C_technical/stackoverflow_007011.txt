Question: <p>What is the Python equivalent of Perl's <code>chomp</code> function, which removes the last character of a value?</p>

Answer: <p>This would replicate exactly perl's chomp (minus behavior on arrays) for "\n" line terminator:</p>

<pre><code>def chomp(x):
    if x.endswith("\r\n"): return x[:-2]
    if x.endswith("\n"): return x[:-1]
    return x[:]
</code></pre>

<p>(Note: it does not modify string 'in place'; it does not strip extra trailing whitespace; takes \r\n in account)</p>
