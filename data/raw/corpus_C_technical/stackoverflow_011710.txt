Question: <p>Why is it bad to name a variable <code>id</code> in Python?</p>

Answer: <p>In <strong>PEP 8 - Style Guide for Python Code</strong>, the following guidance appears in the section <a href="https://www.python.org/dev/peps/pep-0008/#descriptive-naming-styles">Descriptive: Naming Styles </a>:</p>

<blockquote>
  <ul>
  <li><p><code>single_trailing_underscore_</code> : used by convention to avoid conflicts
  with Python keyword, e.g.</p>
  
  <p><code>Tkinter.Toplevel(master, class_='ClassName')</code></p></li>
  </ul>
</blockquote>

<p>So, to answer the question, an example that applies this guideline is:</p>

<pre><code>id_ = 42
</code></pre>

<p>Including the trailing underscore in the variable name makes the intent clear (to those familiar with the guidance in PEP 8).</p>
