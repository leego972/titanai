Question: <p>Is there a way to define a column (primary key) as a <a href="https://en.wikipedia.org/wiki/Universally_unique_identifier">UUID</a> in <a href="http://www.sqlalchemy.org/">SQLAlchemy</a> if using <a href="http://www.postgresql.org/">PostgreSQL</a> (Postgres)?</p>

Answer: <p>I've used the <code>UUIDType</code> from the <code>SQLAlchemy-Utils</code> package: <a href="http://sqlalchemy-utils.readthedocs.org/en/latest/data_types.html#module-sqlalchemy_utils.types.uuid" rel="nofollow">http://sqlalchemy-utils.readthedocs.org/en/latest/data_types.html#module-sqlalchemy_utils.types.uuid</a></p>
