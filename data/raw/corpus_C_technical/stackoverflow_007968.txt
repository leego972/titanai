Question: <p>I am using CYGWIN as a platform and would like to use wxPython. Is there a way to get the source compiled and working in cygwin?</p>

Answer: <p>I tried another solution for using wxPython in cygwin:</p>

<ol>
<li>I installed python27 and wxPython in Windows7</li>
<li>Did "echo 'export PATH=/cygdrive/c/Python27/:$PATH'>>~/.bashrc"</li>
<li>Restart cygwin</li>
</ol>

<p>It works. Cheer!</p>

<p>I don't know if any other Path should be added, but my program was executed on Fedora and it works on there.
