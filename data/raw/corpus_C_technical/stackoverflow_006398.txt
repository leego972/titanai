Question: <p>What's the difference between the list methods <code>append()</code> and <code>extend()</code>?</p>

Answer: <p>This is the equivalent of <code>append</code> and <code>extend</code> using the <code>+</code> operator:</p>

<pre><code>&gt;&gt;&gt; x = [1,2,3]
&gt;&gt;&gt; x
[1, 2, 3]
&gt;&gt;&gt; x = x + [4,5,6] # Extend
&gt;&gt;&gt; x
[1, 2, 3, 4, 5, 6]
&gt;&gt;&gt; x = x + [[7,8]] # Append
&gt;&gt;&gt; x
[1, 2, 3, 4, 5, 6, [7, 8]]
</code></pre>
