Question: <p>What is the difference between old style and new style classes in Python?  Is there ever a reason to use old-style classes these days?</p>

Answer: <p>New-style classes inherit from <code>object</code> and must be written as such in Python 2.2 onwards (i.e. <code>class Classname(object):</code> instead of <code>class Classname:</code>). The core change is to unify types and classes, and the nice side-effect of this is that it allows you to inherit from built-in types.</p>

<p>Read <a href="http://www.python.org/download/releases/2.2.3/descrintro/" rel="nofollow">descrintro</a> for more details.</p>
