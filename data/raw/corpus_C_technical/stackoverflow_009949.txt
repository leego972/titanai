Question: <p>I have a legacy C library that creates a tree of objects. I would like to convert the tree into a pre-existing Python class. How do I create the PyObject for that class?</p>

Answer: <p><a href="http://www.cython.org/" rel="nofollow">Cython</a> is capable of doing this.  It's a semi-fork of Pyrex, and it can wrap existing data structures and expose them to Python.  In fact, this is one of the <a href="http://docs.cython.org/docs/external_C_code.html" rel="nofollow">sections in the user guide</a>.  Cython is relatively easy to use, and it includes an HTML-output format that shows all the generated code as well as highlighted hot spots where optimization could be applied.</p>
