Question: <p>How do I have a Python script that can accept user input (assuming this is possible) and how do I make it read in arguments if run from the command line?</p>

Answer: <p><code>raw_input</code> is no longer available in Python 3.x.  But <code>raw_input</code> was renamed <code>input</code>, so the same functionality exists.</p>

<pre><code>input_var = input("Enter something: ")
print ("you entered " + input_var) 
</code></pre>

<p><a href="http://docs.python.org/py3k/whatsnew/3.0.html#builtins">Documentation of the change</a></p>
