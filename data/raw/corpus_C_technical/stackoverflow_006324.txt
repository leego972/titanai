Answer: <p>The main overhead here is the multiple individual puts to the datastore. If you can, store the links as a single entity, as Andre suggests. You can always split the links into an array and store it in a ListProperty.</p>

<p>If you do need an entity for each link, try this:</p>

<pre><code># For each line in the input, add to the database
groups = []
for x in allLinks:
     newGroup = LinkGrouping()
     newGroup.reference = hash
     newGroup.link = x
     groups.append(newGroup)
db.put(groups)
</code></pre>

<p>It will reduce the datastore roundtrips to one, and it's the roundtrips that are really killing your high CPU cap.</p>
