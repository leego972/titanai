Question: <p>How do I check whether a file exists, without using the <a href="https://docs.python.org/3.6/reference/compound_stmts.html#try"><code>try</code></a> statement?</p>

Answer: <p>Here's a 1 line Python command for the Linux command line environment. I find this VERY HANDY since I'm not such a hot Bash guy.</p>

<pre><code>python -c "import os.path; print os.path.isfile('/path_to/file.xxx')"
</code></pre>

<p>I hope this is helpful.</p>
