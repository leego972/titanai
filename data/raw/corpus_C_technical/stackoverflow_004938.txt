Question: <p>I wonder what is the time complexity of pop method of list objects in Python (in CPython particulary). Also does the value of N for list.pop(N) affects the complexity?  </p>

Answer: <p>Pop() for the last element ought to be O(1) since you only need to return the element referred to by the last element in the array and update the index of the last element.  I would expect pop(N) to be O(N) and require on average N/2 operations since you would need to move any elements beyond the Nth one, one position up in the array of pointers.</p>
