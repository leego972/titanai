Answer: <p>being a newbie here i can't yet directly comment but here is a small correction i'd like to add to the following part of <a href="http://stackoverflow.com/questions/141291/how-to-list-only-top-level-directories-in-python/142368#142368">Î¤ÎÎ©Î¤ÎÎÎÎ¥'s answer</a> :</p>

<blockquote>
  <p>If you prefer full pathnames, then use this function:</p>

<pre><code>def listdirs(folder):  
  return [
    d for d in (os.path.join(folder, d1) for d1 in os.listdir(folder))
    if os.path.isdir(d)
]
</code></pre>
</blockquote>

<p><strong>for those still on python &lt; 2.4</strong>: the inner construct needs to be a list instead of a tuple and therefore should read like this:</p>

<pre><code>def listdirs(folder):  
  return [
    d for d in [os.path.join(folder, d1) for d1 in os.listdir(folder)]
    if os.path.isdir(d)
  ]
</code></pre>

<p>otherwise one gets a syntax error.</p>
