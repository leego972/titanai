Question: <p>I occasionally see the list slice syntax used in Python code like this:</p>

<pre><code>newList = oldList[:]
</code></pre>

<p>Surely this is just the same as:</p>

<pre><code>newList = oldList
</code></pre>

<p>Or am I missing something?</p>

Answer: <p>As it has already been answered, I'll simply add a simple demonstration:</p>

<pre><code>&gt;&gt;&gt; a = [1, 2, 3, 4]
&gt;&gt;&gt; b = a
&gt;&gt;&gt; c = a[:]
&gt;&gt;&gt; b[2] = 10
&gt;&gt;&gt; c[3] = 20
&gt;&gt;&gt; a
[1, 2, 10, 4]
&gt;&gt;&gt; b
[1, 2, 10, 4]
&gt;&gt;&gt; c
[1, 2, 3, 20]
</code></pre>
