Question: <p>I'm just trying to time a piece of code. The pseudocode looks like:</p>

<pre><code>start = get_ticks()
do_long_code()
print "It took " + (get_ticks() - start) + " seconds."
</code></pre>

<p>How does this look in Python?</p>

<p>More specifically, how do I get the number of ticks since midnight (or however Python organizes that timing)?</p>

Answer: <pre><code>import datetime

start = datetime.datetime.now()
do_long_code()
finish = datetime.datetime.now()
delta = finish - start
print delta.seconds
</code></pre>

<p>From midnight:</p>

<pre><code>import datetime

midnight = datetime.datetime.now().replace(hour=0, minute=0, second=0, microsecond=0)
now = datetime.datetime.now()
delta = now - midnight
print delta.seconds
</code></pre>
