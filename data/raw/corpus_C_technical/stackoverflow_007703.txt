Question: <p>I have an XML file and an XML schema in another file and I'd like to validate that my XML file adheres to the schema.  How do I do this in Python?</p>

<p>I'd prefer something using the standard library, but I can install a third-party package if necessary.</p>

Answer: <p>I am assuming you mean using XSD files. Surprisingly there aren't many python XML libraries that support this. lxml does however. Check <a href="http://lxml.de/validation.html">Validation with lxml</a>. The page also lists how to use lxml to validate with other schema types.</p>
