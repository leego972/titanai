Answer: <p>Please read <a href="http://www.python.org/dev/peps/pep-0008/" rel="nofollow">PEP8</a>.  You're swaying pretty far from python conventions.</p>

<p>If you want a list of lists of each line split by comma, I'd do this:</p>

<pre><code>l = []
for line in in_file:
    l.append(line.split(','))
</code></pre>

<p>You'll get a newline on each record.  If you don't want that:</p>

<pre><code>l = []
for line in in_file:
    l.append(line.rstrip().split(','))
</code></pre>
