Question: <p>With a class in Python, how do I define a function to print every single instance of the class in a format defined in the function?</p>

Answer: <p>Same as almost all other OO languages, keep all instances of the class in a collection of some kind.</p>

<p>You can try this kind of thing.</p>

<pre><code>class MyClassFactory( object ):
    theWholeList= []
    def __call__( self, *args, **kw ):
         x= MyClass( *args, **kw )
         self.theWholeList.append( x )
         return x
</code></pre>

<p>Now you can do this.</p>

<pre><code>object= MyClassFactory( args, ... )
print MyClassFactory.theWholeList
</code></pre>
