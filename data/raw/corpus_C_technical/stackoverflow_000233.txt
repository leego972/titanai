Question: <p>I wrote a piece of code to convert PHP's striplashes into valid Python [backslash] escapes:</p>

<pre><code>cleaned = stringwithslashes
cleaned = cleaned.replace('\\n', '\n')
cleaned = cleaned.replace('\\r', '\n')
cleaned = cleaned.replace('\\', '')
</code></pre>

<p>How can I condense it? </p>

Answer: <p>use <code>decode('string_escape')</code></p>

<pre><code>cleaned = stringwithslashes.decode('string_escape')
</code></pre>

<p>Using </p>

<blockquote>
  <p><strong>string_escape</strong> : Produce a string that is suitable as string literal in Python source code</p>
</blockquote>

<p>or concatenate the replace() like WilsonÂ´s answer.</p>

</code></pre>
