Question: <p>Is there an obvious way to do this that I'm missing?  I'm just trying to make thumbnails.</p>

Answer: <p>Based in @tomvon, I finished using the following:</p>

<p>Resizing width:</p>

<pre><code>new_width  = 680
new_height = new_width * height / width 
</code></pre>

<p>Resizing height:</p>

<pre><code>new_height = 680
new_width  = new_height * width / height
</code></pre>

<p>Then just:</p>

<pre><code>img = img.resize((new_width, new_height), Image.ANTIALIAS)
</code></pre>
