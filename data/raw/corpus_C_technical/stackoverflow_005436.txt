Question: <p>Can you add new statements (like <code>print</code>, <code>raise</code>, <code>with</code>) to Python's syntax?</p>

<p>Say, to allow..</p>

<pre><code>mystatement "Something"
</code></pre>

<p>Or,</p>

<pre><code>new_if True:
    print "example"
</code></pre>

<p>Not so much if you <em>should</em>, but rather if it's possible (short of modifying the python interpreters code)</p>

Answer: <p>There is a language based on python called <a href="http://www.livelogix.net/logix/" rel="nofollow">Logix</a> with which you CAN do such things.  It hasn't been under development for a while, but the features that you asked for <b>do work</b> with the latest version. </p>
