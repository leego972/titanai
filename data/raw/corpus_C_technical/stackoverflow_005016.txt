Question: <p>Is there a way to describe the module's data in a similar way that a docstring describes a module or a funcion?</p>

<pre><code>class MyClass(object):
    def my_function():
        """This docstring works!"""
        return True
    my_list = []
    """This docstring does not work!"""
</code></pre>

Answer: <p>As codeape explains, it's not possible to document general data members.</p>

<p>However, it <em>is</em> possible to document <code>property</code> data members:</p>

<pre><code>class Foo:
  def get_foo(self): ...

  def set_foo(self, val): ...

  def del_foo(self): ...

  foo = property(get_foo, set_foo, del_foo, '''Doc string here''')
</code></pre>

<p>This will give a docstring to the <code>foo</code> attribute, obviously.</p>
