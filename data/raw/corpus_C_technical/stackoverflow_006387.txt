Question: <p>What's the difference between the list methods <code>append()</code> and <code>extend()</code>?</p>

Answer: <p><code>append</code> appends a single element. <code>extend</code> appends a list of elements.</p>

<p>Note that if you pass a list to append, it still adds one element:</p>

<pre><code>&gt;&gt;&gt; a = [1, 2, 3]
&gt;&gt;&gt; a.append([4, 5, 6])
&gt;&gt;&gt; a
[1, 2, 3, [4, 5, 6]]
</code></pre>
