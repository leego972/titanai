Question: <p>What is the difference between the following class methods?</p>

<p>Is it that one is static and the other is not?</p>

<pre><code>class Test(object):
  def method_one(self):
    print "Called method_one"

  def method_two():
    print "Called method_two"

a_test = Test()
a_test.method_one()
a_test.method_two()
</code></pre>

Answer: <p>The call to method_two will throw an exception for not accepting the self parameter the Python runtime will automatically pass it.</p>

<p>If you want to create a static method in a Python class, decorate it with the <code>staticmethod decorator</code>.</p>

<pre><code>Class Test(Object):
  @staticmethod
  def method_two():
    print "Called method_two"

Test.method_two()
</code></pre>
