Question: <p>I'd like to call a function in python using a dictionary.</p>

<p>Here is some code:</p>

<pre><code>d = dict(param='test')

def f(param):
    print param

f(d)
</code></pre>

<p>This prints <code>{'param': 'test'}</code> but I'd like it to just print <code>test</code>.</p>

<p>I'd like it to work similarly for more parameters:</p>

<pre><code>d = dict(p1=1, p2=2)
def f2(p1,p2):
    print p1, p2
f2(d)
</code></pre>

<p>Is this possible?</p>

Answer: <p>Figured it out for myself in the end. It is simple, I was just missing the ** operator to unpack the dictionary</p>

<p>So my example becomes:</p>

<pre><code>d = dict(p1=1, p2=2)
def f2(p1,p2):
    print p1, p2
f2(**d)
</code></pre>
