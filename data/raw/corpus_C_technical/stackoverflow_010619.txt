Question: <p>I'm mainly a C# developer, but I'm currently working on a project in Python.</p>

<p>How can I represent the equivalent of an Enum in Python?  </p>

Answer: <p>This solution is a simple way of getting a class for the enumeration defined as a list (no more annoying integer assignments):</p>

<p>enumeration.py:</p>

<pre><code>import new

def create(class_name, names):
    return new.classobj(
        class_name, (object,), dict((y, x) for x, y in enumerate(names))
    )
</code></pre>

<p>example.py:</p>

<pre><code>import enumeration

Colors = enumeration.create('Colors', (
    'red',
    'orange',
    'yellow',
    'green',
    'blue',
    'violet',
))
</code></pre>
