Question: <p>I have a python module installed on my system and I'd like to be able to see what functions/classes/methods are available in it.   </p>

<p>I want to call the doc function on each one. In ruby I can do something like ClassName.methods to get a list of all the methods available on that class. Is there something similar in python?</p>

<p>eg. something like:</p>

<pre><code>from somemodule import foo
print foo.methods # or whatever is the correct method to call
</code></pre>

Answer: <p>You can use <code>dir(module)</code> to see all available methods/attributes.  Also check out PyDocs.</p>
