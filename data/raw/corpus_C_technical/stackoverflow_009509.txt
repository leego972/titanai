Question: <p>There's an existing function that ends in:</p>

<pre><code>return dict.iteritems()
</code></pre>

<p>that returns an unsorted iterator for a given dictionary. I would like to return an iterator that goes through the items in sorted order. How do I do that?</p>

Answer: <p>You can now use <code>OrderedDict</code> in Python 2.7 as well:</p>

<pre><code>&gt;&gt;&gt; from collections import OrderedDict
&gt;&gt;&gt; d = OrderedDict([('first', 1),
...                  ('second', 2),
...                  ('third', 3)])
&gt;&gt;&gt; d.items()
[('first', 1), ('second', 2), ('third', 3)]
</code></pre>

<p>Here you have the <a href="http://docs.python.org/dev/whatsnew/2.7.html">what's new</a> page for 2.7 version and the <a href="http://docs.python.org/dev/library/collections.html#collections.OrderedDict">OrderedDict API</a>.</p>
