Question: <p>What would be the easiest way to move the mouse around (and possibly click) using python on OS X?  </p>

<p>This is just for rapid prototyping, it doesn't have to be elegant.</p>

<p>Thanks!</p>

Answer: <p>Just try this code:</p>

<pre><code>#!/usr/bin/python

import objc

class ETMouse():    
    def setMousePosition(self, x, y):
        bndl = objc.loadBundle('CoreGraphics', globals(), 
                '/System/Library/Frameworks/ApplicationServices.framework')
        objc.loadBundleFunctions(bndl, globals(), 
                [('CGWarpMouseCursorPosition', 'v{CGPoint=ff}')])
        CGWarpMouseCursorPosition((x, y))

if __name__ == "__main__":
    et = ETMouse()
    et.setMousePosition(200, 200)
</code></pre>

<p>it works in OSX leopard 10.5.6</p>
