Answer: <p>To prevent your code from crashes, you maybe want to use a <code>try-except</code> to catch <code>TypeErrors</code></p>

<pre><code>&gt;&gt;&gt; ord("Â¶")
Traceback (most recent call last):
  File "&lt;stdin&gt;", line 1, in &lt;module&gt;
TypeError: ord() expected a character, but string of length 2 found

<p>For example </p>

<pre><code>def is_ascii(s):
    try:
        return all(ord(c) &lt; 128 for c in s)
    except TypeError:
        return False
</code></pre>
