Question: <p>I'm pretty sure one would do this using the os.plock(op) function, but I have no idea how. Also, if there's a better way, I'd be grateful to find out. Code snippets are very welcome. </p>

Answer: <p>This is pretty much Python-independent!  It's a classic example of Unix interprocess communication.  One good option is to use <code>popen()</code> to open a pipe between the parent and child processes, and pass data/messages back and forth along the pipe.</p>

<p>Take a look at the <a href="http://www.python.org/doc/2.5.2/lib/module-subprocess.html" rel="nofollow"><code>subprocess</code> module</a>, which can set up the necessary pipes automatically while spawning child processes.</p>
