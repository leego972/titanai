Question: <p>How can I poll the keyboard from a console python app?  Specifically, I would like to do something akin to this in the midst of a lot of other I/O activities (socket selects, serial port access, etc.):</p>

<pre><code>   while 1:
      # doing amazing pythonic embedded stuff
      # ...

      # periodically do a non-blocking check to see if
      # we are being told to do something else
      x = keyboard.read(1000, timeout = 0)

      if len(x):
          # ok, some key got pressed
          # do something
</code></pre>

<p>What is the correct pythonic way to do this on Windows?  Also, portability to Linux wouldn't be bad, though it's not required.</p>

Answer: <p>Ok, since my attempt to post my solution in a comment failed, here's what I was trying to say.  I could do exactly what I wanted from native Python (on Windows, not anywhere else though) with the following code:</p>

<pre><code>import msvcrt 

def kbfunc(): 
   x = msvcrt.kbhit()
   if x: 
      ret = ord(msvcrt.getch()) 
   else: 
      ret = 0 
   return ret
</code></pre>
