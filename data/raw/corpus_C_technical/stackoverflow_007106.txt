Question: <p>How can I bind arguments to a Python method to store a nullary functor for later invocation?  Similar to C++'s <code>boost::bind</code>.</p>

Answer: <p>Functors can be defined this way in Python.  They're callable objects.  The "binding" merely sets argument values.</p>

<pre><code>class SomeFunctor( object ):
    def __init__( self, arg1, arg2=None ):
        self.arg1= arg1
        self.arg2= arg2
    def __call___( self, arg1=None, arg2=None ):
        a1= arg1 or self.arg1
        a2= arg2 or self.arg2
        # do something
        return
</code></pre>

<p>You can do things like</p>

<pre><code>x= SomeFunctor( 3.456 )
x( arg2=123 )

y= SomeFunctor( 3.456, 123 )
y()
</code></pre>
