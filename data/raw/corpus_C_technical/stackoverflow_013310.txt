Question: <p>I know how to do a HEAD request with httplib, but I have to use mechanize for this site. </p>

<p>Essentially, what I need to do is grab a value from the header (filename) without actually downloading the file.</p>

<p>Any suggestions how I could accomplish this?</p>

Answer: <p>In mechanize there is no need to do HeadRequest class etc.</p>

<p>Simply</p>

<pre><code>
import mechanize

br = mechanize.Browser()

r = br.open("http://www.example.com/")

print r.info()

</code></pre>

<p>That's all.</p>
