Question: <p>I've a python script that has to launch a shell command for every file in a dir:</p>

<pre><code>import os

files = os.listdir(".")
for f in files:
    os.execlp("myscript", "myscript", f)
</code></pre>

<p>This works fine for the first file, but after the "myscript" command has ended, the execution stops and does not come back to the python script.</p>

<p>How can I do? Do I have to <code>fork()</code> before <code>calling os.execlp()</code>?</p>

Answer: <blockquote>
  <p>subprocess: The <code>subprocess</code> module
  allows you to spawn new processes,
  connect to their input/output/error
  pipes, and obtain their return codes.</p>
</blockquote>

<p><a href="http://docs.python.org/library/subprocess.html">http://docs.python.org/library/subprocess.html</a></p>

<p>Usage:</p>

<pre><code>import subprocess
process = subprocess.Popen(command, shell=True, stdout=subprocess.PIPE)
process.wait()
print process.returncode
</code></pre>
