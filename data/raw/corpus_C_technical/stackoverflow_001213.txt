Question: <p>What is the difference between old style and new style classes in Python?  Is there ever a reason to use old-style classes these days?</p>

Answer: <p><strong>Declaration-wise:</strong></p>

<p>New-style classes inherit from object, or from another new-style class.</p>

<pre><code>class NewStyleClass(object):
    pass

class AnotherNewStyleClass(NewStyleClass):
    pass
</code></pre>

<p>Old-style classes don't.</p>

<pre><code>class OldStyleClass():
    pass
</code></pre>
