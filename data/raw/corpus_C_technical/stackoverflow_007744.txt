Question: <p>I've got this date time string:</p>

<pre><code>post["date"] = "2007-07-18 10:03:19"
</code></pre>

<p>I'd like to extract just "2007-07-18" as a date. I've seen some reference to <code>strptime</code> but I'm not sure how to use it.  How can I extract the date from this string?</p>

Answer: <p>You can use <a href="https://pypi.python.org/pypi/python-dateutil" rel="nofollow">https://pypi.python.org/pypi/python-dateutil</a> which can support any datetime format e.g:</p>

<pre><code>&gt;&gt;&gt; from dateutil.parser import parse
&gt;&gt;&gt; d1="2007-07-18 10:03:19"
&gt;&gt;&gt; date_obj = parse(d1)
&gt;&gt;&gt; date_obj
datetime.datetime(2007, 7, 18, 10, 3, 19)
&gt;&gt;&gt; date_obj.strftime("%Y-%m-%d")
'2007-07-18'
&gt;&gt;&gt; d2 = "18-07-2007 10:03:19"
&gt;&gt;&gt; d = parse(d2)
&gt;&gt;&gt; d
datetime.datetime(2007, 7, 18, 10, 3, 19)
&gt;&gt;&gt; d.strftime("%Y-%m-%d")
'2007-07-18'
</code></pre>
