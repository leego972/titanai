Question: <p>I would like to drag and drop my data file onto a Python script and have it process the file and generate output. The Python script accepts the name of the data file as a command-line parameter, but Windows Explorer doesn't allow the script to be a drop target.</p>

<p>Is there some kind of configuration that needs to be done somewhere for this work?</p>

Answer: <p>write a simple shell script (file.bat)</p>

<pre><code>"c:\Python27\python.exe" yourprogram.py %1
</code></pre>

<p>where %1 stands for the firs argument you pass to the script.</p>

<p>Now drag%drop your target files on the file.bat icon.</p>
