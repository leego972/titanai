Question: <p>In Python, how can I parse a numeric string like <code>"545.2222"</code> to its corresponding float value, <code>542.2222</code>? Or parse the string <code>"31"</code> to an integer, <code>31</code>?</p>

<p>I just want to know how to parse a float string to a float, and (separately) an int string to an int.</p>

Answer: <p>The question seems a little bit old. But let me suggest a function, parseStr, which makes something similar, that is, returns integer or float and if a given ASCII string cannot be converted to none of them it returns it untouched. The code of course might be adjusted to do only what you want:</p>

<pre><code>   &gt;&gt;&gt; import string
   &gt;&gt;&gt; parseStr = lambda x: x.isalpha() and x or x.isdigit() and \
   ...                      int(x) or x.isalnum() and x or \
   ...                      len(set(string.punctuation).intersection(x)) == 1 and \
   ...                      x.count('.') == 1 and float(x) or x
   &gt;&gt;&gt; parseStr('123')
   123
   &gt;&gt;&gt; parseStr('123.3')
   123.3
   &gt;&gt;&gt; parseStr('3HC1')
   '3HC1'
   &gt;&gt;&gt; parseStr('12.e5')
   1200000.0
   &gt;&gt;&gt; parseStr('12$5')
   '12$5'
   &gt;&gt;&gt; parseStr('12.2.2')
   '12.2.2'
</code></pre>
