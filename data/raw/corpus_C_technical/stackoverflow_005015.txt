Question: <p>Is there a way to describe the module's data in a similar way that a docstring describes a module or a funcion?</p>

<pre><code>class MyClass(object):
    def my_function():
        """This docstring works!"""
        return True
    my_list = []
    """This docstring does not work!"""
</code></pre>

Answer: <p>It <strong>is</strong> possible to make documentation of module's data, with use of <a href="http://epydoc.sourceforge.net/">epydoc</a> syntax. Epydoc is one of the most frequently used documentation tools for Python.</p>

<p>The syntax for documenting is <code>#:</code> above the variable initialization line, like this:</p>

<pre><code># module.py:

#: Very important data.
#: Use with caution.
#: @type: C{str}
data = "important data"
</code></pre>

<p>Now when you generate your documentation, <code>data</code> will be described as module variable with given description and type <code>str</code>. You can omit the <code>@type</code> line.</p>
