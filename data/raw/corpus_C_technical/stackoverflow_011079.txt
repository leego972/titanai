Question: <p>Given a path such as <code>"mydir/myfile.txt"</code>, how do I find the absolute filepath relative to the current working directory in Python? E.g. on Windows, I might end up with:</p>

<pre><code>"C:/example/cwd/mydir/myfile.txt"
</code></pre>

Answer: <p>You could use the new Python 3.4 library <code>pathlib</code>. (You can also get it for Python 2.6 or 2.7 using <code>pip install pathlib</code>.) The authors <a href="http://www.python.org/dev/peps/pep-0428/#abstract" rel="nofollow">wrote</a>: "The aim of this library is to provide a simple hierarchy of classes to handle filesystem paths and the common operations users do over them."</p>

<p>To get an absolute path in Windows:</p>

<pre><code>&gt;&gt;&gt; from pathlib import Path
&gt;&gt;&gt; p = Path("pythonw.exe").resolve()
&gt;&gt;&gt; p
WindowsPath('C:/Python27/pythonw.exe')
&gt;&gt;&gt; str(p)
'C:\\Python27\\pythonw.exe'
</code></pre>

<p>Or on UNIX:</p>

<pre><code>&gt;&gt;&gt; from pathlib import Path
&gt;&gt;&gt; p = Path("python3.4").resolve()
&gt;&gt;&gt; p
PosixPath('/opt/python3/bin/python3.4')
&gt;&gt;&gt; str(p)
'/opt/python3/bin/python3.4'
</code></pre>

<p>Docs are here: <a href="https://docs.python.org/3/library/pathlib.html" rel="nofollow">https://docs.python.org/3/library/pathlib.html</a></p>
