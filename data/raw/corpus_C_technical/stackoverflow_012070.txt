Question: <p>I am attempting to use the 'tempfile' module for manipulating and creating text files. Once the file is ready I want to save it to disk. I thought it would be as simple as using 'shutil.copy'. However, I get a 'permission denied' IOError:</p>

<pre><code>&gt;&gt;&gt; import tempfile, shutil
&gt;&gt;&gt; f = tempfile.TemporaryFile(mode ='w+t')
&gt;&gt;&gt; f.write('foo')
&gt;&gt;&gt; shutil.copy(f.name, 'bar.txt')

    shutil.copy(f.name, 'bar.txt')

</code></pre>

<p>Is this not intended when using the 'tempfile' library? Is there a better way to do this? (Maybe I am overlooking something very trivial)</p>

Answer: <p>Starting from python 2.6 you can also use <code>NamedTemporaryFile</code> with the <code>delete=</code> option set to False. This way the temporary file will be accessible, even after you close it.</p>

<p>Note that on Windows (NT and later) you cannot access the file a second time while it is still open. You have to close it before you can copy it. This is not true on Unix systems.</p>
