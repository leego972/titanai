Question: <p>What would be the simplest way to daemonize a python script in Linux ? I need that this works with every flavor of Linux, so it should only use python based tools. </p>

Answer: <p>Use <a href="http://www.clapper.org/software/python/grizzled/" rel="nofollow">grizzled.os.daemonize</a>:</p>

<pre><code>$ easy_install grizzled

&gt;&gt;&gt; from grizzled.os import daemonize
&gt;&gt;&gt; daemon.daemonize()
</code></pre>

<p>To understand how this works or to do it yourself, read <a href="http://code.activestate.com/recipes/278731/" rel="nofollow">the discussion on ActiveState</a>.</p>
