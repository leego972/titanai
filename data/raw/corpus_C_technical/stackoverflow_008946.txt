Question: <p>We use a number of diffrent web services in our company, wiki(moinmoin), bugtracker (internally), requestracker (customer connection), subversion. Is there a way to parse the wikipages so that if I write "... in Bug1234 you could ..." Bug1234 woud be renderd as a link to <code>http://mybugtracker/bug1234</code></p>

Answer: <p>check out the interwiki page in moinmoin, (most wikis have them) we use trac for example and you can set up different link paths to point to your different web resources.  So in our Trac you can go [[SSGWiki:Some Topic]] and it will point to another internal wiki.</p>
