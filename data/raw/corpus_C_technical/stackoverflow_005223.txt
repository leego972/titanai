mysql_options(&amp;mysql, MYSQL_OPT_RECONNECT, &amp;reconnect);
</code></pre>

<p>but no luck with MySQLdb (python-mysql).</p>

Answer: <p>You other bet it to work around dropped connections yourself with code.</p>

<p>One way to do it would be the following:</p>

<pre><code>import MySQLdb

class DB:
    conn = None

    def connect(self):
        self.conn = MySQLdb.connect()

    def cursor(self):
        try:
            return self.conn.cursor()
        except (AttributeError, MySQLdb.OperationalError):
            self.connect()
            return self.conn.cursor()

db = DB()
cur = db.cursor()
# wait a long time for the Mysql connection to timeout
cur = db.cursor()
# still works
</code></pre>
