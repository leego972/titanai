Answer: <p>You can use the function <a href="http://docs.python.org/2/library/socket.html#socket.socket.connect_ex" rel="nofollow">connect_ex</a>. It doesn't throw an exception. Instead of that, returns a C style integer value (referred to as <a href="http://linux.die.net/man/3/errno" rel="nofollow">errno</a> in C):</p>

<pre><code>s =  socket.socket(socket.AF_INET, socket.SOCK_STREAM)
result = s.connect_ex((host, port))
s.close()
if result:
    print "problem with socket!"
else:
    print "everything it's ok!"
</code></pre>
