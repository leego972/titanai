Question: <p>I want to create some text in a canvas:</p>

<pre><code>myText = self.canvas.create_text(5, 5, anchor=NW, text="TEST")
</code></pre>

<p>Now how do I find the width and height of myText?</p>

Answer: <p>This method seemed to work well if  all you are interested in is the width and height of the canvas being considered, using the bounds of the box and then checking the differential works just as well if you want to do it that way.</p>

<pre><code>width = myText.winfo_width()  
height = myText.winfo_height()
</code></pre>
