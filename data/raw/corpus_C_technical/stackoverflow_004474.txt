<pre><code>$shows = Array(0 =&gt; Array('id' =&gt; 1, 'name' =&gt; 'Sesaeme Street'), 
               1 =&gt; Array('id' =&gt; 2, 'name' =&gt; 'Dora The Explorer'));
</code></pre>

Answer: <p>Not exactly the same syntax, but there are a number of dictionary extensions out there which respect the order in which the key/value pairs have been added.  E.g. <a href="http://home.arcor.de/wolfgang.grafen/Python/Modules/seqdict/Seqdict.html" rel="nofollow">seqdict</a>.</p>
