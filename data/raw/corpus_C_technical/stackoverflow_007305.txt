Question: <p>Let's say I wanted to make a python script interface with a site like Twitter.</p>

<p>What would I use to do that? I'm used to using curl/wget from bash, but Python seems to be much nicer to use. What's the equivalent?</p>

<p>(This isn't Python run from a webserver, but run locally via the command line)</p>

Answer: <p>I wholeheartedly recommend <a href="http://wwwsearch.sourceforge.net/mechanize/" rel="nofollow">mechanize</a> for python. It's exactly a programmable web browser that you can use from python, which handles forms and cookies as well! It makes any kind of site crawling a breeze.</p>

<p>Take a look at the examples on that link to see what it can do.</p>
