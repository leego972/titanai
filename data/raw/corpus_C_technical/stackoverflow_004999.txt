Question: <p>I am building a project involving natural language processing, since the nlp module currently only deal with english text, so I have to make sure the user submitted content (not long, only several words) is in english. Are there established ways to achieve this? Python or Javascript way preferred.</p>

Answer: <p>Try n-gram based statistical language recognition. This is a <a href="http://odur.let.rug.nl/~vannoord/TextCat/Demo/" rel="nofollow">link</a> to a demo of an algorithm using this technique, there is also a link to a paper describing the algorithm there. Try the demo, it performs quite well even on very short texts (3-4 words).</p>
