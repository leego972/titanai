Question: <p>How does one write a unittest that fails only if a function doesn't throw an expected exception?</p>

Answer: <p>The code in my previous answer can be simplified to:</p>

<pre><code>def test_afunction_throws_exception(self):
    self.assertRaises(ExpectedException, afunction)
</code></pre>

<p>And if afunction takes arguments, just pass them into assertRaises like this:</p>

<pre><code>def test_afunction_throws_exception(self):
    self.assertRaises(ExpectedException, afunction, arg1, arg2)
</code></pre>
