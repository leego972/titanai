Question: <p>I have a script that needs to do some stuff based on file creation &amp; modification dates but has to run on Linux &amp; Windows.</p>

<p>What's the best <strong>cross-platform</strong> way to get file creation &amp; modification date/times in Python?</p>

Answer: <p>If following symbolic links is not important, you can also use the <code>os.lstat</code> builtin.</p>

<pre><code>&gt;&gt;&gt; os.lstat("2048.py")
posix.stat_result(st_mode=33188, st_ino=4172202, st_dev=16777218L, st_nlink=1, st_uid=501, st_gid=20, st_size=2078, st_atime=1423378041, st_mtime=1423377552, st_ctime=1423377553)
&gt;&gt;&gt; os.lstat("2048.py").st_atime
1423378041.0
</code></pre>
