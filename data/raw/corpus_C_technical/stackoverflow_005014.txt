Question: <p>Is there a way to describe the module's data in a similar way that a docstring describes a module or a funcion?</p>

<pre><code>class MyClass(object):
    def my_function():
        """This docstring works!"""
        return True
    my_list = []
    """This docstring does not work!"""
</code></pre>

Answer: <p>To my knowledge, it is not possible to assign docstrings to module data members.</p>

<p><a href="http://www.python.org/dev/peps/pep-0224/">PEP 224</a> suggests this feature, but the PEP was rejected.</p>

<p>I suggest you document the data members of a module in the module's docstring:</p>

<pre><code># module.py:
"""About the module.

module.data: contains the word "spam"

"""

data = "spam"
</code></pre>
