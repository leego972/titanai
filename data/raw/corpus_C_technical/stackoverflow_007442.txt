Question: <p>I don't know what commands to enter into the setup.py file when compiling a python program to use my icons. Can anyone help me? 
Thanks in advance.</p>

Answer: <pre><code>from distutils.core import setup
import py2exe
setup(
        windows=[{"script": 'app.py', "icon_resources": [(1, "icon.ico")]}],
        options={"py2exe":{"unbuffered": True,
                        "optimize": 2,
                        "bundle_files" : 1,
                        "dist_dir": "bin"}},
                        zipfile = "lib.zip", 
)
</code></pre>
