Question: <p>How can I read the colors of an image with python using google app engine?</p>

<p><strong>Example:</strong> I like to build a function to determine the most striking colors of an image to set a harmonic background color for it.</p>

Answer: <p>For PNG you can use <a href="http://packages.python.org/pypng/" rel="nofollow">PyPNG module</a> - lightweight pure-Python PNG decoder/encoder.</p>

<pre><code>import png

point = (10, 20) # coordinates of pixel to read

reader = png.Reader(filename='image.png') # streams are also accepted
w, h, pixels, metadata = reader.read()
pixel_byte_width = 4 if metadata['has_alpha'] else 3
pixel_position = point[0] + point[1] * w
print pixels[
  pixel_position * pixel_byte_width :
  (pixel_position + 1) * pixel_byte_width]
</code></pre>
