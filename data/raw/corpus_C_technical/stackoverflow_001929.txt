Question: <p>How do I check whether a file exists, without using the <a href="https://docs.python.org/3.6/reference/compound_stmts.html#try"><code>try</code></a> statement?</p>

Answer: <p><strong>Demo</strong>: </p>

<pre><code>try:
    with open('my_settings.dat') as fp:
        pass
except IOError as e:
    print "Unable to open file" #Does not exist OR no read permissions
</code></pre>

<p>Handling missing files with IOErrors rather than if statements.An IOError exception will be raised if the file exists but the user does not have read permissions.</p>
