Question: <p>I need to convert a bunch of files to utf-8 in Python, and I have trouble with the "converting the file" part.</p>

<p>I'd like to do the equivalent of:</p>

<pre><code>iconv -t utf-8 $file &gt; converted/$file # this is shell code
</code></pre>

<p>Thanks!</p>

Answer: <p>This worked for me in a small test:</p>

<pre><code>sourceEncoding = "iso-8859-1"
targetEncoding = "utf-8"
source = open("source")
target = open("target", "w")

target.write(unicode(source.read(), sourceEncoding).encode(targetEncoding))
</code></pre>
