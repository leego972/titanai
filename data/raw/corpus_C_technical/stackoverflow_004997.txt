Question: <p>I am building a project involving natural language processing, since the nlp module currently only deal with english text, so I have to make sure the user submitted content (not long, only several words) is in english. Are there established ways to achieve this? Python or Javascript way preferred.</p>

Answer: <p>I think the most effective way would be to ask the users to submit english text only :)</p>

<p>You can show a language selection drop-down over your text area with English/ Other as the options. When user selects "Other",  disable the text area with a message that only English language is supported [at the moment].</p>
