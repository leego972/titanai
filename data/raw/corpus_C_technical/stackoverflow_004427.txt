Question: <p>For a list <code>["foo", "bar", "baz"]</code> and an item in the list <code>"bar"</code>, what's the cleanest way to get its index (1) in Python?</p>

Answer: <p>One thing that is really helpful in learning Python is to use the interactive help function:</p>

<pre><code>&gt;&gt;&gt; help(["foo", "bar", "baz"])
Help on list object:

class list(object)
 ...

 |
 |  index(...)
 |      L.index(value, [start, [stop]]) -&gt; integer -- return first index of value
 |
</code></pre>

<p>which will often lead you to the method you are looking for.</p>
