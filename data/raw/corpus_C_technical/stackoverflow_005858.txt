Question: <p>In C++ you can disable a function in parent's class by declaring it as private in the child class. How can this be done in Python? I.E. How can I hide parent's function from child's public interface?</p>

Answer: <p>A variation on the answer of kurosch:</p>

<pre><code>class Foo( object ):
    def foo( self ):
        print 'FOO!'

class Bar( Foo ):
    @property
    def foo( self ):
        raise AttributeError( "'Bar' object has no attribute 'foo'" )

b = Bar()
b.foo
</code></pre>

<p>This raises an <code>AttributeError</code> on the property instead of when the method is called.</p>
