Question: <p>I'm using Python, and would like to insert a string into a text file without deleting or copying the file. How can I do that?</p>

Answer: <p>Depends on what you want to do.  To append you can open it with "a":</p>

<pre><code> with open("foo.txt", "a") as f:
     f.write("new line\n")
</code></pre>

<p>If you want to preprend something you have to read from the file first:</p>

<pre><code>with open("foo.txt", "r+") as f:
     old = f.read() # read everything in the file
     f.seek(0) # rewind
     f.write("new line\n" + old) # write the new line before
</code></pre>
