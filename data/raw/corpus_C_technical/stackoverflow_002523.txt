Question: <p>How do I end a Tkinter program? Let's say I have this code:</p>

<pre><code>from Tkinter import *

def quit():
    # code to exit

root = Tk()
Button(root, text="Quit", command=quit).pack()
root.mainloop()
</code></pre>

<p>How should I define the <code>quit</code> function?</p>

Answer: <p>The usual method to exit a Python program:</p>

<pre><code>sys.exit()
</code></pre>

<p>(to which you can also pass an exit status) or </p>

<pre><code>raise SystemExit
</code></pre>

<p>will work fine in a Tkinter program.</p>
