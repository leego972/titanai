Question: <p>For a list <code>["foo", "bar", "baz"]</code> and an item in the list <code>"bar"</code>, what's the cleanest way to get its index (1) in Python?</p>

Answer: <p>You have to set a condition to check if the element you're searching is in the list</p>

<pre><code>if 'your_element' in mylist:
    print mylist.index('your_element')
else:
    print None
</code></pre>
