  <p><a href="http://www.mono-project.com/docs/tools+libraries/tools/repl/" rel="nofollow">http://www.mono-project.com/docs/tools+libraries/tools/repl/</a></p>

<p>And wondered whether something like this exists for Python.</p>

Answer: <p><a href="http://www.dreampie.org/" rel="nofollow">DreamPie</a> is my personal favorite. It doesn't appear to be any more restrictive than CSharpRepl.  For example, the graph drawing example can be done if matplotlib is installed.  There is an example screenshot to this effect on DreamPie's web site (<a href="http://dreampie.sourceforge.net/" rel="nofollow">http://dreampie.sourceforge.net/</a>).  </p>

<p>Bpython is similar, and I like it better.  But it is only available on Linux as binary.  </p>
