Question: <p>I am building a project involving natural language processing, since the nlp module currently only deal with english text, so I have to make sure the user submitted content (not long, only several words) is in english. Are there established ways to achieve this? Python or Javascript way preferred.</p>

Answer: <p>Try:</p>

<p><a href="http://wordlist.sourceforge.net/" rel="nofollow">http://wordlist.sourceforge.net/</a></p>

<p>For a list of English words.</p>

<p>You will need to be careful of names, e.g. "Canberra" or "Bill Clinton". These won't appear in the word list. I suggest just checking whether the first letter is capitalized as a first attempt.</p>
