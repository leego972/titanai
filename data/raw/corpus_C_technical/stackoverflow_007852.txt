Question: <p>For some reason I can't find a way to get the equivalents of sqlite's interactive shell commands:</p>

<pre><code>.tables
.dump
</code></pre>

<p>using the Python sqlite3 API. </p>

<p>Is there anything like that?</p>

Answer: <p>You can fetch the list of tables and schemata by querying the SQLITE_MASTER table:</p>

<pre><code>sqlite&gt; .tab
job         snmptarget  t1          t2          t3        
sqlite&gt; select name from sqlite_master where type = 'table';
job
t1
t2
snmptarget
t3

sqlite&gt; .schema job
CREATE TABLE job (
    id INTEGER PRIMARY KEY,
    data VARCHAR
);
sqlite&gt; select sql from sqlite_master where type = 'table' and name = 'job';
CREATE TABLE job (
    id INTEGER PRIMARY KEY,
    data VARCHAR
)
</code></pre>
