Question: <p>I want to take a screenshot via a python script and unobtrusively save it.</p>

<p>I'm only interested in the Linux solution, and should support any X based environment.</p>

Answer: <p>I have a wrapper project (<a href="https://github.com/ponty/pyscreenshot">pyscreenshot</a>) for scrot, imagemagick, pyqt, wx and pygtk.
If you have one of them, you can use it.
All solutions are included from this discussion.</p>

<p>Install:</p>

<pre><code>easy_install pyscreenshot
</code></pre>

<p>Example:</p>

<pre><code>import pyscreenshot as ImageGrab

# fullscreen
im=ImageGrab.grab()
im.show()

# part of the screen
im=ImageGrab.grab(bbox=(10,10,500,500))
im.show()

# to file
ImageGrab.grab_to_file('im.png')
</code></pre>
