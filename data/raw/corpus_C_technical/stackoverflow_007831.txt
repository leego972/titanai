Question: <p>Is it possible to use <a href="http://www.python.org/" rel="nofollow">CPython</a> to develop Adobe Flash based applications?</p>

Answer: <p>I guess it would be possible to compile the python interpreter to flash bytecode using this <a href="http://labs.adobe.com/downloads/alchemy.html" rel="nofollow">http://labs.adobe.com/downloads/alchemy.html</a> and then use it to run python programs. But apart from that the answer is no.</p>
