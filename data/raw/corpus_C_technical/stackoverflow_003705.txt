Question: <p>In C I could, for example, zero out bit #10 in a 32 bit unsigned value like so:</p>

<pre><code>unsigned long value = 0xdeadbeef;
value &amp;= ~(1&lt;&lt;10);
</code></pre>

<p>How do I do that in Python ?</p>

Answer: <p>Omit the 'unsigned long', and the semi-colons are not needed either:</p>

<pre><code>value = 0xDEADBEEF
value &amp;= ~(1&lt;&lt;10)
print value
"0x%08X" % value
</code></pre>
