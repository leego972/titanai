Question: <p>I want to start using Python for small projects but the fact that a misplaced tab or indent can throw a compile error is really getting on my nerves. Is there some type of setting to turn this off?</p>

<p>I'm currently using NotePad++. Is there maybe an IDE that would take care of the tabs and indenting?</p>

Answer: <p>No, there isn't. Indentation is syntax for Python. You can:</p>

<ol>
<li>Use tabnanny.py to check your code</li>
<li>Use a syntax-aware editor that highlights such mistakes (vi does that, emacs I bet it does, and then, most IDEs do too)</li>
<li>(far-fetched) write a preprocessor of your own to convert braces (or whatever block delimiters you love) into indentation</li>
</ol>
