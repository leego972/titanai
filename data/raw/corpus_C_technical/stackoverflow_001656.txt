Question: <p>Using the Python Documentation I found the <a href="http://docs.python.org/lib/module-HTMLParser.html">HTML parser</a> but I have no idea which library to import to use it, how do I find this out (bearing in mind it doesn't say on the page).</p>

Answer: <p>Try:</p>

<pre><code>import HTMLParser
</code></pre>

<p>In Python 3.0, the HTMLParser module has been renamed to html.parser
you can check about this <a href="http://docs.python.org/library/htmlparser.html">here</a></p>

<p>Python 3.0</p>

<pre><code>import html.parser
</code></pre>

<p>Python 2.2 and above</p>

<pre><code>import HTMLParser
</code></pre>
