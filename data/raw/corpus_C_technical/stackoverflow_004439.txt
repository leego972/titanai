Question: <p>For a list <code>["foo", "bar", "baz"]</code> and an item in the list <code>"bar"</code>, what's the cleanest way to get its index (1) in Python?</p>

Answer: <p>This solution is not as powerful as others, but if you're a beginner and only know about <code>for</code>loops it's still possible to find the first index of an item while avoiding the ValueError:</p>

<pre><code>def find_element(p,t):
i = 0
for e in p:
    if e == t:
        return i
    else:
        i +=1
return -1
</code></pre>
