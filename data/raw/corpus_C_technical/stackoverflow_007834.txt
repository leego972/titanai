Question: <p>I just installed a linux system (Kubuntu) and was wondering if there is a program to make python programs executable for linux.</p>

Answer: <p>Just put this in the first line of your script :</p>

<pre><code>#!/usr/bin/env python
</code></pre>

<p>Make the file executable with</p>

<pre><code>chmod +x myfile.py
</code></pre>

<p>Execute with</p>

<pre><code>./myfile.py
</code></pre>
