Question: <p>What's the <strong>easiest, tersest, and most flexible</strong> method or library for parsing Python command line arguments?</p>

Answer: <p><a href="https://github.com/muromec/consoleargs" rel="nofollow">consoleargs</a> deserves to be mentioned here. It is very easy to use. Check it out:</p>

<pre><code>from consoleargs import command

@command
def main(url, name=None):
  """
  :param url: Remote URL 
  :param name: File name
  """
  print """Downloading url '%r' into file '%r'""" % (url, name)

if __name__ == '__main__':
  main()
</code></pre>

<p>Now in console:</p>

<pre><code>% python demo.py --help
Usage: demo.py URL [OPTIONS]

URL:    Remote URL 

Options:
    --name -n   File name

% python demo.py http://www.google.com/
Downloading url ''http://www.google.com/'' into file 'None'

% python demo.py http://www.google.com/ --name=index.html
Downloading url ''http://www.google.com/'' into file ''index.html''
</code></pre>
