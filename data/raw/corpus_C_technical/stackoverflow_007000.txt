Question: <p>What is the Python equivalent of Perl's <code>chomp</code> function, which removes the last character of a value?</p>

Answer: <p>Careful with <code>"foo".rstrip(os.linesep)</code>: That will only chomp the newline characters for the platform where your Python is being executed. Imagine you're chimping the lines of a Windows file under Linux, for instance:</p>

<pre><code>$ python
Python 2.7.1 (r271:86832, Mar 18 2011, 09:09:48) 
[GCC 4.5.0 20100604 [gcc-4_5-branch revision 160292]] on linux2
Type "help", "copyright", "credits" or "license" for more information.
&gt;&gt;&gt; import os, sys
&gt;&gt;&gt; sys.platform
'linux2'
&gt;&gt;&gt; "foo\r\n".rstrip(os.linesep)
'foo\r'
&gt;&gt;&gt;
</code></pre>

<p>Use <code>"foo".rstrip("\r\n")</code> instead, as Mike says above.</p>
