Question: <p>I need to convert a list (or a dict) into a comma-separated list for passing to another language.</p>

<p>Is there a nicer way of doing this than:</p>

<pre><code> result = ''
 args = ['a', 'b', 'c', 'd']

 i = 0
 for arg in args:
     if i != 0:    result += arg
     else:         result += arg + ', '
     i += 1

 result = 'function (' + result + ')
</code></pre>

<p>Thanks,
Dan</p>

Answer: <p>Why not use a standard that both languages can parse, like JSON, XML, or YAML?  <a href="http://pypi.python.org/pypi/simplejson" rel="nofollow">simplejson</a> is handy, and included as json in python 2.6.</p>
