Question: <p>I've got some experience with <a href="http://en.wikipedia.org/wiki/Bash_%28Unix_shell%29">Bash</a>, which I don't mind, but now that I'm doing a lot of Windows development I'm needing to do basic stuff/write basic scripts using 
the Windows command-line language. For some reason said language really irritates me, so I was considering learning Python and using that instead.</p>

Answer: <p>Python is well suited for these tasks, and I would guess much easier to develop in and debug than Windows batch files.</p>

<p>The question is, I think, how easy and painless it is to ensure that all the computers that you have to run these scripts on, have Python installed.</p>
