Question: <p>What's the easiest way of me converting the simpler regex format that most users are used to into the correct re python regex string?</p>

<p>As an example, I need to convert this:</p>

<pre><code>string = "*abc+de?"
</code></pre>

<p>to this:</p>

<pre><code>string = ".*abc.+de.?"
</code></pre>

<p>Of course I could loop through the string and build up another string character by character, but that's surely an inefficient way of doing this?</p>

Answer: <p>Here is a <a href="http://www.unix.com.ua/orelly/perl/cookbook/ch06_10.htm" rel="nofollow">Perl example</a> of doing this. It is simply using a table to replace each wildcard construct with the corresponding regular expression. I've done this myself previously, but in C. It shouldn't be too hard to port to Python.</p>
