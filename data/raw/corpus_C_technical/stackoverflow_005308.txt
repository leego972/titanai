Question: <p>I'm using the following view function to iterate over all items in the database (in order to find a tag), but I think the performance is very poor if the dataset is large.
Any other approach?</p>

<pre><code>def by_tag(tag):
return  '''
        function(doc) {
            if (doc.tags.length &gt; 0) {
                for (var tag in doc.tags) {
                    if (doc.tags[tag] == "%s") {
                        emit(doc.published, doc)
                    }
                }
            }
        };
        ''' % tag
</code></pre>

Answer: <p>You can define a single permanent view, as Bahadir suggests. when doing this sort of indexing, though, <em>don't</em> output the doc for each key. Instead, emit([tag, doc.published], null). In current release versions you'd then have to do a separate lookup for each doc, but SVN trunk now has support for specifying "include_docs=True" in the query string and CouchDB will automatically merge the docs into your view for you, without the space overhead.</p>
