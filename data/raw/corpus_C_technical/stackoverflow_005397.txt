Question: <p>I've got some experience with <a href="http://en.wikipedia.org/wiki/Bash_%28Unix_shell%29">Bash</a>, which I don't mind, but now that I'm doing a lot of Windows development I'm needing to do basic stuff/write basic scripts using 
the Windows command-line language. For some reason said language really irritates me, so I was considering learning Python and using that instead.</p>

<p>Is Python suitable for such things? Moving files around, creating scripts to do things like unzipping a backup and restoring a SQL database, etc.</p>

Answer: <p>Python, along with <a href="http://sourceforge.net/projects/pywin32/" rel="nofollow">Pywin32</a>, would be fine for Windows automation.  However, VBScript or JScript used with the Winows Scripting Host works just as well, and requires nothing additional to install.</p>
