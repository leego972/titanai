Question: <p>How can I call an external command (as if I'd typed it at the Unix shell or Windows command prompt) from within a Python script?</p>

Answer: <p>without the output of result</p>

<pre><code>import os
os.system("your command here")
</code></pre>

<p>with output of result</p>

<pre><code>import commands
commands.getoutput("your command here")
or
commands.getstatusoutput("your command here")
</code></pre>
