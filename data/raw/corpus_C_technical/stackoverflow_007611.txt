Question: <p>What is and how can it be used in C#.<br/>
Can you use the same concept in Python/Perl?</p>

Answer: <p>A <a href="http://msdn.microsoft.com/en-us/library/wa80x488.aspx">partial type</a> (it doesn't have to be a class; structs and interfaces can be partial too) is basically a single type which has its code spread across multiple files.</p>

<p>The main use for this is to allow a code generator (e.g. a Visual Studio designer) to "own" one file, while hand-written code is put in another.</p>

<p>I've no idea whether Python/Perl have the same capabilities, I'm afraid.</p>
