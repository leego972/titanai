Question: <p>How can I output colored text to the terminal, in Python?
What is the best Unicode symbol to represent a solid block?</p>

Answer: <p><a href="http://asciimatics.readthedocs.io/en/stable/intro.html" rel="nofollow">asciimatics</a> provides a portable support for building text UI and animations:</p>

<pre><code>#!/usr/bin/env python
from asciimatics.effects import RandomNoise  # $ pip install asciimatics
from asciimatics.renderers import SpeechBubble, Rainbow
from asciimatics.scene import Scene
from asciimatics.screen import Screen
from asciimatics.exceptions import ResizeScreenError


def demo(screen):
    render = Rainbow(screen, SpeechBubble('Rainbow'))
    effects = [RandomNoise(screen, signal=render)]
    screen.play([Scene(effects, -1)], stop_on_resize=True)

while True:
    try:
        Screen.wrapper(demo)
        break
    except ResizeScreenError:
        pass
</code></pre>
