Question: <p>What would be the quickest way to construct a python binding to a C or C++ library?</p>

<p>(using windows if this matters)</p>

Answer: <p><a href="http://openwetware.org/wiki/Julius_B._Lucks/Projects/Python_All_A_Scientist_Needs">This paper, claiming python to be all a scientist needs,</a> basically says: first prototype everything in Python. Then when you need to speed a part up, use SWIG and translate this part to C.</p>
