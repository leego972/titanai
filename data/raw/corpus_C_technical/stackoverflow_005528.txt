Question: <p>I'm pretty sure one would do this using the os.plock(op) function, but I have no idea how. Also, if there's a better way, I'd be grateful to find out. Code snippets are very welcome. </p>

Answer: <p>You have two options: <code>os.popen*</code> in the <code>os</code> module, or you can use the <code>subprocess</code> module to the same effect. The Python manual has pretty documentation and examples for <a href="http://www.python.org/doc/2.5.2/lib/module-popen2.html" rel="nofollow" title="popen">popen</a> and <a href="http://www.python.org/doc/2.5.2/lib/module-subprocess.html" rel="nofollow" title="subprocess">subprocess</a>.</p>
