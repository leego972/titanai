Question: <p>I'm mainly a C# developer, but I'm currently working on a project in Python.</p>

<p>How can I represent the equivalent of an Enum in Python?  </p>

Answer: <p>From Python 3.4 there will be official support for enums. You can find documentation and examples <a href="http://docs.python.org/3.4/library/enum.html" rel="nofollow">here on Python 3.4 documentation page</a>.</p>

<blockquote>
  <p>Enumerations are created using the class syntax, which makes them easy
  to read and write. An alternative creation method is described in
  Functional API. To define an enumeration, subclass Enum as follows:</p>
</blockquote>

<pre><code>from enum import Enum
class Color(Enum):
     red = 1
     green = 2
     blue = 3
</code></pre>
