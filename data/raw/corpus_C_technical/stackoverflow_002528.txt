Question: <p>How do I end a Tkinter program? Let's say I have this code:</p>

<pre><code>from Tkinter import *

def quit():
    # code to exit

root = Tk()
Button(root, text="Quit", command=quit).pack()
root.mainloop()
</code></pre>

<p>How should I define the <code>quit</code> function?</p>

Answer: <p>I'm thinking of making an RPG with Tkinter, and I find that if use a while True loop, make sure you save progress or whatever, and then use something like this:</p>

<pre><code>    import Tkinter

    root=Tkinter.Tk()
    def q():
        exit()
    while True:        
        Button(root, text="Quit", command=q).pack()
        root.mainloop()
</code></pre>

<p>Worked for me!</p>

<p>It does just stop the program but the root.destroy() or root.quit() wasn't working for me. exit() worked fine!</p>
