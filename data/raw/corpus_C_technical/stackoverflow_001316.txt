Question: <p>Been scouring the net for something like firewatir but for python.  I'm trying to automate  firefox on linux.  Any suggestions?</p>

Answer: <p>Many command line tools don't have a javascript interpreter so do not support web 2.0 functionality.  <a href="http://code.google.com/p/juicedpyshell" rel="nofollow">juicedpyshell</a> is based on PyXPCOMext's PyShell example.  It gives you a python shell window "inside" the browser, and simplifies access to both the DOM of what you are browsing to and also the shell window itself (so you can add GUI elements as part of your automation script).  But its a new project so probably not as full featured as some of the above.</p>
