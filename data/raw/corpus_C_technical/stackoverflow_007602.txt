Question: <p>I need to test a function that needs to query a page on an external server using urllib.urlopen (it also uses urllib.urlencode). The server could be down, the page could change; I can't rely on it for a test.</p>

<p>What is the best way to control what urllib.urlopen returns?</p>

Answer: <p>I am using <a href="http://www.voidspace.org.uk/python/mock/">Mock's</a> patch decorator:</p>

<pre><code>from mock import patch

[...]

@patch('urllib.urlopen')
def test_foo(self, urlopen_mock):
    urlopen_mock.return_value = MyUrlOpenMock()
</code></pre>
