Question: <p>Is there a benefit to using one over the other? They both seem to return the same results.</p>

<pre><code>&gt;&gt;&gt; 6/3
2
&gt;&gt;&gt; 6//3
2
</code></pre>

Answer: <p>As everyone has already answered, <code>//</code> is floor division.</p>

<p>Why this is important is that <code>//</code> is unambiguously floor division, in all Python versions from 2.2, including Python 3.x versions.</p>

<p>The behavior of <code>/</code> can change depending on:</p>

<ul>
<li>Active <code>__future__</code> import or not (module-local)</li>
<li>Python command line option, either <code>-Q old</code> or <code>-Q new</code></li>
</ul>
