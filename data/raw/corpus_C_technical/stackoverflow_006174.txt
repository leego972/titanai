Question: <p>Imagine I have these python lists:</p>

<pre><code>keys = ['name', 'age']
values = ['Monty', 42, 'Matt', 28, 'Frank', 33]
</code></pre>

<p>Is there a direct or at least a simple way to produce the following list of dictionaries ?</p>

<pre><code>[
    {'name': 'Monty', 'age': 42},
    {'name': 'Matt',  'age': 28},
    {'name': 'Frank', 'age': 33}
]
</code></pre>

Answer: <p>Here's my simple approach.  It seems to be close to the idea that @Cheery had except that I destroy the input list.</p>

<pre><code>def pack(keys, values):
  """This function destructively creates a list of dictionaries from the input lists."""
  retval = []
  while values:
    d = {}
    for x in keys:
      d[x] = values.pop(0)
    retval.append(d)
  return retval
</code></pre>
