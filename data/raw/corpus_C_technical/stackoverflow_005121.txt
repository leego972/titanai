Question: <p>What is the difference between multiprocessor programming and multicore programming?
preferably show examples in python how to write a small program for multiprogramming &amp; multicore programming</p>

Answer: <p>As mentioned in another post Python 2.6 has the <a href="http://docs.python.org/library/multiprocessing.html">multiprocessing</a> module, which can take advantage of multiple cores/processors (it gets around GIL by starting multiple processes transparently). It offers some primitives similar to the threading module. You'll find some (simple) examples of usage in the documentation pages.</p>
