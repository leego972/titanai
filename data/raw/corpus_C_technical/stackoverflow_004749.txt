Answer: <p>In this case, as pointed out by others as well, functional decomposition is the way to go. Code in Python 3:</p>

<pre><code>def user_confirms():
    while True:
        answer = input("Is this OK? (y/n) ").strip().lower()
        if answer in "yn":
            return answer == "y"

def main():
    while True:
        # do stuff
        if user_confirms():
            break
</code></pre>
