<p>Here's the quickExit version that runs pretty quickly, but isn't a one-liner.</p>

<pre><code>def quickExit( aList ):
    """for with return False if no match found."""
    value= aList[0]
    for x in aList:
        if x != value: return False
    return True
</code></pre>
