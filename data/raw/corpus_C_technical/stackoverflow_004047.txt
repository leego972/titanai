Question: <p>I have a Person model that has a foreign key relationship to Book.  Book has a number of fields, but I'm most concerned about "author" (a standard CharField).</p>

<p>With that being said, in my PersonAdmin model, I'd like to display "book.author" using "list_display".  I've tried all of the obvious methods for doing so (see below), but nothing seems to work.  Any suggestions?</p>

<pre><code>class PersonAdmin(admin.ModelAdmin):
  list_display = ['book.author',]
</code></pre>

Answer: <p>AlexRobbins' answer worked for me, except that the first two lines need to be in the model (perhaps this was assumed?), and should reference self:</p>

<pre><code>def book_author(self):
  return self.book.author
</code></pre>

<p>Then the admin part works nicely.</p>
