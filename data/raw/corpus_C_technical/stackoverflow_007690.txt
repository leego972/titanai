Question: <p>I have the following Python code:  </p>

<pre><code>import xml.dom.minidom
import xml.parsers.expat

try:
    domTree = ml.dom.minidom.parse(myXMLFileName)
except xml.parsers.expat.ExpatError, e:
    return e.args[0]
</code></pre>

<p>which I am using to parse an XML file. Although it quite happily spots simple XML errors like mismatched tags, it completely ignores the DTD specified at the top of the XML file:  </p>

<pre><code>&lt;?xml version="1.0" encoding="UTF-8" standalone="no" ?&gt;
&lt;!DOCTYPE ServerConfig SYSTEM "ServerConfig.dtd"&gt;
</code></pre>

<p>so it doesn't notice when mandatory elements are missing, for example. How can I switch on DTD checking?</p>

Answer: <p>Just by way of explanation: Python xml.dom.minidom and xml.sax use the expat parser by default, which is a non-validating parser.  It may read the DTD in order to do entity replacement, but it won't validate against the DTD.</p>

<p>gimel and Tim recommend lxml, which is a nicely pythonic binding for the libxml2 and libxslt libraries.  It supports validation against a DTD.  I've been using lxml, and I like it a lot.</p>
