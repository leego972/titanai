Question: <p>I am looking to format a number like 188518982.18 to Â£188,518,982.18 using Python.</p>

Answer: <p>Not quite sure why it's not mentioned more online (or on this thread), but the <a href="http://babel.pocoo.org/">Babel</a> package (and Django utilities) from the Edgewall guys is awesome for currency formatting (and lots of other i18n tasks).  It's nice because it doesn't suffer from the need to do everything globally like the core Python locale module.</p>

<p>The example the OP gave would simply be:</p>

<pre><code>&gt;&gt;&gt; import babel.numbers
&gt;&gt;&gt; import decimal
&gt;&gt;&gt; babel.numbers.format_currency( decimal.Decimal( "188518982.18" ), "GBP" )
Â£188,518,982.18
</code></pre>
