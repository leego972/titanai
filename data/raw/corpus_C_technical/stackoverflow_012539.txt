Question: <p>What is the difference between the following class methods?</p>

<p>Is it that one is static and the other is not?</p>

<pre><code>class Test(object):
  def method_one(self):
    print "Called method_one"

  def method_two():
    print "Called method_two"

a_test = Test()
a_test.method_one()
a_test.method_two()
</code></pre>

Answer: <p>method_two won't work because you're defining a member function but not telling it what the function is a member of. If you execute the last line you'll get:</p>

<pre><code>&gt;&gt;&gt; a_test.method_two()
Traceback (most recent call last):
  File "&lt;stdin&gt;", line 1, in &lt;module&gt;
TypeError: method_two() takes no arguments (1 given)
</code></pre>

<p>If you're defining member functions for a class the first argument must always be 'self'.</p>
