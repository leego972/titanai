Question: <p>How, in the simplest possible way, distinguish between Windows XP and Windows Vista, using Python and <a href="http://python.net/crew/mhammond/win32/Downloads.html">pywin32</a> or <a href="http://www.wxpython.org/">wxPython</a>?</p>

<p>Essentially, I need a function that called will return True iff current OS is Vista:</p>

<pre><code>&gt;&gt;&gt; isWindowsVista()
True
</code></pre>

Answer: <p>The solution used in Twisted, which doesn't need pywin32:</p>

<pre><code>def isVista():
    if getattr(sys, "getwindowsversion", None) is not None:
        return sys.getwindowsversion()[0] == 6
    else:
        return False
</code></pre>

<p>Note that it will also match Windows Server 2008.</p>
