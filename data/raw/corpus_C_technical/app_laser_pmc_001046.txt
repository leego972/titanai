Disability was assessed with EDSS<sup><xref rid="fcag007-B21" ref-type="bibr">21</xref></sup> by a trained assessor.</p></sec><sec id="fcag007-s2.4"><title>Magnetic resonance imaging acquisition and analysis</title><p>MRI was performed in patients only. MRI data were acquired using a 3T Philips Ingenia CX system (Philips Healthcare, Best, The Netherlands) with a 32-channel head coil. High-resolution (1 mm<sup>3</sup> isotropic) 3D T1-weighted images were acquired for brain volumetric measurements. A magnetization-prepared 3D Turbo Field Echo sequence was used with the following parameters: number of slices = 176, repetition time (TR) = 28 ms, echo time (TE) = 7 ms, flip angle (FA) = 24°, voxel size = 1.0 × 1.0 × 1.0 mm³, acquired in the sagittal orientation. In addition, 3D T2-weighted fluid-attenuated inversion recovery (FLAIR) data were acquired for each subject using the following parameters: voxel size = 1.2 mm³ isotropic, number of slices = 176, repetition time (TR) = 4800 ms, inversion time = 1650 ms, echo time (TE) = 268 ms, acquired in the sagittal orientation.</p><p>T2 FLAIR images were used for the segmentation of white matter lesions. Lesion detection was conducted using a single cascade version of NicMSlesion.<sup><xref rid="fcag007-B22" ref-type="bibr">22</xref></sup> This is a supervised machine learning based technique which implements a single convolutional neural network to classify lesion voxels. The model used for this segmentation has been trained using clinical trial data (MS-STAT2) acquired on the same MRI scanner and has been previously validated in house.<sup><xref rid="fcag007-B23" ref-type="bibr">23</xref></sup> Lesion masks were checked and manually corrected by trained raters.</p><p>For each participant, the FLAIR volume was then linearly co-registered to the 3D T1 using NiftyReg,<sup><xref rid="fcag007-B24" ref-type="bibr">24</xref>,<xref rid="fcag007-B25" ref-type="bibr">25</xref></sup> and the obtained transformations were applied to the lesion masks to enable lesion filling using a patch-based technique.<sup><xref rid="fcag007-B26" ref-type="bibr">26</xref></sup></p><p>Anatomical T1-weighted lesion-filled images were used for whole brain tissue class segmentation. Whole brain images were segmented in native subject space into gross tissues classes (cortical grey matter, white matter, deep grey matter, cerebrospinal fluid), as well as parcellated regional brain volumes<sup><xref rid="fcag007-B27" ref-type="bibr">27</xref></sup> using Geodesical Information Flows segmentation software.</p><p>White and grey matter brain volumes were adjusted for total intracranial volume (TIV) in regression models. The residuals of these regression models were considered the new, <italic toggle="yes">adjusted</italic>, grey and white matter values to be used in subsequent steps.<sup><xref rid="fcag007-B28" ref-type="bibr">28</xref></sup> Regional cortical volumes were corrected for total grey matter (adjusted values). Visual pathway structures/cortices and non-visual cortices were examined (the latter as qualitative controls).</p></sec><sec id="fcag007-s2.5"><title>Defining optic neuritis status</title><p>Eyes affected by optic neuritis were designated with the following criteria: thinner eye of a pair if inter-eye differences were ≥ 5 µm for pRNFL and ≥ 4 µm for mGCIPL.<sup><xref rid="fcag007-B29" ref-type="bibr">29</xref></sup> For remaining OCT metrics, if eyes showed an absolute pRNFL thickness &lt;75 µm or mGCIPL thickness &lt;52 µm (calculations based on &lt;2.5 standard deviations below the weighted pRNFL and GCIPL mean for a healthy cohort aged between 18 and 70 + years, obtained from a Heidelberg Spectralis machine),<sup><xref rid="fcag007-B29" ref-type="bibr">29</xref>,<xref rid="fcag007-B30" ref-type="bibr">30</xref></sup> these were additionally assigned as eyes affected by optic neuritis.</p></sec><sec id="fcag007-s2.6"><title>Statistical analysis</title><p>Analyses were performed using R Studio (R 4.1.2) (Posit, Massachusetts, USA). Differences in demographic variables between HCs and MS patients were explored with two sample <italic toggle="yes">t</italic> tests or chi-squared tests of independence (for numeric or categorical).</p><p>Optic neuritis and eye status (HC, non-optic neuritis, optic neuritis) were initially assessed as predictors of OCT (pRNFL, mGCIPL) and superficial vascular plexus OCTA (VAD, VLD, FD) metrics, adjusting for age and sex at eye level in linear mixed models with participants as random intercepts to account for within-subject eye correlations.</p><p>Further analyses for MS patients were performed using linear mixed models with participants as random intercepts in two forms.
