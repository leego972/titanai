Question: <p>How can I fetch more than 1000 record from data store and put all in one single list to pass to django?</p>

Answer: <p>we are using something in our <code>ModelBase</code> class that is:</p>

<pre><code>@classmethod
def get_all(cls):
  q = cls.all()
  holder = q.fetch(1000)
  result = holder
  while len(holder) == 1000:
    holder = q.with_cursor(q.cursor()).fetch(1000)
    result += holder
  return result
</code></pre>

<p>This gets around the 1000 query limit on every model without having to think about it. I suppose a keys version would be just as easy to implement.</p>
