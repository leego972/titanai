Question: <p>I need to validate an XML string (and not a file)
against a DTD description file. </p>

<p>How can that be done in <code>python</code>?</p>

Answer: <p>from the examples directory in the libxml2 python bindings:</p>

<pre><code>#!/usr/bin/python -u
import libxml2
import sys

# Memory debug specific
libxml2.debugMemory(1)

dtd="""&lt;!ELEMENT foo EMPTY&gt;"""
instance="""&lt;?xml version="1.0"?&gt;
&lt;foo&gt;&lt;/foo&gt;"""

dtd = libxml2.parseDTD(None, 'test.dtd')
ctxt = libxml2.newValidCtxt()
doc = libxml2.parseDoc(instance)
ret = doc.validateDtd(ctxt, dtd)
if ret != 1:
    print "error doing DTD validation"
    sys.exit(1)

doc.freeDoc()
dtd.freeDtd()
del dtd
del ctxt
</code></pre>
