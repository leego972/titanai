Question: <p>I want to send some strings in a list in a POST call. eg:</p>

<pre><code>    www.example.com/?post_data = A list of strings
</code></pre>

<p>The python code receives the data as a single string (Instead of a list of strings). How do I post it as  a list of strings?</p>

Answer: <p>There's no such thing as a "list of strings" in a URL (or in practically anything in HTTP - if you specify multiple values for the same header, they come out as a single delimited value in most web app frameworks IME). It's just a single string. I suggest you delimit the strings in some way (e.g. comma-separated) and then parse them out again at the other end.</p>
