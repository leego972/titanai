Question: <p>Is there any example code of a <a href="http://www.python.org/">cpython</a> (not IronPython) client which can call Windows Communication Foundation (WCF) service?</p>

Answer: <p>I do not know of any direct examples, but if the WCF service is REST enabled you could access it through POX (Plain Old XML) via the REST methods/etc (if the service has any). If you are in control of the service you could expose endpoints via REST  as well. </p>
