Question: <p>I want to write a program that would print every combination of a set of variables to a text file, creating a word list. Each answer should be written on a separate line and write all of the results for 1 digit, 2 digits, and 3 digits to a single text file.</p>

<p>Is there a simple way I can write a python program that can accomplish this? Here is an example of the output I am expecting when printing all the binary number combinations possible for 1, 2, and 3 digits:</p>

<pre><code>Output:
0  
1

00  
01  
10  
11

000  
001  
010  
011  
100  
101  
110  
111
</code></pre>

Answer: <p>A basic function to produce all the permutations of a list is given below. In this approach, permutations are created lazily by using generators.</p>

<pre><code>def perms(seq):
    if seq == []:
        yield []
    else:
        res = []
        for index,item in enumerate(seq):
            rest = seq[:index] + seq[index+1:]
            for restperm in perms(rest):
                yield [item] + restperm

alist = [1,1,0]
for permuation in perms(alist):
    print permuation
</code></pre>
