Question: <p>For example, if I have a <em>unicode</em> string, I can encode it as an <em>ASCII</em> string like so:</p>

<pre><code>&gt;&gt;&gt; u'\u003cfoo/\u003e'.encode('ascii')
'&lt;foo/&gt;'
</code></pre>

<p>However, I have e.g. this <em>ASCII</em> string:</p>

<pre><code>'\u003foo\u003e'
</code></pre>

<p>... that I want to turn into the same <em>ASCII</em> string as in my first example above:</p>

<pre><code>'&lt;foo/&gt;'
</code></pre>

Answer: <p>At some point you will run into issues when you encounter special characters like Chinese characters or emoticons in a string you want to decode i.e. errors that look like this:</p>

<pre><code>UnicodeEncodeError: 'ascii' codec can't encode characters in position 109-123: ordinal not in range(128)
</code></pre>

<p>For my case (twitter data processing), I decoded as follows to allow me to see all characters with no errors</p>

<pre><code>&gt;&gt;&gt; s = '\u003cfoo\u003e'
&gt;&gt;&gt; s.decode( 'unicode-escape' ).encode( 'utf-8' )
&gt;&gt;&gt; &lt;foo&gt;
</code></pre>
