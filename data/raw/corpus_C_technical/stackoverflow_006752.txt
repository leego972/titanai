Question: <p>I'm running <a href="http://en.wikipedia.org/wiki/Mac_OS_X_Leopard" rel="nofollow">Mac&nbsp;OS&nbsp;X Leopard</a> and wanted to know what the easy way to setup a web development environment to use Python, MySQL, Apache on my machine which would allow me to develop on my Mac and then easily move it to a host in the future.</p>

<p>I've been trying to get mod_wsgi installed and configured to work with Django and have a headache now. Are there any web hosts that currently use mod_wsgi besides Google, so I could just develop there?</p>

Answer: <p>Of course Mac OS X, in recent versions, comes with Python and Apache.  However you may want to have more flexibility in the versions you use, or you may not like the tweaks Apple has made to the way they are configured.  A good way to get a more generic set of tools, including MySQL, is to install them anew.  This will help your portability issues.  The frameworks can be installed relatively easily with one of these open source package providers.</p>

<ul>
<li><a href="http://www.finkproject.org/" rel="nofollow">Fink</a></li>
<li><a href="http://www.macports.org/" rel="nofollow">MacPorts</a></li>
<li><a href="http://sourceforge.net/projects/mamp" rel="nofollow">MAMP</a></li>
</ul>
