Question: <p>I'm trying to debug a deadlock in a multi-threaded Python application after it has locked up.  Is there a way to attach a debugger to inspect the state of the process?  </p>

<p>Edit: I'm attempting this on Linux, but it would be great if there were a cross-platform solution.  It's Python after all :)</p>

Answer: <p><a href="https://www.jetbrains.com/pycharm/" rel="nofollow">PyCharm IDE</a> allows attaching to a running Python process since version 4.0. </p>

<p><a href="https://www.jetbrains.com/pycharm/help/attaching-to-process.html" rel="nofollow">Here</a> is described how to do that.</p>
