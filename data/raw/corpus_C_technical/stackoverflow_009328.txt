Answer: <p>Python is well suited for folding on indent, bit for writing my own code I use markers as they can crunch a document down the way you want it and can serve as a kind of a table of contents. I have this in my vimrc to flip between the two when I'm viewing someone elses code. </p>

<pre><code>#Toggle fold methods \fo
let g:FoldMethod = 0
map &lt;leader&gt;fo :call ToggleFold()&lt;cr&gt;
fun! ToggleFold()
    if g:FoldMethod == 0
        exe 'set foldmethod=indent'
        let g:FoldMethod = 1
    else
        exe 'set foldmethod=marker'
        let g:FoldMethod = 0
    endif
endfun
#Add markers (trigger on class Foo line)
nnoremap ,f2 ^wywO#&lt;c-r&gt;0 {{{2&lt;esc&gt;
nnoremap ,f3 ^wywO#&lt;c-r&gt;0 {{{3&lt;esc&gt; 
nnoremap ,f4 ^wywO#&lt;c-r&gt;0 {{{4&lt;esc&gt;
nnoremap ,f1 ^wywO#&lt;c-r&gt;0 {{{1&lt;esc&gt;
</code></pre>
