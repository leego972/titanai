Question: <p>It seems like there should be a simpler way than:</p>

<pre><code>import string
s = "string. With. Punctuation?" # Sample string 
out = s.translate(string.maketrans("",""), string.punctuation)
</code></pre>

<p>Is there?</p>

Answer: <p>Not necessarily simpler, but a different way, if you are more familiar with the re family. </p>

<pre><code>import re, string
s = "string. With. Punctuation?" # Sample string 
out = re.sub('[%s]' % re.escape(string.punctuation), '', s)
</code></pre>
