Question: <p>I'm looking for Python code that removes C and C++ comments from a string. (Assume the string contains an entire C source file.)</p>

<p>I realize that I could .match() substrings with a Regex, but that doesn't solve nesting <code>/*</code>, or having a <code>//</code> inside a <code>/* */</code>.</p>

<p>Ideally, I would prefer a non-naive implementation that properly handles awkward cases.</p>

Answer: <p>The regular expression cases will fall down in some situations, like where a string literal contains a subsequence which matches the comment syntax.  You really need a parse tree to deal with this.</p>
