Question: <p>I want to I check whether a string is in ASCII or not.</p>

<p>I am aware of <code>ord()</code>, however when I try <code>ord('Ã©')</code>, I have <code>TypeError: ord() expected a character, but string of length 2 found</code>. I understood it is caused by the way I built Python (as explained in <a href="http://docs.python.org/library/functions.html#ord"><code>ord()</code>'s documentation</a>). </p>

<p>Is there another way to check?</p>

Answer: <p>Vincent Marchetti has the right idea, but <code>str.decode</code> has been deprecated in Python 3.  In Python 3 you can make the same test with <code>str.encode</code>:</p>

<pre><code>try:
    mystring.encode('ascii')
except UnicodeEncodeError:
    pass  # string is not ascii
else:
    pass  # string is ascii
</code></pre>

<p>Note the exception you want to catch has also changed from <code>UnicodeDecodeError</code> to <code>UnicodeEncodeError</code>.</p>
