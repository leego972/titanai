Question: <p>I want to start using Python for small projects but the fact that a misplaced tab or indent can throw a compile error is really getting on my nerves. Is there some type of setting to turn this off?</p>

<p>I'm currently using NotePad++. Is there maybe an IDE that would take care of the tabs and indenting?</p>

Answer: <p>It's possible to write a pre-processor which takes randomly-indented code with pseudo-python keywords like "endif" and "endwhile" and properly indents things. I had to do this when using python as an "ASP-like" language, because the whole notion of "indentation" gets a bit fuzzy in such an environment.</p>

<p>Of course, even with such a thing you really ought to indent sanely, at which point the conveter becomes superfluous.</p>
