Question: <p>Say I have a blogging app in Django. How can i re-order the posts using a draggable table in the default admin?</p>

<p>It would be best if i didn't have to add any extra fields to the model, but if i really have to i can.</p>

Answer: <p>In model class you would probably have to add "order" field, to maintain specific order (eg. item with order = 10 is the last one and order = 1 is the first one). Then you can add a JS code in admin change_list template (see <a href="http://docs.djangoproject.com/en/dev/ref/contrib/admin/#modeladmin-media-definitions" rel="nofollow">this</a>) to maintain drag&amp;drop feature. Finally change ordering in Meta of model to something like ['order'].</p>
