Question: <p>How do I convert a datetime <em>string in local time</em> to a <em>string in UTC time</em>?</p>

<p>I'm sure I've done this before, but can't find it and SO will hopefully help me (and others) do that in future.</p>

<p><strong>Clarification</strong>:  For example, if I have <code>2008-09-17 14:02:00</code> in my local timezone (<code>+10</code>), I'd like to generate a string with the equivalent <code>UTC</code> time: <code>2008-09-17 04:02:00</code>.</p>

<p>Also, from <a href="http://lucumr.pocoo.org/2011/7/15/eppur-si-muove/">http://lucumr.pocoo.org/2011/7/15/eppur-si-muove/</a>, note that in general this isn't possible as with DST and other issues there is no unique conversion from local time to UTC time.</p>

Answer: <p>Here's a summary of common Python time conversions</p>

<ul>
<li>struct_time (UTC) â POSIX:<br><code>calendar.timegm(struct_time)</code></li>
<li>NaÃ¯ve datetime (local) â POSIX:<br><code>calendar.timegm(stz.localize(dt, is_dst=None).utctimetuple())</code></li>
<li>NaÃ¯ve datetime (UTC) â POSIX:<br><code>calendar.timegm(dt.utctimetuple())</code></li>
<li>Aware datetime â POSIX:<br><code>calendar.timegm(dt.utctimetuple())</code></li>
<li>POSIX â struct_time (UTC):<br><code>time.gmtime(t)</code></li>
<li>NaÃ¯ve datetime (local) â struct_time (UTC):<br><code>stz.localize(dt, is_dst=None).utctimetuple()</code></li>
<li>NaÃ¯ve datetime (UTC) â struct_time (UTC):<br><code>dt.utctimetuple()</code></li>
<li>Aware datetime â struct_time (UTC):<br><code>dt.utctimetuple()</code></li>
<li>POSIX â NaÃ¯ve datetime (local):<br><code>datetime.fromtimestamp(t, None)</code></li>
<li>struct_time (UTC) â NaÃ¯ve datetime (local):<br><code>datetime.datetime(struct_time[:6], tzinfo=UTC).astimezone(tz).replace(tzinfo=None)</code></li>
<li>NaÃ¯ve datetime (UTC) â NaÃ¯ve datetime (local):<br><code>dt.replace(tzinfo=UTC).astimezone(tz).replace(tzinfo=None)</code></li>
<li>Aware datetime â NaÃ¯ve datetime (local):<br><code>dt.astimezone(tz).replace(tzinfo=None)</code></li>
<li>POSIX â NaÃ¯ve datetime (UTC):<br><code>datetime.utcfromtimestamp(t)</code></li>
<li>struct_time (UTC) â NaÃ¯ve datetime (UTC):<br><code>datetime.datetime(struct_time[:6])</code></li>
<li>NaÃ¯ve datetime (local) â NaÃ¯ve datetime (UTC):<br><code>stz.localize(dt, is_dst=None).astimezone(UTC).replace(tzinfo=None)</code></li>
<li>Aware datetime â NaÃ¯ve datetime (UTC):<br><code>dt.astimezone(UTC).replace(tzinfo=None)</code></li>
<li>POSIX â Aware datetime:<br><code>datetime.fromtimestamp(t, tz)</code></li>
<li>struct_time (UTC) â Aware datetime:<br><code>datetime.datetime(struct_time[:6], tzinfo=UTC).astimezone(tz)</code></li>
<li>NaÃ¯ve datetime (local) â Aware datetime:<br><code>stz.localize(dt, is_dst=None)</code></li>
<li>NaÃ¯ve datetime (UTC) â Aware datetime:<br><code>dt.replace(tzinfo=UTC)</code></li>
</ul>
