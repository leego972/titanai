Question: <p>How can I find local IP addresses (i.e. 192.168.x.x or 10.0.x.x) in Python platform independently and using only the standard library?</p>

Answer: <p>One simple way to produce "clean" output via command line utils:</p>

<pre><code>import commands
ips = commands.getoutput("/sbin/ifconfig | grep -i \"inet\" | grep -iv \"inet6\" | " +
                         "awk {'print $2'} | sed -ne 's/addr\:/ /p'")
print ips
</code></pre>

<p>It will show all IPv4 addresses on the system.</p>
