Question: <p>Does beautiful soup work with iron python?
If so with which version of iron python?
How easy is it to distribute a windows desktop app on .net 2.0 using iron python (mostly c# calling some python code for parsing html)? </p>

Answer: <p>Regarding the second part of your question, you can use the DLR Hosting APIs to run IronPython code from within a C# application. The DLR hosting spec is <a href="http://compilerlab.members.winisp.net/dlr-spec-hosting.pdf" rel="nofollow">here</a>. This <a href="http://blogs.msdn.com/seshadripv/" rel="nofollow">blog</a> also contains some sample hosting applications</p>
