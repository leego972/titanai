Question: <p>I'm mainly a C# developer, but I'm currently working on a project in Python.</p>

<p>How can I represent the equivalent of an Enum in Python?  </p>

Answer: <p>Here is one implementation:</p>

<pre><code>class Enum(set):
    def __getattr__(self, name):
        if name in self:
            return name
        raise AttributeError
</code></pre>

<p>Here is its usage:</p>

<pre><code>Animals = Enum(["DOG", "CAT", "HORSE"])

print(Animals.DOG)
</code></pre>
