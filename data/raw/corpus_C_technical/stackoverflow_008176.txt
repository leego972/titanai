Question: <p>Is it possible? 
By debug I mean setting breakpoints, inspect values and advance step by step.</p>

Answer: <p>One can debug applications built on Web2py using the following set-up:</p>

<ol>
<li>Eclipse IDE</li>
<li>Install Pydev into Eclipse</li>
<li>Set Breakpoints on your code as needed</li>
<li>Within Eclipse right-click the file web2py.py and select Debug As -> Python Run</li>
<li>When a breakpoint is hit Eclipse will jump to the breakpoint where you can inspect variables and step thru the code</li>
</ol>
