Question: <p>I have a large source repository split across multiple projects. I would like to produce a report about the health of the source code, identifying problem areas that need to be addressed.</p>

<p>Specifically, I'd like to call out routines with a high cyclomatic complexity, identify repetition, and perhaps run some lint-like static analysis to spot suspicious (and thus likely erroneous) constructs.</p>

<p>How might I go about constructing such a report?</p>

Answer: <p>Thanks to <a href="http://pydev.org/" rel="nofollow">Pydev</a>, you can <a href="http://pydev.org/manual_adv_pylint.html" rel="nofollow">integrate pylint</a> in the <a href="http://www.eclipse.org/" rel="nofollow">Eclipse IDE</a> really easily and get a code report each time you save a modified file.</p>
