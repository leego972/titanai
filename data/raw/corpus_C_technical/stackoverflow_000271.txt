Question: <p>What's the best way to sanitise user input for a Python-based web application? Is there a single function to remove HTML characters and any other necessary characters combinations to prevent an <a href="http://en.wikipedia.org/wiki/Cross-site_scripting" rel="nofollow">XSS</a> or SQL injection attack?</p>

Answer: <p>Jeff Atwood himself described how StackOverflow.com sanitizes user input (in non-language-specific terms) on the Stack Overflow blog: <a href="http://blog.stackoverflow.com/2008/06/safe-html-and-xss/" rel="nofollow">http://blog.stackoverflow.com/2008/06/safe-html-and-xss/</a></p>

<p>However, as Justin points out, if you use Django templates or something similar then they probably sanitize your HTML output anyway.</p>

<p>SQL injection also shouldn't be a concern.  All of Python's database libraries (MySQLdb, cx_Oracle, etc) always sanitize the parameters you pass.  These libraries are used by all of Python's object-relational mappers (such as Django models), so you don't need to worry about sanitation there either.</p>
