Question: <p>I'd like to create a script to manipulate Apache2 configuration directly, reading and writing its properties (like adding a new VirtualHost, changing settings of one that already exists).</p>

<p>Are there any libs out there, for Perl, Python or Java that automates that task?</p>

Answer: <p>Look at <a href="http://augeas.net/" rel="nofollow">Augeas</a>, it's not specifically for Apache-httpd config. files it's just a generic config. file "editor" API. One of it's major selling points is that it will keep comments/etc. is happy for other tools to alter the files and will refuse to let you save broken files.</p>

<p>Also the fact that you can use the same API in all the languages you asked about, and that you can edit other config. files using the same APIs are both major advantages IMO.</p>
