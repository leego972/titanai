Question: <p>When I run a wxPython application, it prints the string &ldquo;Redirecting output to win32trace remote collector&rdquo;and I must open PythonWin's trace collector tool to view that trace output.</p>

<p>Since I'm not interested in collecting this output, how should I disable this feature?</p>

Answer: <p>You can even pass that when you instantiate your wx.App():</p>

<pre><code>if __name__ == "__main__":
    app = wx.App(redirect=False) #or 0
    app.MainLoop()
</code></pre>

<p><a href="http://wxpython.org/docs/api/wx.App-class.html#__init__" rel="nofollow">wxPython wx.App docs</a></p>
