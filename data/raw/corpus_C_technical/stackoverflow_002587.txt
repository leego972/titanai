Question: <p>How would a go about making a program where the user enters a string, and the program generates a list of words beginning with that string?</p>

<p>Ex:<br />
User: "abd"<br />
Program:abdicate, abdomen, abduct...</p>

<p>Thanks!</p>

<p><hr /></p>

<p>Edit:  I'm using python, but I assume that this is a fairly language-independent problem.</p>

Answer: <p>A linear scan is slow, but a prefix tree is probably overkill.  Keeping the words sorted and using a binary search is a fast and simple compromise.</p>

<pre><code>import bisect
words = sorted(map(str.strip, open('/usr/share/dict/words')))
def lookup(prefix):
    return words[bisect.bisect_left(words, prefix):bisect.bisect_right(words, prefix+'~')]

&gt;&gt;&gt; lookup('abdicat')
['abdicate', 'abdication', 'abdicative', 'abdicator']
</code></pre>
