Question: <p>I just installed a linux system (Kubuntu) and was wondering if there is a program to make python programs executable for linux.</p>

Answer: <p>Another way to do it could be by creating an alias.
For example in terminal write:</p>

<pre><code>alias printhello='python /home/hello_world.py'
</code></pre>

<p>Writing <code>printhello</code> will run hello_world.py, but this is only temporary.
To make aliases permanent, you have to add them to bashrc, you can edit it by writing this in the terminal:</p>

<pre><code>gedit ~/.bashrc
</code></pre>
