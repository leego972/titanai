Question: <p>Convert mysql timestamp to epoch time in python - is there an easy way to do this?</p>

Answer: <p>If you don't want to have MySQL do the work for some reason, then you can do this in Python easily enough.  When you get a datetime column back from MySQLdb, you get a Python datetime.datetime object.  To convert one of these, you can use time.mktime.  For example:</p>

<pre><code>import time
# Connecting to database skipped (also closing connection later)
c.execute("SELECT my_datetime_field FROM my_table")
d = c.fetchone()[0]
print time.mktime(d.timetuple())
</code></pre>
