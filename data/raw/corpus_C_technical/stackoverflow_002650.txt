Question: <p>One of the basic data structures in Python is the dictionary, which allows one to record "keys" for looking up "values" of any type.  Is this implemented internally as a hash table?  If not, what is it?</p>

Answer: <p>To expand upon nosklo's explanation:</p>

<pre><code>a = {}
b = ['some', 'list']
a[b] = 'some' # this won't work
a[tuple(b)] = 'some' # this will, same as a['some', 'list']
</code></pre>
