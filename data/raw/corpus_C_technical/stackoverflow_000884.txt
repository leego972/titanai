Question: <p>Using <a href="http://pyobjc.sourceforge.net/">PyObjC</a>, you can use Python to write Cocoa applications for OS X. Can I write native iPhone apps using Python and if so, how?</p>

Answer: <p><a href="http://omz-software.com/pythonista">Pythonista</a> has an Export to Xcode feature that allows you to export your Python scripts as Xcode projects that build standalone iOS apps.</p>
