Question: <p>For example, if passed the following:</p>

<pre><code>a = []
</code></pre>

<p>How do I check to see if <code>a</code> is empty?</p>

Answer: <pre><code>a = []

# First way
if a:
    print 'yes'
else:
    print 'no'

    print 'yes'
else:
    print 'no'
</code></pre>
