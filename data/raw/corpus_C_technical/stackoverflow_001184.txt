Question: <p>For example, if passed the following:</p>

<pre><code>a = []
</code></pre>

<p>How do I check to see if <code>a</code> is empty?</p>

Answer: <p>You can even try using bool() like this</p>

<pre><code>    a = [1,2,3];
    print bool(a); # it will return True
    a = [];
    print bool(a); # it will return False
</code></pre>
