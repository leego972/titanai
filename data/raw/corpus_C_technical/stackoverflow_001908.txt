Question: <p>How do I check whether a file exists, without using the <a href="https://docs.python.org/3.6/reference/compound_stmts.html#try"><code>try</code></a> statement?</p>

Answer: <pre><code>import os
path = /path/to/dir

root,dirs,files = os.walk(path).next()
if myfile in files:
   print "yes it exists"
</code></pre>

<p>This is helpful when checking for several files. Or you want to do a set intersection/ subtraction with an existing list.</p>
