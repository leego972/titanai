Question: <p>Is there a framework equivalent to Guice (<a href="http://code.google.com/p/google-guice">http://code.google.com/p/google-guice</a>) for Python?</p>

Answer: <p>There's dyject (<a href="http://dyject.com" rel="nofollow">http://dyject.com</a>), a lightweight framework for both Python 2 and Python 3 that uses the built-in ConfigParser</p>
