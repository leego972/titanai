Question: <p>I need to upload some data to a server using HTTP <code>PUT</code> in python. From my brief reading of the urllib2 docs, it only does HTTP <code>POST</code>. Is there any way to do an HTTP <code>PUT</code> in python?</p>

Answer: <p>I also recommend <a href="http://code.google.com/p/httplib2/" rel="nofollow">httplib2</a> by Joe Gregario.  I use this regularly instead of httplib in the standard lib.</p>
