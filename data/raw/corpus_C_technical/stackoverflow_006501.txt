Question: <p>Is there a good Java alternative to pyftpdlib? I am looking for an easy to setup and run embedded ftp server.</p>

Answer: <p>Check out Apache's <a href="http://mina.apache.org/ftpserver/" rel="nofollow">FTPServer</a>.</p>

<p>They have an <a href="http://mina.apache.org/ftpserver/embedding-ftpserver-in-5-minutes.html" rel="nofollow">example</a> of how to embed it in a Java application.</p>
