<p>Here is an (overcomplicated?) example.  If people have a simpler one that demos it, I'd like to hear it.   The issue:  the list comprehensions using next() are filled with the result from the last iteration.  </p>

Answer: <p>The problem is that with <code>return self.display</code> you return a <em>reference</em> to this list (not a copy). So what you end up with is a list where each element is a reference to self.display. To illustrate, look at the following:</p>

<pre><code>&gt;&gt;&gt; a = [1,2]
&gt;&gt;&gt; b = [a,a]
&gt;&gt;&gt; b
[[1, 2], [1, 2]]
&gt;&gt;&gt; a.append(3)
&gt;&gt;&gt; b
[[1, 2, 3], [1, 2, 3]]
</code></pre>

<p>You probably want to use something like <code>return self.display[:]</code>.</p>
