Question: <p>In Python for the *nix, does <code>time.sleep()</code> block the thread or the process?</p>

Answer: <p>It will just sleep the thread except in the case where your application has only a single thread, in which case it will sleep the thread and effectively the process as well.</p>

<p>The python documentation on sleep doesn't specify this however, so I can certainly understand the confusion!</p>
