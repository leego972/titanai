Question: <p>i am trying to do something with the PIL Image library in django, but i experience some problems.</p>

<p>I do like this:</p>

<p><code>
import Image
</code></p>

<p>And then I do like this</p>

<p><code>
images = map(Image.open, glob.glob(os.path.join(dirpath, '*.thumb.jpg')))
</code></p>

<p>But when i try to run this i get an error and it leeds me to think that its not imported correctly, anybody know?</p>

<p><code>
type object 'Image' has no attribute 'open'
</code></p>

Answer: <p>The error above happens because your file is called Image.py and you're trying to import yourself. As Manual pointed out, you should import Image from the PIL module, but you'd also need to rename your file so it's <em>not</em> called Image.py.</p>
