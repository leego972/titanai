Question: <p>This is a question I have wondered about for quite some time, yet I have never found a suitable solution. If I run a script and I come across, let's say an IndexError, python prints the line, location and quick description of the error and exits. Is it possible to automatically start pdb when an error is encountered? I am not against having an extra import statement at the top of the file, nor a few extra lines of code.</p>

Answer: <p>IPython makes this simple on the command line:</p>

<pre><code>python myscript.py arg1 arg2
</code></pre>

<p>can be rewritten to</p>

<pre><code>ipython --pdb myscript.py -- arg1 arg2
</code></pre>

<p>Or, similarly, if calling a module:</p>

<pre><code>python -m mymodule arg1 arg2
</code></pre>

<p>can be rewritten to</p>

<pre><code>ipython --pdb -m mymodule -- arg1 arg2
</code></pre>

<p>Note the <code>--</code> to stop IPython from reading the script's arguments as its own.</p>

<p>This also has the advantage of invoking the enhanced IPython debugger (ipdb) instead of pdb.</p>
