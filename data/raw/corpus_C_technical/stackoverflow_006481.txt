Question: <p>Is there a UI library to create a message box or input box in python?</p>

Answer: <p>Simple message boxes and input boxes can be created using EasyGui, a small library using Tkinter, which Python comes with.</p>

<p>You can get EasyGui here: <a href="http://easygui.sourceforge.net/" rel="nofollow">http://easygui.sourceforge.net/</a></p>
