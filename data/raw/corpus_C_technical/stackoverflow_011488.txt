Question: <p>How can I load a Python module given its full path? Note that the file can be anywhere in the filesystem, as it is a configuration option.</p>

Answer: <p>Here is some code that works in all Python versions, from 2.7-3.5 and probably even others.</p>

<pre><code>config_file = "/tmp/config.py"
with open(config_file) as f:
    code = compile(f.read(), config_file, 'exec')
    exec(code, globals(), locals())
</code></pre>

<p>I tested it. It may be ugly but so far is the only one that works in all versions.</p>
