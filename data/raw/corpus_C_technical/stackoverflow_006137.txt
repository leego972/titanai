Question: <p>I want to create a list of integers from 1 to n. I can do this in Python using range(1, n+1), and in Haskell using: take n (iterate (1+) 1). </p>

<p>What is the right OCaml idiom for this?</p>

Answer: <p>OCaml has special syntax for pattern matching on ranges:</p>

<pre><code>let () =
  let my_char = 'a' in
  let is_lower_case = match my_char with
  | 'a'..'z' -&gt; true (* Two dots define a range pattern *)
  | _ -&gt; false
  in
  printf "result: %b" is_lower_case
</code></pre>

<p>To create a range, you can use <a href="https://github.com/janestreet/core" rel="nofollow"><code>Core</code></a>:</p>

<pre><code>List.range 0 1000
</code></pre>
