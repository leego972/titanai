Question: <p>It seems</p>

<pre><code>import Queue

Queue.Queue().get(timeout=10)
</code></pre>

<p>is keyboard interruptible (ctrl-c) whereas</p>

<pre><code>import Queue

Queue.Queue().get()
</code></pre>

<p>is not. I could always create a loop;</p>

<pre><code>import Queue
q = Queue()

while True:
    try:
        q.get(timeout=1000)
    except Queue.Empty:
        pass
</code></pre>

<p>but this seems like a strange thing to do.</p>

<p>So, is there a way of getting an indefinitely waiting but keyboard interruptible Queue.get()?</p>

Answer: <p>This may not apply to your use case at all. But I've successfully used this pattern in several cases: (sketchy and likely buggy, but you get the point).</p>

<pre><code>STOP = object()

def consumer(q):
    while True:
        x = q.get()
        if x is STOP:
            return
        consume(x)

def main()
    q = Queue()
    c=threading.Thread(target=consumer,args=[q])

    try:
        run_producer(q)
    except KeybordInterrupt:
        q.enqueue(STOP)
    c.join()
</code></pre>
