Question: <p>I am learning Python for a class now, and we just covered tuples as one of the data types. I read the Wikipedia page on it, but, I could not figure out where such a data type would be useful in practice. Can I have some examples, perhaps in Python, where an immutable set of numbers would be needed? How is this different from a list?</p>

Answer: <p>A tuple is a sequence of values. The values can be any type, and they are indexed by integer, so tuples are not like lists. The most important difference is that <strong>tuples are immutable.</strong></p>

<p>A tuple is a comma-separated list of values:</p>

<pre><code>t = 'p', 'q', 'r', 's', 't'
</code></pre>

<p>it is good practice to enclose tuples in parentheses:</p>

<pre><code>t = ('p', 'q', 'r', 's', 't') 
</code></pre>
