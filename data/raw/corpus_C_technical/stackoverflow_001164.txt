Question: <p>For example, if passed the following:</p>

<pre><code>a = []
</code></pre>

<p>How do I check to see if <code>a</code> is empty?</p>

Answer: <p>An empty list is itself considered false in true value testing (see <a href="https://docs.python.org/2/library/stdtypes.html#truth-value-testing">python documentation</a>):</p>

<pre><code>a = []
if a:
     print "not empty"
</code></pre>
