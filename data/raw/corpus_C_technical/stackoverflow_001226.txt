Question: <p>I use Emacs primarily for coding Python but sometimes I use IDLE. Is there a way to change the key bindings easily in IDLE to match Emacs?</p>

Answer: <p>There's a program for Windows called XKeymacs that allows you to specify emacs keybindings for different programs.  It should work with IDLE.</p>
