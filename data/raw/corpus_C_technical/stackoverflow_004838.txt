Question: <p>So what I'm looking for here is something like <a href="http://us2.php.net/print_r">PHP's print_r</a> function. This is so I can debug my scripts by seeing what's the state of the object in question.</p>

Answer: <p>Try <a href="https://github.com/symonsoft/ppretty" rel="nofollow">ppretty</a></p>

<pre><code>from ppretty import ppretty


class A(object):
    s = 5

    def __init__(self):
        self._p = 8

    @property
    def foo(self):
        return range(10)


print ppretty(A(), show_protected=True, show_static=True, show_properties=True)
</code></pre>

<p>Output:</p>

<pre><code>__main__.A(_p = 8, foo = [0, 1, ..., 8, 9], s = 5)
</code></pre>
