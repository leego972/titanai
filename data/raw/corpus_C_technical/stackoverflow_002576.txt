Question: <p>How would a go about making a program where the user enters a string, and the program generates a list of words beginning with that string?</p>

<p>Ex:<br />
User: "abd"<br />
Program:abdicate, abdomen, abduct...</p>

<p>Thanks!</p>

<p><hr /></p>

<p>Edit:  I'm using python, but I assume that this is a fairly language-independent problem.</p>

Answer: <p>Try using regex to search through your list of words, e.g. /^word/ and report all matches.</p>
