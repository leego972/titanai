Question: <p>How do I connect to a MySQL database using a python program?</p>

Answer: <p>Oracle (MySQL) now supports a pure Python connector.  That means no binaries to install: it's just a Python library.  It's called "Connector/Python".  </p>

<p><a href="http://dev.mysql.com/downloads/connector/python/">http://dev.mysql.com/downloads/connector/python/</a></p>
