Question: <p>In python, is there a difference between calling <code>clear()</code> and assigning <code>{}</code> to a dictionary? If yes, what is it?
Example:<pre><code>d = {"stuff":"things"}
d.clear()   #this way
d = {}      #vs this way
</code></pre></p>

Answer: <p><em>Mutating</em> methods are always useful if the original object is not in scope:</p>

<pre><code>def fun(d):
    d.clear()
    d["b"] = 2

d={"a": 2}
fun(d)
d          # {'b': 2}
</code></pre>

<p>Re-assigning the dictionary would create a new object and wouldn't modify the original one.</p>
