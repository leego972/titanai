Question: <p>How can I call an external command (as if I'd typed it at the Unix shell or Windows command prompt) from within a Python script?</p>

Answer: <p>Here is calling a external command and return or print commands output.</p>

<p>Python <a href="https://docs.python.org/2/library/subprocess.html" rel="nofollow">Subprocess</a> check_output is good for </p>

<blockquote>
  <p>Run command with arguments and return its output as a byte string.</p>
</blockquote>

<pre><code>import subprocess
proc = subprocess.check_output('ipconfig /all')
print proc
</code></pre>
