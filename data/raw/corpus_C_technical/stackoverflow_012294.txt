Question: <p>I need to package my python application, its dependencies and python into a single MSI installer. The end result should desirably be:</p>

<ul>
<li>Python is installed in the standard location</li>
<li>the package and its dependencies are installed in a separate directory (possibly site-packages)</li>
<li>the installation directory should contain the python uncompressed and a standalone executable is not required</li>
</ul>

Answer: <p><a href="http://wiki.python.org/moin/Py2Exe" rel="nofollow">py2exe</a> will make windows executables with python bundled in.</p>
