Question: <p>Can you add new statements (like <code>print</code>, <code>raise</code>, <code>with</code>) to Python's syntax?</p>

<p>Say, to allow..</p>

<pre><code>mystatement "Something"
</code></pre>

<p>Or,</p>

<pre><code>new_if True:
    print "example"
</code></pre>

<p>Not so much if you <em>should</em>, but rather if it's possible (short of modifying the python interpreters code)</p>

Answer: <p>Yes, to some extent it is possible. There is a <a href="http://entrian.com/goto/">module</a> out there that uses <code>sys.settrace()</code> to implement <code>goto</code> and <code>comefrom</code> "keywords":</p>

<pre><code>from goto import goto, label
for i in range(1, 10):
  for j in range(1, 20):
    print i, j
    if j == 3:
      goto .end # breaking out from nested loop
label .end
print "Finished"
</code></pre>
