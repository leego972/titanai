Question: <p>How would a go about making a program where the user enters a string, and the program generates a list of words beginning with that string?</p>

<p>Ex:<br />
User: "abd"<br />
Program:abdicate, abdomen, abduct...</p>

<p>Thanks!</p>

<p><hr /></p>

<p>Edit:  I'm using python, but I assume that this is a fairly language-independent problem.</p>

Answer: <p>Don't use a bazooka to kill a fly. Use something simple just like SQLite. There are all the tools you need for every modern languages and you can just do :</p>

<pre><code>"SELECT word FROM dict WHERE word LIKE "user_entry%"
</code></pre>

<p>It's lightning fast and a baby could do it. What's more it's portable, persistent and so easy to maintain.</p>
