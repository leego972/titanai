Question: <p>When you call the <code>object.__repr__()</code> method in python you get something like this back: <code>&lt;__main__.Test object at 0x2aba1c0cf890&gt;</code>, is there any way to get a hold of the memory address if you overload <code>__repr__()</code>, other then calling <code>super(Class, obj).__repr__()</code> and regexing it out? </p>

Answer: <p>You could reimplement the default repr this way:</p>

<pre><code>def __repr__(self):
    return '&lt;%s.%s object at %s&gt;' % (
        self.__class__.__module__,
        self.__class__.__name__,
        hex(id(self))
    )
</code></pre>
