Question: <p>Markdown is a great tool for formatting plain text into pretty html, but it doesn't turn plain-text links into URLs automatically. Like this one:</p>

<p><a href="http://www.google.com/" rel="nofollow">http://www.google.com/</a></p>

<p>How do I get markdown to add  tags to URLs when I format a block of text?</p>

Answer: <p>Best case scenario, edit the markdown and just put &lt; > around the URLs. This will make the link clickable. Only problem is it requires educating your users, or whoever writes the markdown.</p>
