Question: <p>I have this Python application that gets stuck from time to time and I can't find out where.</p>

<p>Is there any way to signal Python interpreter to show you the exact code that's running? </p>

<p>Some kind of on-the-fly stacktrace?</p>

Answer: <p>It's worth looking at <a href="http://bashdb.sourceforge.net/pydb/" rel="nofollow">Pydb</a>, "an expanded version of the Python debugger loosely based on the gdb command set". It includes signal managers which can take care of starting the debugger when a specified signal is sent.</p>

<p>A 2006 Summer of Code project looked at adding remote-debugging features to pydb in a module called <a href="http://svn.python.org/projects/sandbox/trunk/pdb/" rel="nofollow">mpdb</a>. </p>
