Question: <p>For some reason I can't find a way to get the equivalents of sqlite's interactive shell commands:</p>

<pre><code>.tables
.dump
</code></pre>

<p>using the Python sqlite3 API. </p>

<p>Is there anything like that?</p>

Answer: <p>I've implemented a sqlite table schema parser in PHP, you may check here: <a href="https://github.com/c9s/LazyRecord/blob/master/src/LazyRecord/TableParser/SqliteTableDefinitionParser.php" rel="nofollow">https://github.com/c9s/LazyRecord/blob/master/src/LazyRecord/TableParser/SqliteTableDefinitionParser.php</a></p>

<p>You can use this definition parser to parse the definitions like the code below:</p>

<pre><code>$parser = new SqliteTableDefinitionParser;
$parser-&gt;parseColumnDefinitions('x INTEGER PRIMARY KEY, y DOUBLE, z DATETIME default \'2011-11-10\', name VARCHAR(100)');
</code></pre>
