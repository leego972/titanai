Question: <p>How do I connect to Gmail and determine which messages have attachments?  I then want to download each attachment, printing out the Subject: and From: for each message as I process it.</p>

Answer: <p>For Java, you will find <a href="http://g4j.sourceforge.net/" rel="nofollow">G4J</a> of use. It's a set of APIs to communicate with Google Mail via Java (the screenshot on the homepage is a demonstration email client built around this)</p>
