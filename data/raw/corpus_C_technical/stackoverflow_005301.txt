Question: <p>When using <code>__import__</code> with a dotted name, something like: <code>somepackage.somemodule</code>, the module returned isn't <code>somemodule</code>, whatever is returned seems to be mostly empty! what's going on here?</p>

Answer: <p>There is something that works as you want it to: <code>twisted.python.reflect.namedAny</code>:</p>

<pre><code>&gt;&gt;&gt; from twisted.python.reflect import namedAny
&gt;&gt;&gt; namedAny("operator.eq")
&lt;built-in function eq&gt;
&gt;&gt;&gt; namedAny("pysqlite2.dbapi2.connect")
&lt;built-in function connect&gt;
&gt;&gt;&gt; namedAny("os")
&lt;module 'os' from '/usr/lib/python2.5/os.pyc'&gt;
</code></pre>
