Question: <p>I'm trying to format numbers. Examples:</p>

<pre><code>1     =&gt; 1
12    =&gt; 12
123   =&gt; 123
1234  =&gt; 1,234
12345 =&gt; 12,345
</code></pre>

<p>It strikes as a fairly common thing to do but I can't figure out which filter I'm supposed to use.</p>

<p>Edit: If you've a generic Python way to do this, I'm happy adding a formatted field in my model.</p>

Answer: <p>Well I couldn't find a Django way, but I did find a python way from inside my model:</p>

<pre><code>def format_price(self):
    import locale
    locale.setlocale(locale.LC_ALL, '')
    return locale.format('%d', self.price, True)
</code></pre>
