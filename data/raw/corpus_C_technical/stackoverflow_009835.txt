Question: <p>I am writing a program in Python, and I realized that a problem I need to solve requires me, given a set <code>S</code> with <code>n</code> elements (|S|=n), to test a function on all possible subsets of a certain order <code>m</code> (i.e. with <em>m</em> number of elements). To use the answer to produce a partial solution, and then try again with the next order m=m+1, until m=n.</p>

<p>I am on my way to write a solution of the form:</p>

<pre><code>def findsubsets(S, m):
    subsets = set([])
    ...
    return subsets
</code></pre>

<p>But knowing Python I expected a solution to be already there.</p>

<p>What is the best way to accomplish this?</p>

Answer: <p>Using the canonical function to get the <a href="http://en.wikipedia.org/wiki/Power_set">powerset</a> from the <a href="http://docs.python.org/2/library/itertools.html#recipes">the itertools recipe</a> page:</p>

<pre><code>from itertools import chain, combinations

def powerset(iterable):
  xs = list(iterable)
  # note we return an iterator rather than a list
  return chain.from_iterable( combinations(xs,n) for n in range(len(xs)+1) )
</code></pre>

<p>Used like:</p>

<pre><code>&gt;&gt;&gt; list(powerset("abc"))
[(), ('a',), ('b',), ('c',), ('a', 'b'), ('a', 'c'), ('b', 'c'), ('a', 'b', 'c')]

&gt;&gt;&gt; list(powerset(set([1,2,3])))
[(), (1,), (2,), (3,), (1, 2), (1, 3), (2, 3), (1, 2, 3)]
</code></pre>

<p>map to sets if you want so you can use union, intersection, etc...:</p>

<pre><code>&gt;&gt;&gt; map(set, powerset(set([1,2,3])))
[set([]), set([1]), set([2]), set([3]), set([1, 2]), set([1, 3]), set([2, 3]), set([1, 2, 3])]

&gt;&gt;&gt; reduce(lambda x,y: x.union(y), map(set, powerset(set([1,2,3]))))
set([1, 2, 3])
</code></pre>
