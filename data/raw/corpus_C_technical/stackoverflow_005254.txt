Question: <p>I currently do my textfile manipulation through a bunch of badly remembered AWK, sed, Bash and a tiny bit of Perl.</p>

<p>I've seen mentioned a few places that python is good for this kind of thing, I know a little and I would like to know more. Is Python a good choice for this, and is there a good book or guide to learning how to use Python to replace shell scripting, AWK, sed and friends?</p>

Answer: <p>While researching this topic, I found <a href="http://hg.mozilla.org/users/tmielczarek_mozilla.com/pyshell/file/tip/shell.py" rel="nofollow">this proof-of-concept code</a> (via a comment at <a href="http://jlebar.com/2010/2/1/Replacing_Bash.html" rel="nofollow">http://jlebar.com/2010/2/1/Replacing_Bash.html</a>) that lets you "write shell-like pipelines in Python using a terse syntax, and leveraging existing system tools where they make sense":</p>

<pre><code>for line in sh("cat /tmp/junk2") | cut(d=',',f=1) | 'sort' | uniq:
    sys.stdout.write(line)
</code></pre>
