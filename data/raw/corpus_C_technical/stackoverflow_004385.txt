Question: <p>I've discovered that cElementTree is about 30 times faster than <code>xml.dom.minidom</code> and I'm rewriting my XML encoding/decoding code. However, I need to output XML that contains CDATA sections and there doesn't seem to be a way to do that with ElementTree.</p>

<p>Can it be done?</p>

Answer: <p>The accepted solution cannot work with <strong>Python 2.7</strong>. However, there is another package called <a href="http://lxml.de/" rel="nofollow">lxml</a> which (though slightly slower) shared a largely identical syntax with the <code>xml.etree.ElementTree</code>. <code>lxml</code> is able to both write and parse <code>CDATA</code>. Documentation <a href="http://lxml.de/" rel="nofollow">here</a></p>
