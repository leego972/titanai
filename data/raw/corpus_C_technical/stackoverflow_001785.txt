Question: <p>Why is it bad to name a variable <code>id</code> in Python?</p>

Answer: <p>Because python is a dynamic language, it's not usually a good idea to give a variable and a function the same name.  id() is a function in python, so it's recommend not to use a variable named id.  Bearing that in mind, that applies to all functions that you might use... a variable shouldn't have the same name as a function.</p>
