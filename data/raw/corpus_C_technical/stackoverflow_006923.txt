Question: <p>If I type this line in an MS-DOS command prompt window:  </p>

<pre><code>ipy -X:ColorfulConsole
</code></pre>

<p>IronPython starts up as expected with the colorful console option enabled. However, if I type the same line in Windows PowerShell I get the message:  </p>

<pre><code>File -X: does not exist
</code></pre>

<p>Can someone explain what I'm doing wrong?</p>

Answer: <p>try:</p>

<pre><code>ipy '-X:ColorfulConsole'
</code></pre>

<p>Or whatever quoting mechanism is supported in Windows PowerShell - the shell is splitting your argument. </p>

<p>Typing</p>

<pre><code>ipy -X: ColorfulConsole
</code></pre>

<p>in MS-DOS command prompt window returns same response <code>File -X: does not exist</code>.</p>
