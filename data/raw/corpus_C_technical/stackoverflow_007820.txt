Question: <p>The Python <a href="http://www.python.org/doc/2.5.2/lib/datetime-datetime.html"><code>datetime.isocalendar()</code></a> method returns a tuple <code>(ISO_year, ISO_week_number, ISO_weekday)</code> for the given <code>datetime</code> object.  Is there a corresponding inverse function?  If not, is there an easy way to compute a date given a year, week number and day of the week?</p>

Answer: <p>For the next people coming here,  a shorter, single-def, version of Ben's good solution:</p>

<pre><code>def iso_to_gregorian(iso_year, iso_week, iso_day):
    jan4 = datetime.date(iso_year, 1, 4)
    start = jan4 - datetime.timedelta(days=jan4.isoweekday()-1)
    return start + datetime.timedelta(weeks=iso_week-1, days=iso_day-1)
</code></pre>
