Question: <p>I have got a python script which is creating an ODBC connection. The ODBC connection is generated with a connection string. In this connection string I have to include the username and password for this connection.  </p>

<p>Is there an easy way to obscure this password in the file (just that nobody can read the password when I'm editing the file) ? </p>

Answer: <p>base64 is the way to go for your simple needs. There is no need to import anything:</p>

<pre><code>&gt;&gt;&gt; 'your string'.encode('base64')
'eW91ciBzdHJpbmc=\n'
&gt;&gt;&gt; _.decode('base64')
'your string'
</code></pre>
