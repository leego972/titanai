Question: <p>How do you change the size of figure drawn with matplotlib?</p>

Answer: <p>In case you're looking for a way to change the figure size in Pandas, you could do e.g.:</p>

<pre><code>df['some_column'].plot(figsize=(10, 5))
</code></pre>

<p>where <code>df</code> is a Pandas dataframe. If you want to change the default settings, you could do the following:</p>

<pre><code>import pandas as pd

# update 'default' stylesheet
pd.tools.plotting.mpl_stylesheet['figure.figsize'] = (10.0, 5.0)

# start using the 'default' style sheet (not used by default)
pd.set_option('display.mpl_style', 'default')
</code></pre>
