Question: <p>I'm writing a shell for a project of mine, which by design parses commands that looks like this:</p>

<p>COMMAND_NAME ARG1="Long Value" ARG2=123 ARG3=me@me.com</p>

<p>My problem is that Python's command line parsing libraries (getopt and optparse) forces me to use '-' or '--' in front of the arguments. This behavior doesn't match my requirements.</p>

<p>Any ideas how can this be solved? Any existing library for this?</p>

Answer: <p>Little late to the party... but <a href="http://www.python.org/dev/peps/pep-0389/" rel="nofollow">PEP 389</a> allows for this and much more.</p>

<p>Here's a little nice library should your version of Python need it code.google.com/p/argparse</p>

<p>Enjoy.</p>
