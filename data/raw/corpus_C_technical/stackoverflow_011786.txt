Question: <p>Is there a c# library which provides similar functionality to the <a href="http://wiki.wxpython.org/PubSub" rel="nofollow">Python PubSub</a> library? I think it's kind of an Observer Pattern which allows me to subscribe for messages of a given topic instead of using events.</p>

Answer: <p>Note, if you have events for message notification, there are many options for dependancy injection / inversion of control.  See <a href="http://www.springframework.net/" rel="nofollow">Spring.Net</a> and <a href="http://www.castleproject.org/container/" rel="nofollow">Castle Windsor</a> as two popular frameworks.</p>
