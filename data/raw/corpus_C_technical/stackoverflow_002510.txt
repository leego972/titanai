<p>It would be best if i didn't have to add any extra fields to the model, but if i really have to i can.</p>

Answer: <p>There's a nice package for ordering admin objects these days</p>

<p><a href="https://github.com/iambrandontaylor/django-admin-sortable" rel="nofollow">https://github.com/iambrandontaylor/django-admin-sortable</a></p>
