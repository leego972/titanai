Question: <p>I would like to trim long sequences of the same value from a binary file in python. A simple way of doing it is simply reading in the file and using re.sub to replace the unwanted sequence. This will of course not work on large binary files. Can it be done in something like numpy?</p>

Answer: <p>You need to make your question more precise.  Do you know the values you want to trim ahead of time?</p>

<p>Assuming you do, I would probably search for the matching sections using <code>subprocess</code> to run "<code>fgrep -o -b &lt;search string&gt;</code>" and then change the relevant sections of the file using the python <code>file</code> object's <code>seek</code>, <code>read</code> and <code>write</code> methods.</p>
