Question: <p>How do I have a Python script that can accept user input (assuming this is possible) and how do I make it read in arguments if run from the command line?</p>

Answer: <p>The best way to process command line arguments is the <a href="https://docs.python.org/library/argparse.html" rel="nofollow"><code>argparse</code> module.</a></p>

<p>Use <code>raw_input()</code> to get user input.  If you import the <a href="https://docs.python.org/library/readline.html" rel="nofollow"><code>readline module</code></a> your users will have line editing and history.</p>
