Question: <p>I'm writing a python script that executes a csh script in Solaris 10. The csh script prompts the user for the root password (which I know) but I'm not sure how to make the python script answer the prompt with the password. Is this possible? Here is what I'm using to execute the csh script:</p>

<pre><code>import commands

commands.getoutput('server stop')
</code></pre>

Answer: <p>Should be able to pass it as a parameter.  something like:</p>

<pre><code>commands.getoutput('server stop -p password')
</code></pre>
