Question: <p>For some reason I can't find a way to get the equivalents of sqlite's interactive shell commands:</p>

<pre><code>.tables
.dump
</code></pre>

<p>using the Python sqlite3 API. </p>

<p>Is there anything like that?</p>

Answer: <p>After a lot of fiddling I found a better answer at <a href="http://www.sqlite.org/pragma.html#pragma_table_info" rel="nofollow">sqlite docs</a> for listing the metadata for the table, even attached databases. </p>

<pre><code>meta = cursor.execute("PRAGMA table_info('Job')")
for r in meta:
    print r
</code></pre>

<p>The key information is to prefix table_info, not my_table with the attachment handle name.</p>
