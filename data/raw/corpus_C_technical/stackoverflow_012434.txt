Question: <p>How do I end a Tkinter program? Let's say I have this code:</p>

<pre><code>from Tkinter import *

def quit():
    # code to exit

root = Tk()
Button(root, text="Quit", command=quit).pack()
root.mainloop()
</code></pre>

<p>How should I define the <code>quit</code> function?</p>

Answer: <p>try this. </p>

<pre><code>    self.parent.destroy() 
    self.parent.quit()
</code></pre>

<p>maybe you send root like parameter to a frame that you did. so If you want to finish it you have to call your father so he can close it all, instead of closing each one of his children. </p>
