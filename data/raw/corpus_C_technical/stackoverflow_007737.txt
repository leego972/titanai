Question: <p>We have developers with knowledge of these languages - Ruby , Python, .Net or Java. We are developing an application which will mainly handle XML documents. Most of the work is to convert predefined XML files into database tables, providing mapping between XML documents through database, creating reports from database etc. Which language will be the easiest and fastest to work with?
(It is a web-app)</p>

Answer: <p>An interesting solution could be Ruby.
Simply use XML->Object mappers and then use an object-relational-mapper (ORM) to put it inside a database.
I had to do a short talk on XML Mapping with ruby, you could look at the slides and see what you like best: <a href="http://www.marc-seeger.de/2008/11/25/ruby-xml-mapping/" rel="nofollow">http://www.marc-seeger.de/2008/11/25/ruby-xml-mapping/</a></p>

<p>As for the ORM: Active Record or Datamapper should be the way to go</p>
