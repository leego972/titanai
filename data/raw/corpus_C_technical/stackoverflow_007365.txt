Question: <p>Should I start a Python program with:</p>

<pre><code>if__name__ == '__main__':
some code...
</code></pre>

<p>And if so, why? I saw it many times but don't have a clue about it.</p>

Answer: <p>Guido Van Rossum <a href="http://www.artima.com/weblogs/viewpost.jsp?thread=4829">suggests</a>:</p>

<pre><code>def main(argv=None):
  if argv is None:
    argv = sys.argv
  ...

if __name__ == "__main__":
    sys.exit(main())
</code></pre>

<p>This way you can run <code>main()</code> from somewhere else (supplying the arguments), and if you want to exit with an error code just <code>return 1</code> from <code>main()</code>, and it won't make an interactive interpreter exit by mistake.</p>
