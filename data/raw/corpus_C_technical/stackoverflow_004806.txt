<p>In a nutshell, how should we convert XML to JSON using Python?</p>

Answer: <p>There is a method to transport XML-based markup as JSON which allows it to be losslessly converted back to its original form. See <a href="http://jsonml.org/" rel="nofollow">http://jsonml.org/</a>. </p>
