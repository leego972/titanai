Question: <p>I've got this date time string:</p>

<pre><code>post["date"] = "2007-07-18 10:03:19"
</code></pre>

<p>I'd like to extract just "2007-07-18" as a date. I've seen some reference to <code>strptime</code> but I'm not sure how to use it.  How can I extract the date from this string?</p>

Answer: <p>You can use the <a href="http://pypi.python.org/pypi/parsedatetime/" rel="nofollow">parsedatetime</a> module.</p>

<pre><code>&gt;&gt;&gt; from parsedatetime.parsedatetime import Calendar
&gt;&gt;&gt; c = Calendar()
&gt;&gt;&gt; c.parse("2007-07-18 10:03:19")
((2008, 11, 19, 10, 3, 19, 2, 324, 0), 2)
</code></pre>
