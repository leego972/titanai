Question: <p>For some reason I can't find a way to get the equivalents of sqlite's interactive shell commands:</p>

<pre><code>.tables
.dump
</code></pre>

<p>using the Python sqlite3 API. </p>

<p>Is there anything like that?</p>

Answer: <p>Apparently the version of sqlite3 included in Python 2.6 has this ability: <a href="http://docs.python.org/dev/library/sqlite3.html">http://docs.python.org/dev/library/sqlite3.html</a></p>

<pre><code># Convert file existing_db.db to SQL dump file dump.sql
import sqlite3, os

con = sqlite3.connect('existing_db.db')
with open('dump.sql', 'w') as f:
    for line in con.iterdump():
        f.write('%s\n' % line)
</code></pre>
