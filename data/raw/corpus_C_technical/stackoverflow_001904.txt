Question: <p>How do I check whether a file exists, without using the <a href="https://docs.python.org/3.6/reference/compound_stmts.html#try"><code>try</code></a> statement?</p>

Answer: <p>Unlike <a href="http://docs.python.org/3.3/library/os.path.html?highlight=os.path#os.path.isfile"><code>isfile()</code></a>, <a href="http://docs.python.org/3.3/library/os.path.html?highlight=os.path#os.path.exists"><code>exists()</code></a> will yield <em>True</em> for directories.<br>
So depending on if you want only plain files or also directories, you'll use <code>isfile()</code> or <code>exists()</code>. Here is a simple REPL output.</p>

<pre><code>&gt;&gt;&gt; print os.path.isfile("/etc/password.txt")
True
&gt;&gt;&gt; print os.path.isfile("/etc")
False
&gt;&gt;&gt; print os.path.isfile("/does/not/exist")
False
&gt;&gt;&gt; print os.path.exists("/etc/password.txt")
True
&gt;&gt;&gt; print os.path.exists("/etc")
True
&gt;&gt;&gt; print os.path.exists("/does/not/exist")
False
</code></pre>
