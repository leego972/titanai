Answer: <p>As a work-around, you could set the zip_ok option to false so that your project is installed as an unzipped directory, then it will be a little easier for your users to find the editor config file.</p>

<p>In distutils2, it will be possible to install things to more directories, including custom directories, and to have pre/post-install/remove hooks.</p>
