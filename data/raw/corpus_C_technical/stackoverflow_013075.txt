Question: <p>How does one write a unittest that fails only if a function doesn't throw an expected exception?</p>

Answer: <p>You can build your own <code>contextmanager</code> to check if the exception was raised.</p>

<pre><code>import contextlib

@contextlib.contextmanager
def raises(exception):
    try:
        yield 
    except exception as e:
        assert True
    else:
        assert False
</code></pre>

<p>And then you can use <code>raises</code> like this:</p>

<pre><code>with raises(Exception):
    print "Hola"  # Calls assert False

with raises(Exception):
    raise Exception  # Calls assert True
</code></pre>

<p>If you are using <code>pytest</code>, this thing is implemented already. You can do <code>pytest.raises(Exception)</code>:</p>

<p>Example:</p>

<pre><code>def test_div_zero():
    with pytest.raises(ZeroDivisionError):
        1/0
</code></pre>
