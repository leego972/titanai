Question: <p>I need to run a simple request/response python module under an
existing system with windows/apache/FastCGI.</p>

<p>All the FastCGI wrappers for python I tried work for Linux only
(they use socket.fromfd() and other such shticks).</p>

<p>Is there a wrapper that runs under windows?</p>

Answer: <p>A <a href="http://code.djangoproject.com/ticket/8742" rel="nofollow">Django bug</a> suggests that <a href="http://pypi.python.org/pypi/python-fastcgi" rel="nofollow">python-fastcgi</a> will work for you, and its PyPI page reports that it works on Windows.</p>
