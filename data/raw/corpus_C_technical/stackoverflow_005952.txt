Question: <p>I know that python has a <code>len()</code> function that is used to determine the size of a string, but I was wondering why its not a method of the string object.</p>

<h2><strong>Update</strong></h2>

<p>Ok, I realized I was embarrassingly mistaken. <code>__len__()</code> is actually a method of a string object. It just seems weird to see object oriented code in Python using the len function on string objects. Furthermore, it's also weird to see <code>__len__</code> as the name instead of just len.</p>

Answer: <p>Jim's answer to <a href="http://stackoverflow.com/questions/83983/why-isnt-the-len-function-inherited-by-dictionaries-and-lists-in-python">this question</a> may help; I copy it here. Quoting Guido van Rossum:</p>
