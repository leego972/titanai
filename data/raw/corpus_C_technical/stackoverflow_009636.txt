Question: <p>I have an array of objects in Python </p>

<pre><code>[obj1, obj2, obj3]
</code></pre>

<p>and I want to pass them to off to a C++ function to perform some computation. I'm using SWIG to write my interface. The class type of the passed object is already defined in C++. </p>

<p>What's the best way to do this?</p>

Answer: <p>It depends on if your function is already written and cannot be changed, in which case you may need to check Swig docs to see if there is already a typemap from PyList to std::vector (I think there is).  If not, taking PyObject* as the argument to the function and using the Python C API for manipulating lists should work fine.  I haven't had any problems with it so far.  For self-documentation, I recommend typedef'ing PyObject* to some kind of expected type, like "PythonList" so that the parameters have some meaning.</p>
