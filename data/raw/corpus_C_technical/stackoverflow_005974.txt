Question: <p>I have a base class with a property which (the get method) I want to overwrite in the subclass. My first thought was something like:</p>

<pre><code>class Foo(object):
    def _get_age(self):
        return 11

    age = property(_get_age)


class Bar(Foo):
    def _get_age(self):
        return 44
</code></pre>

<p>This does not work (subclass bar.age returns 11). I found a solution with an lambda expression which works:</p>

<pre><code>age = property(lambda self: self._get_age())
</code></pre>

<p>So is this the right solution for using properties and overwrite them in a subclass, or are there other preferred ways to do this?</p>

Answer: <p>Another way to do it, without having to create any additional classes. I've added a set method to show what you do if you only override one of the two:</p>

<pre><code>class Foo(object):
    def _get_age(self):
        return 11

    def _set_age(self, age):
        self._age = age

    age = property(_get_age, _set_age)


class Bar(Foo):
    def _get_age(self):
        return 44

    age = property(_get_age, Foo._set_age)
</code></pre>

<p>This is a pretty contrived example, but you should get the idea.</p>
