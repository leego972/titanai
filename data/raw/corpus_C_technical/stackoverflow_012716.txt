Question: <p>I want to use the macports version of python instead of the one that comes with Leopard.</p>

Answer: <p>Don't. Apple ships various system utilities that rely on the system Python (and particularly the Python "framework" build); removing it will cause you problems.</p>

<p>Instead, modify your PATH environ variable in your <code>~/.bash_profile</code> to put <code>/opt/local/bin</code> first.</p>
