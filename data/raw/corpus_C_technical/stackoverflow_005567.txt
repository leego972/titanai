Answer: <p>I've been able to compile and run Enso by using /LD as a compiler flag.  This links dynamically to the MS Visual C++ runtime, and seems to allow you to get away without a manifest.</p>

<p>If you're using SCons, see the diff file here: <a href="http://paste2.org/p/69732" rel="nofollow">http://paste2.org/p/69732</a></p>
