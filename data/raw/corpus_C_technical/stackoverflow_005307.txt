Question: <p>I'm using the following view function to iterate over all items in the database (in order to find a tag), but I think the performance is very poor if the dataset is large.
Any other approach?</p>

<pre><code>def by_tag(tag):
return  '''
        function(doc) {
            if (doc.tags.length &gt; 0) {
                for (var tag in doc.tags) {
                    if (doc.tags[tag] == "%s") {
                        emit(doc.published, doc)
                    }
                }
            }
        };
        ''' % tag
</code></pre>

Answer: <p><em>Disclaimer: I didn't test this and don't know if it can perform better.</em>  </p>

<p>Create a single perm view:</p>

<pre><code>function(doc) {
  for (var tag in doc.tags) {
    emit([tag, doc.published], doc)
  }
};
</code></pre>

<p>And query with 
_view/your_view/all?startkey=['your_tag_here']&amp;endkey=['your_tag_here', {}]</p>

<p>Resulting JSON structure will be slightly different but you will still get the publish date sorting.</p>
