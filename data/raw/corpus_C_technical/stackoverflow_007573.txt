Question: <p>How do I convert a string to the variable name in <a href="http://en.wikipedia.org/wiki/Python_%28programming_language%29">Python</a>?</p>

<p>For example, if the program contains a object named <code>self.post</code> that contains a variable named, I want to do something like:</p>

<pre><code>somefunction("self.post.id") = |Value of self.post.id|
</code></pre>

Answer: <p>Also, there is the <strong><a href="https://docs.python.org/2/library/functions.html#globals" rel="nofollow">globals()</a></strong> function in <a href="http://en.wikipedia.org/wiki/Python_%28programming_language%29" rel="nofollow">Python</a> which returns a dictionary with all the defined variables. You could also use something like this:</p>

<pre><code>print globals()["myvar"]
</code></pre>
