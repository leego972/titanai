Question: <p>Is there any IDE (like VS) with drag and drop support for building python GUI, connecting to dbs etc?

Answer: <p>Also for PyGTK, there is <a href="http://gazpacho.sicem.biz/" rel="nofollow">Gazpacho</a>, it's pure python which makes adding your own custom widgets easier, and already has gtkbuilder support.</p>

<p>I took over maintenance of the project a few months ago, and we plan to release it under the umbrella of the <a href="http://pida.co.uk/" rel="nofollow">PIDA IDE</a>, in a more Visual Studio-like setup. Patches accepted!</p>
