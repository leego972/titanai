Question: <p>I am getting an 'access is denied' error when I attempt to delete a folder that is not empty. I used the following command in my attempt: <code>os.remove("/folder_name")</code>. </p>

<p>What is the most effective way of removing/deleting a folder/directory that is not empty?</p>

Answer: <p>Base on kkubasik's answer, check if folder exists before remove, more robust</p>

<pre><code>import shutil
def remove_folder(path):
    # check if folder exists
    if os.path.exists(path):
         # remove if exists
         shutil.rmtree(path)
remove_folder("/folder_name")
</code></pre>
