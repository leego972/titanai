Question: <p>So what I'm looking for here is something like <a href="http://us2.php.net/print_r">PHP's print_r</a> function. This is so I can debug my scripts by seeing what's the state of the object in question.</p>

Answer: <p>You want vars() mixed with pprint:</p>

<pre><code>from pprint import pprint
pprint (vars(your_object))
</code></pre>
