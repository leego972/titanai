Question: <p>So what I'm looking for here is something like <a href="http://us2.php.net/print_r">PHP's print_r</a> function. This is so I can debug my scripts by seeing what's the state of the object in question.</p>

Answer: <p>If you're using this for debugging, and you just want a recursive dump of everything, the accepted answer is unsatisfying because it requires that your classes have good <code>__str__</code> implementations already. If that's not the case, this works much better:</p>

<pre><code>import json
print(json.dumps(YOUR_OBJECT, 
                 default=lambda obj: vars(obj),
                 indent=1))
</code></pre>
