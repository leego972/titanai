Question: <p>For a list <code>["foo", "bar", "baz"]</code> and an item in the list <code>"bar"</code>, what's the cleanest way to get its index (1) in Python?</p>

Answer: <p><code>index()</code> returns the <strong>first</strong> index of value!</p>

<blockquote>
  <p>|  index(...)<br>
   |      L.index(value, [start, [stop]]) -> integer -- return first index of value</p>
</blockquote>

<pre><code>def all_indices(value, qlist):
    indices = []
    idx = -1
    while True:
        try:
            idx = qlist.index(value, idx+1)
            indices.append(idx)
        except ValueError:
            break
    return indices

all_indices("foo", ["foo","bar","baz","foo"])
</code></pre>
