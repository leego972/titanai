Question: <p>How can I delete the contents of a local folder in Python?</p>

<p>The current project is for Windows but I would like to see *nix also.</p>

Answer: <p>Expanding on mhawke's answer this is what I've implemented. It removes all the content of a folder but not the folder itself. Tested on Linux with files, folders and symbolic links, should work on Windows as well.</p>

<pre><code>import os
import shutil

for root, dirs, files in os.walk('/path/to/folder'):
    for f in files:
    	os.unlink(os.path.join(root, f))
    for d in dirs:
    	shutil.rmtree(os.path.join(root, d))
</code></pre>
