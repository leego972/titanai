Question: <p>I want to take a screenshot via a python script and unobtrusively save it.</p>

<p>I'm only interested in the Linux solution, and should support any X based environment.</p>

Answer: <p>Cross platform solution using <a href="http://wxpython.org">wxPython</a>:</p>

<pre><code>import wx
wx.App()  # Need to create an App instance before doing anything
screen = wx.ScreenDC()
size = screen.GetSize()
bmp = wx.EmptyBitmap(size[0], size[1])
mem = wx.MemoryDC(bmp)
mem.Blit(0, 0, size[0], size[1], screen, 0, 0)
del mem  # Release bitmap
bmp.SaveFile('screenshot.png', wx.BITMAP_TYPE_PNG)
</code></pre>
