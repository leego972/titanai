Question: <p>Is there any way to install setuptools for python 2.6 in Windows without having an .exe installer? </p>

<p>There isn't one built at the moment, and the maintainer of setuptools has stated that it's probable be a while before he'll get to it. </p>

<p>Does anyone know of a way to install it anyway?</p>

Answer: <p>The easiest setuptools installation option is to use the pre-packaged Windows Installer.</p>

<p>for <strong>32-bit</strong> Python on Windows, the official setuptools page has been updated and has windows installers for Python 2.6 and 2.7:</p>

<ul>
<li><a href="http://pypi.python.org/pypi/setuptools" rel="nofollow">http://pypi.python.org/pypi/setuptools</a></li>
</ul>

<p>for <strong>64-bit</strong> Python on Windows, setuptools Windows installers are available here:</p>

<ul>
<li><a href="http://www.lfd.uci.edu/~gohlke/pythonlibs/" rel="nofollow">http://www.lfd.uci.edu/~gohlke/pythonlibs/</a></li>
</ul>
