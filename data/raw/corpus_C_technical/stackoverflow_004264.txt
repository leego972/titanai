Question: <p>Has anyone ever heard of a UNIX shell written in a reasonable language, like Python?</p>

Answer: <p>From all appearances, Python IS a shell.  It runs with <code>#!</code> and it can run interactively.  Between the <code>os</code> and <code>shutil</code> packages you have all of the features of standard Unix shells.</p>

<p>Since you can do anything in Python with simple, powerful scripts, you don't really need to spend any time messing with the other shells.</p>
