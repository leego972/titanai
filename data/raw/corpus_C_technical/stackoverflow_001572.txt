Question: <p>I have a text file on my local machine that is generated by a daily Python script run in cron. </p>

<p>I would like to add a bit of code to have that file sent securely to my server over SSH.</p>

Answer: <p><a href="http://fabfile.org" rel="nofollow"><code>fabric</code></a> could be used to upload files vis ssh:</p>

<pre><code>#!/usr/bin/env python
from fabric.api import execute, put
from fabric.network import disconnect_all

if __name__=="__main__":
    import sys
    # specify hostname to connect to and the remote/local paths
    srcdir, remote_dirname, hostname = sys.argv[1:]
    try:
        s = execute(put, srcdir, remote_dirname, host=hostname)
        print(repr(s))
    finally:
        disconnect_all()
</code></pre>
