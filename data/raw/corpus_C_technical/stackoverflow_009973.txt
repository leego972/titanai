Question: <p>In Python, how can I parse a numeric string like <code>"545.2222"</code> to its corresponding float value, <code>542.2222</code>? Or parse the string <code>"31"</code> to an integer, <code>31</code>?</p>

<p>I just want to know how to parse a float string to a float, and (separately) an int string to an int.</p>

Answer: <p>Users <em>codelogic</em> and <em>harley</em> are correct, but keep in mind if you know the string is an integer (for example, 545) you can call int("545") without first casting to float.</p>

<p>If your strings are in a list, you could use the map function as well. </p>

<pre><code>&gt;&gt;&gt; x = ["545.0", "545.6", "999.2"]
&gt;&gt;&gt; map(float, x)
[545.0, 545.60000000000002, 999.20000000000005]
&gt;&gt;&gt;
</code></pre>

<p>It is only good if they're all the same type.</p>
