Question: <p>I have an XML file and an XML schema in another file and I'd like to validate that my XML file adheres to the schema.  How do I do this in Python?</p>

<p>I'd prefer something using the standard library, but I can install a third-party package if necessary.</p>

Answer: <p>lxml provides etree.DTD</p>

<p>from the tests on <a href="http://lxml.de/api/lxml.tests.test_dtd-pysrc.html" rel="nofollow">http://lxml.de/api/lxml.tests.test_dtd-pysrc.html</a></p>

<pre><code>...
root = etree.XML(_bytes("&lt;b/&gt;")) 
dtd = etree.DTD(BytesIO("&lt;!ELEMENT b EMPTY&gt;")) 
self.assert_(dtd.validate(root)) 
</code></pre>
