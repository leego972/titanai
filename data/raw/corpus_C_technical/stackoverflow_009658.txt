Question: <p>In python, is there a difference between calling <code>clear()</code> and assigning <code>{}</code> to a dictionary? If yes, what is it?
Example:<pre><code>d = {"stuff":"things"}
d.clear()   #this way
d = {}      #vs this way
</code></pre></p>

Answer: <p>As an illustration for the things already mentioned before:</p>

<pre><code>&gt;&gt;&gt; a = {1:2}
&gt;&gt;&gt; id(a)
3073677212L
&gt;&gt;&gt; a.clear()
&gt;&gt;&gt; id(a)

&gt;&gt;&gt; a = {}
