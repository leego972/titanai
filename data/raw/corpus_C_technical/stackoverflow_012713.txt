Question: <p>I want to use the macports version of python instead of the one that comes with Leopard.</p>

Answer: <p>I have both installed:</p>

<pre><code>$ which python
/usr/bin/python
$ which python2.5
/opt/local/bin/python2.5
</code></pre>

<p>I also added the following line to my <code>.profile</code>:</p>

<pre><code>export PATH=/opt/local/bin:/opt/local/sbin:$PATH
</code></pre>
