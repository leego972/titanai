Question: <p>Is there a way to send a file using POST from a Python script?</p>

Answer: <p>From <a href="http://docs.python-requests.org/en/latest/user/quickstart/#post-a-multipart-encoded-file">http://docs.python-requests.org/en/latest/user/quickstart/#post-a-multipart-encoded-file</a></p>

<p>Requests makes it very simple to upload Multipart-encoded files:</p>

<pre><code>&gt;&gt;&gt; r = requests.post('http://httpbin.org/post', files={'report.xls': open('report.xls', 'rb')})
</code></pre>

<p>That's it. I'm not joking - this is one line of code. File was sent. Let's check:</p>
