Answer: <p>Download the Python 2.6 Windows installer from <a href="http://python.org/" rel="nofollow">python.org</a> (<a href="http://python.org/ftp/python/2.6/python-2.6.msi" rel="nofollow">direct link</a>). <p>Most web development frameworks (Django, Turbogears, etc) come with a built-in webserver command that runs on the local computer without Apache.</p>
