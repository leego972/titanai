Question: <p>Should I start a Python program with:</p>

<pre><code>if__name__ == '__main__':
some code...
</code></pre>

<p>And if so, why? I saw it many times but don't have a clue about it.</p>

Answer: <p>If your program is usable as a library but you also have a main program (e.g. to test the library), that construct lets others import the file as a library and not run your main program. If your program is named foo.py and you do "import foo" from another python file, <code>__name__</code> evaluates to <code>'foo'</code>, but if you run "python foo.py" from the command line, <code>__name__</code> evaluates to <code>'__main__'</code>.</p>

<p>Note that you do need to insert a space between if and _, and indent the main program:</p>

<pre><code>if __name__ == '__main__':
    main program here
</code></pre>
