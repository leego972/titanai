Question: <p>I need to enable/disable completely network interfaces from a script in Windows XP. I'm looking for a python solution, but any general way (eg WMI, some command-line Ã  la netsh, some windows call) is welcome and will be adjusted. Thanks.</p>

Answer: <p>The <a href="http://support.microsoft.com/kb/311272" rel="nofollow">devcon</a> tool can control the NIC, but not the interface directly. It's a command-line version of the Device Manager applet.</p>

<pre><code>devcon disable (id or portion of name)
devcon enable (id or portion of name)
</code></pre>
