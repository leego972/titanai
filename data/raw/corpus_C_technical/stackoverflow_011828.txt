Question: <p>How do I check whether a file exists, without using the <a href="https://docs.python.org/3.6/reference/compound_stmts.html#try"><code>try</code></a> statement?</p>

Answer: <p>This sample function will test for a file's presence in a very Pythonic way using try .. except:</p>

<pre><code>def file_exists(filename):
    try:
        with open(filename) as f:
            return True
    except IOError:
        return False
</code></pre>
