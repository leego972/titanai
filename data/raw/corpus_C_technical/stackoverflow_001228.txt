Question: <p>I use Emacs primarily for coding Python but sometimes I use IDLE. Is there a way to change the key bindings easily in IDLE to match Emacs?</p>

Answer: <p><a href="http://www.python.org/doc/2.5/lib/module-readline.html" rel="nofollow">'readline' module</a> supposedly provides Emacs like key bindings and even functionality. However, it is not available on Windows but on Unix. Therefore, this might be a viable solution if you are not using Windows.</p>

<pre><code>import readline
</code></pre>
