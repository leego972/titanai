Question: <p>How do I check whether a file exists, without using the <a href="https://docs.python.org/3.6/reference/compound_stmts.html#try"><code>try</code></a> statement?</p>

Answer: <p>You could try this: (safer)</p>

<pre><code>try:
    # http://effbot.org/zone/python-with-statement.htm
    # with is more safe to open file
    with open('whatever.txt') as fh: 
        # do something with fh
except IOError as e:
    print("({})".format(e))
</code></pre>

<p>the ouput would be:</p>

<blockquote>
  <p>([Errno 2] No such file or directory:
  'whatever.txt')</p>
</blockquote>

<p>then, depending on the result, your program can just keep running from there or you can code to stop it if you want.</p>
