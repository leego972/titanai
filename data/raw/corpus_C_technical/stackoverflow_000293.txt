Question: <p>I have a list of 2-item tuples and I'd like to convert them to 2 lists where the first contains the first item in each tuple and the second list holds the second item.</p>

<p><strong>For example:</strong></p>

<pre><code>original = [('a', 1), ('b', 2), ('c', 3), ('d', 4)]
# and I want to become...
result = (['a', 'b', 'c', 'd'], [1, 2, 3, 4])
</code></pre>

<p>Is there a builtin function that does that?</p>

Answer: <p>It's only another way to do it but it helped me a lot so I write it here:</p>

<p>Having this data structure:</p>

<pre><code>X=[1,2,3,4]
Y=['a','b','c','d']
XY=zip(X,Y)
</code></pre>

<p>Resulting in:</p>

<pre><code>In: XY
Out: [(1, 'a'), (2, 'b'), (3, 'c'), (4, 'd')]
</code></pre>

<p>The more pythonic way to unzip it and go back to the original is this one in my opinion:</p>

<pre><code>x,y=zip(*XY)
</code></pre>

<p>But this return a tuple so if you need an array you can use:</p>

<pre><code>xy=(list(x),list(y))
</code></pre>
