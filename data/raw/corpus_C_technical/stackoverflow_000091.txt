Question: <p>What do I need to look at to see if I'm on Windows, Unix, etc?</p>

Answer: <p>If you not looking for the kernel version etc, but looking for the linux distribution you may want to use the following </p>

<p>in python2.6+ </p>

<pre><code>&gt;&gt;&gt; import platform
&gt;&gt;&gt; print platform.linux_distribution()
('CentOS Linux', '6.0', 'Final')
&gt;&gt;&gt; print platform.linux_distribution()[0]
CentOS Linux
&gt;&gt;&gt; print platform.linux_distribution()[1]
6.0
</code></pre>

<p>in python2.4</p>

<pre><code>&gt;&gt;&gt; import platform
&gt;&gt;&gt; print platform.dist()
('centos', '6.0', 'Final')
&gt;&gt;&gt; print platform.dist()[0]
centos
&gt;&gt;&gt; print platform.dist()[1]
6.0
</code></pre>

<p>Obviously, this will work only if you are running this on linux. If you want to have more generic script across platforms, you can mix this with code samples given in other answers.</p>
