Answer: <p>Python also has meta classes but that is more like a template class than a partial class.  A good example of meta class usage is the Django ORM.  All of your table models inherit from a base model class which also gets functionality included from a meta class.  It is a pretty cool concept that enables an active record like pattern (is it full active record?).</p>
