Answer: <p>There is a python debugger that is part of the core distribution of python called 'pdb'. I rarely use it myself, but find it useful sometimes.</p>

<p>Given this program:</p>

<pre><code>def foo():
    a = 0
    print "hi"

    a += 1

    print "bye"

foo()
</code></pre>

<p>Here is a session debugging it:</p>
