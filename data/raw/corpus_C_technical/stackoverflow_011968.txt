Question: <p>How can I call an external command (as if I'd typed it at the Unix shell or Windows command prompt) from within a Python script?</p>

Answer: <p>I quite like <a href="http://shell-command.readthedocs.org/en/latest/index.html" rel="nofollow">shell_command</a> for its simplicity.  It's built on top of the subprocess module.</p>
