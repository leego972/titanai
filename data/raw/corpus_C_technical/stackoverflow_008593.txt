Question: <p>How can I send a monitor into/out-of a different power state (like sleep)?</p>

Answer: <pre><code>import win32gui
import win32con

if argument == "on":
  win32gui.SendMessage(win32con.HWND_BROADCAST, win32con.WM_SYSCOMMAND,
                       win32con.SC_MONITORPOWER, -1)

if argument == "off":
  win32gui.SendMessage(win32con.HWND_BROADCAST, win32con.WM_SYSCOMMAND,
                       win32con.SC_MONITORPOWER, 2)

if argument == "sleep":
  win32gui.SendMessage(win32con.HWND_BROADCAST, win32con.WM_SYSCOMMAND,
                       win32con.SC_MONITORPOWER, 1)
</code></pre>
