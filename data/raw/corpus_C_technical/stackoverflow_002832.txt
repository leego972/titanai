Question: <p>What is the simplest way to determine the length (in seconds) of a given mp3 file, <strong>without using outside libraries</strong>? (python source highly appreciated)</p>

Answer: <p>You can use <a href="http://spacepants.org/src/pymad/">pymad</a>.  It's an external library, but don't fall for the Not Invented Here trap.  Any particular reason you don't want any external libraries?</p>

<pre><code>import mad

mf = mad.MadFile("foo.mp3")
track_length_in_milliseconds = mf.total_time()
</code></pre>

<p>Spotted <a href="http://simonwillison.net/2003/Dec/4/mp3lengths/">here</a>.</p>

<p>--</p>

<p>If you really don't want to use an external library, have a look <a href="http://ibofobi.dk/stuff/mp3/">here</a> and check out how he's done it.  Warning: it's complicated.</p>
