Question: <p>How do I check whether a file exists, without using the <a href="https://docs.python.org/3.6/reference/compound_stmts.html#try"><code>try</code></a> statement?</p>

Answer: <p>In 2016 the best way is still using <code>os.path.isfile</code></p>

<pre><code>&gt;&gt;&gt; os.path.isfile('/path/to/some/file.txt')
</code></pre>

<p>Or in <code>python3</code> you can use <code>pathlib</code></p>

<pre><code>import pathlib
path = pathlib.Path('/path/to/some/file.txt')
if path.is_file():
    ...
</code></pre>
