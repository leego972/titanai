Question: <p>Using <a href="http://numpy.scipy.org/" rel="nofollow">NumPy</a>, a matrix A has n rows and m columns, and I want add a guard ring to matrix A. That guard ring is all zero.</p>

<p>What should I do? Use Reshape? But the element is not enough to make a n+1 m+1 matrix.</p>

<p>Or etc.?</p>

<p>Thanks in advance</p>

I mean an extra ring of cells that always contain 0 surround matrix A.Basically there is a Matrix B has n+2rows m+2columns where the first row and columns and the last row and columns are all zero,and the rest of it are same as matrix A.

Answer: <p>Following up on your <a href="http://stackoverflow.com/questions/362489/how-do-i-add-a-guard-ring-to-a-matrix-in-numpy#362576">comment</a>:  </p>

<pre><code>&gt;&gt;&gt; import numpy
&gt;&gt;&gt; a = numpy.array(range(9)).reshape((3,3))
&gt;&gt;&gt; b = numpy.zeros(tuple(s+2 for s in a.shape), a.dtype)
&gt;&gt;&gt; b[tuple(slice(1,-1) for s in a.shape)] = a
&gt;&gt;&gt; b
array([[0, 0, 0, 0, 0],
       [0, 0, 1, 2, 0],
       [0, 3, 4, 5, 0],
       [0, 6, 7, 8, 0],
       [0, 0, 0, 0, 0]])
</code></pre>
