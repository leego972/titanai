Question: <p>I'm developing a website (in Django) that uses OpenID to authenticate users. As I'm currently only running on my local machine I can't authenticate using one of the OpenID providers on the web. So I figure I need to run a local OpenID server that simply lets me type in a username and then passes that back to my main app.</p>

<p>Does such an OpenID dev server exist? Is this the best way to go about it?</p>

Answer: <p>The libraries at <a href="http://openidenabled.com/" rel="nofollow">OpenID Enabled</a> ship with examples that are sufficient to run a local test provider.  Look in the examples/djopenid/ directory of the python-openid source distribution.  Running that will give you an instance of <a href="http://openidenabled.com/python-openid/trunk/examples/server/" rel="nofollow">this test provider</a>.</p>
