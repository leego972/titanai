Question: <p>How do I check whether a file exists, without using the <a href="https://docs.python.org/3.6/reference/compound_stmts.html#try"><code>try</code></a> statement?</p>

Answer: <p>This is the simplest way to check if a file exists. Just <strong>because</strong> the file existed when you checked doesn't <strong>guarantee</strong> that it will be there when you need to open it.</p>

<pre><code>import os
fname = "foo.txt"
if os.path.isfile(fname):
    print "file does exist at this time"
else:
    print "no such file"
</code></pre>
