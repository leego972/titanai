Question: <p>How can I find local IP addresses (i.e. 192.168.x.x or 10.0.x.x) in Python platform independently and using only the standard library?</p>

Answer: <p>On Linux:</p>

<pre><code>&gt;&gt;&gt; import socket, struct, fcntl
&gt;&gt;&gt; sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
&gt;&gt;&gt; sockfd = sock.fileno()
&gt;&gt;&gt; SIOCGIFADDR = 0x8915
&gt;&gt;&gt;
&gt;&gt;&gt; def get_ip(iface = 'eth0'):
...     ifreq = struct.pack('16sH14s', iface, socket.AF_INET, '\x00'*14)
...     try:
...         res = fcntl.ioctl(sockfd, SIOCGIFADDR, ifreq)
...     except:
...         return None
...     ip = struct.unpack('16sH2x4s8x', res)[2]
...     return socket.inet_ntoa(ip)
... 
&gt;&gt;&gt; get_ip('eth0')
'10.80.40.234'
&gt;&gt;&gt; 
</code></pre>
