Question: <p>I want to use the macports version of python instead of the one that comes with Leopard.</p>

Answer: <p>Use the <a href="http://www.macports.org/ports.php?by=name&amp;substr=python%5Fselect">python_select</a> port to switch python interpreters.</p>

<pre><code>sudo port install python25
sudo port install python_select
sudo python_select python25
</code></pre>

<p>This will symlink <code>/opt/local/bin/python</code> to the selected version. Then export <code>PATH</code> as described above.</p>
