Question: <p>Is it possible to use <a href="http://www.python.org/" rel="nofollow">CPython</a> to develop Adobe Flash based applications?</p>

Answer: <p>You can try <a href="http://www.libming.org/" rel="nofollow">ming</a>, a library for generating Macromedia Flash files (.swf).</p>

<p>It's written in C but it has wrappers that allow it to be used in C++, PHP, Python, Ruby, and Perl. </p>
