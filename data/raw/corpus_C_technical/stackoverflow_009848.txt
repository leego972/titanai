Question: <p>Assuming the file exists (using <code>os.path.exists(filename)</code> to first make sure that it does), how do I display the time a file was last modified?  This is on Linux if that makes any difference.</p>

Answer: <p><a href="http://docs.python.org/library/os.html#os.stat">os.stat()</a></p>

<pre><code>import os
filename = "/etc/fstab"
statbuf = os.stat(filename)
print "Modification time:",statbuf.st_mtime 
</code></pre>

<p>Linux does not record the creation time of a file (<a href="http://unix.stackexchange.com/q/24441/61642">for most fileystems</a>).</p>
