Question: <p>How do I check whether a file exists, without using the <a href="https://docs.python.org/3.6/reference/compound_stmts.html#try"><code>try</code></a> statement?</p>

Answer: <p>You have the <a href="https://docs.python.org/2/library/os.path.html#os.path.exists"><code>os.path.exists</code></a> function:</p>

<pre><code>import os.path
os.path.exists(file_path)
</code></pre>

<p>This returns <code>True</code> for both files and directories but you can additionally use <code>os.path.isfile</code> to test if it's a file specifically.</p>
