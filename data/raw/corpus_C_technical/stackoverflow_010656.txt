Question: <p>Because regular expressions scare me, I'm trying to find a way to remove all HTML tags and resolve HTML entities from a string in Python.</p>

Answer: <p>While I agree with Lucas that regular expressions are not all that scary, I still think that you should go with a specialized HTML parser. This is because the HTML standard is hairy enough (especially if you want to parse arbitrarily "HTML" pages taken off the Internet) that you would need to write a lot of code to handle the corner cases. It seems that <a href="http://docs.python.org/lib/module-htmllib.html" rel="nofollow">python includes one out of the box</a>. </p>

<p>You should also check out the <a href="http://utidylib.berlios.de/" rel="nofollow">python bindings for TidyLib</a> which can clean up broken HTML, making the success rate of any HTML parsing much higher.</p>
