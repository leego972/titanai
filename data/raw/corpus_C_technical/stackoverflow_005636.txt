Question: <p>I need to perform a filtered query from within a django template, to get a set of objects equivalent to python code within a view:</p>

<pre><code>queryset = Modelclass.objects.filter(somekey=foo)
</code></pre>

<p>In my template I would like to do</p>

<pre><code>{% for object in data.somekey_set.FILTER %}
</code></pre>

<p>but I just can't seem to find out how to write FILTER.</p>

Answer: <p>This can be solved with an assignment tag:</p>

<pre><code>from django import template

register = template.Library()

@register.assignment_tag
def query(qs, **kwargs):
    """ template tag which allows queryset filtering. Usage:
          {% query books author=author as mybooks %}
          {% for book in mybooks %}
            ...
          {% endfor %}
    """
    return qs.filter(**kwargs)
</code></pre>
