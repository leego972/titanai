Question: <p>What's the difference between the list methods <code>append()</code> and <code>extend()</code>?</p>

Answer: <p>The append() method adds a single item to the end of the list. </p>

<pre><code>x = [1, 2, 3]
x.append([4, 5])
x.append('abc')
print x
# gives you
[1, 2, 3, [4, 5], 'abc']
</code></pre>

<p>The extend() method takes one argument, a list, and appends each of the items of the argument to the original list. (Lists are implemented as classes. âCreatingâ a list is really instantiating a class. As such, a list has methods that operate on it.)</p>

<pre><code>x = [1, 2, 3]
x.extend([4, 5])
x.extend('abc')
print x
# gives you
[1, 2, 3, 4, 5, 'a', 'b', 'c']
</code></pre>
