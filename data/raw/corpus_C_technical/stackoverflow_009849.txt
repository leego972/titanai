Question: <p>Assuming the file exists (using <code>os.path.exists(filename)</code> to first make sure that it does), how do I display the time a file was last modified?  This is on Linux if that makes any difference.</p>

Answer: <pre><code>&gt;&gt;&gt; import os
&gt;&gt;&gt; f = os.path.getmtime('test1.jpg')
&gt;&gt;&gt; f
1223995325.0
</code></pre>
