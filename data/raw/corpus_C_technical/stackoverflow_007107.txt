Question: <p>How can I bind arguments to a Python method to store a nullary functor for later invocation?  Similar to C++'s <code>boost::bind</code>.</p>

Answer: <p>If <code>functools.partial</code> is not available then it can be easily emulated:</p>

<pre><code>&gt;&gt;&gt; make_printer = lambda s: lambda: sys.stdout.write("%s\n" % s)
&gt;&gt;&gt; import sys
&gt;&gt;&gt; print_hello = make_printer("hello")
&gt;&gt;&gt; print_hello()
hello
</code></pre>

<p>Or</p>

<pre><code>def partial(func, *args, **kwargs):
    def f(*args_rest, **kwargs_rest):
        kw = kwargs.copy()
        kw.update(kwargs_rest)
        return func(*(args + args_rest), **kw) 
    return f

def f(a, b):
    return a + b

p = partial(f, 1, 2)
print p() # -&gt; 3

p2 = partial(f, 1)
print p2(7) # -&gt; 8

d = dict(a=2, b=3)
p3 = partial(f, **d)
print p3(), p3(a=3), p3() # -&gt; 5 6 5
</code></pre>
