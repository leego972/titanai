Question: <p>Why is it bad to name a variable <code>id</code> in Python?</p>

Answer: <p>'id' is a built-in method in Python. Assigning a value to 'id' will overwrite the method. It is best to use either an identifier before as in "some_id" or use it in a different capitalization method.</p>

<p>The built in method takes a single parameter and returns an integer for the memory address of the object that you passed.</p>

<p><code>&gt;&gt;&gt;</code>id(1)</p>

<p>9787760</p>

<p><code>&gt;&gt;&gt;</code>x = 1</p>

<p><code>&gt;&gt;&gt;</code>id(x)</p>

<p>9787760</p>
