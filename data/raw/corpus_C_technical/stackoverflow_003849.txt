Question: <p>Is there a framework equivalent to Guice (<a href="http://code.google.com/p/google-guice">http://code.google.com/p/google-guice</a>) for Python?</p>

Answer: <p>I like this simple and neat framework.</p>

<p><a href="http://pypi.python.org/pypi/injector/">http://pypi.python.org/pypi/injector/</a></p>

<blockquote>
  <p>Dependency injection as a formal pattern is less useful in Python than
  in other languages, primarily due to its support for keyword
  arguments, the ease with which objects can be mocked, and its dynamic
  nature.</p>
  
  <p>That said, a framework for assisting in this process can remove a lot
  of boiler-plate from larger applications. That's where Injector can
  help. It automatically and transitively provides keyword arguments
  with their values. As an added benefit, Injector encourages nicely
  compartmentalized code through the use of Module s.</p>
  
  <p>While being inspired by Guice, it does not slavishly replicate its
  API. Providing a Pythonic API trumps faithfulness.</p>
</blockquote>
