Question: <p>I have two Django projects and applications running on the same Apache installation.  Both projects and both applications have the same name, for example myproject.myapplication.  They are each in separately named directories so it looks like .../dir1/myproject/myapplication and .../dir2/myproject/myapplication.   </p>

<p>Everything about the actual public facing applications works fine.  When I log into either of the admin sites it seems ok, but if I switch and do any work on the opposite admin site I get logged out of the first one.  In short I can't be logged into both admin sites at once.  Any help would be appreciated.</p>

Answer: <p>Set the <a href="http://docs.djangoproject.com/en/dev/topics/http/sessions/#session-cookie-domain">SESSION&#x5F;COOKIE&#x5F;DOMAIN</a> option.  You need to set the domain for each of your sites so the cookies don't override each other.</p>

<p>You can also use SESSION&#x5F;COOKIE&#x5F;NAME to make the cookie names different for each site.</p>
