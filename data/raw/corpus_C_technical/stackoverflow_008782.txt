Question: <p>Does python have the ability to create dynamic keywords?</p>

<p>For example:</p>

<pre><code>qset.filter(min_price__usd__range=(min_price, max_price))
</code></pre>

<p>I want to be able to change the <strong>usd</strong> part based on a selected currency.</p>

Answer: <p>Yes, It does. Use <code>**kwargs</code> in a function definition.</p>

<p>Example:</p>

<pre><code>def f(**kwargs):
    print kwargs.keys()


f(a=2, b="b")     # -&gt; ['a', 'b']
f(**{'d'+'e': 1}) # -&gt; ['de']
</code></pre>
