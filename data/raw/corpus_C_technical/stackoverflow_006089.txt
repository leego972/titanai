Question: <p>I would like to be able to drop to the python REPL from the debugger -- if this is not possible is there an easier way to evaluate python expressions in the context of the  current breakpoint other than manually adding them all as watch expressions?</p>

Answer: <p>There is a dedicated Pydev Console available by clicking on the "New console" dropdown in the console view.</p>

<p>See <a href="http://pydev.sourceforge.net/console.html">http://pydev.sourceforge.net/console.html</a></p>
