Question: <p>Is there a way to find the application name of the current active window at a given time on Mac OS X using Python?</p>

Answer: <p>The method in the accepted answer was deprecated in OS X 10.7+. The current recommended version would be the following:</p>

<pre><code>from AppKit import NSWorkspace
active_app_name = NSWorkspace.sharedWorkspace().frontmostApplication().localizedName()
print active_app_name
</code></pre>
