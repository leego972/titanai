Question: <p>Say I only needed to use findall() from the re module, is it more efficient to do:</p>

<pre><code>from re import findall
</code></pre>

<p>or </p>

<pre><code>import re
</code></pre>

<p>Is there actually any difference in speed/memory usage etc?</p>

Answer: <p>There is no difference on the import, however there is a small difference on access.</p>

<p>When you access the function as</p>

<pre><code>re.findall()
</code></pre>

<p>python will need to first find the module in the global scope and then find findall in modules dict.  May make a difference if you are calling it inside a loop thousands of times.</p>
