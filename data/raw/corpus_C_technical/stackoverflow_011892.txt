Question: <p>I'd like to search for a given MAC address on my network, all from within a Python script.  I already have a map of all the active IP addresses in the network but I cannot figure out how to glean the MAC address.  Any ideas?</p>

Answer: <p>Mark Pilgrim describes how to do this on Windows for the current machine with the Netbios module <a href="http://groups.google.com/group/comp.lang.python/msg/fd2e7437d72c1c21" rel="nofollow">here</a>.  You can get the Netbios module as part of the Win32 package available at python.org.  Unfortunately at the moment I cannot find the docs on the module.</p>
