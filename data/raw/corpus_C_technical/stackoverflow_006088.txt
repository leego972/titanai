Question: <p>I would like to be able to drop to the python REPL from the debugger -- if this is not possible is there an easier way to evaluate python expressions in the context of the  current breakpoint other than manually adding them all as watch expressions?</p>

Answer: <p>I don't use <em>pydev</em>, but to drop to python's interactive REPL from code:</p>

<pre><code>import code
code.interact(local=locals())
</code></pre>

<p>To drop to python's debugger from code:</p>

<pre><code>import pdb
pdb.set_trace()
</code></pre>

<p>Finally, to run a interactive REPL after running some code, you can use python's <code>-i</code> switch:</p>

<pre><code>python -i script.py
</code></pre>

<p>That will give you a python prompt after the code, even if it throws an exception.</p>

<p>You may be able to hook some of those solutions into <em>pydev</em>, I think.</p>
