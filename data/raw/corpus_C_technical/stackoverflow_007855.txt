Question: <p>For some reason I can't find a way to get the equivalents of sqlite's interactive shell commands:</p>

<pre><code>.tables
.dump
</code></pre>

<p>using the Python sqlite3 API. </p>

<p>Is there anything like that?</p>

Answer: <p>In Python:</p>

<pre><code>con = sqlite3.connect('database.db')
cursor = con.cursor()
cursor.execute("SELECT name FROM sqlite_master WHERE type='table';")
print(cursor.fetchall())
</code></pre>

<p>Watch out for my other <a href="http://stackoverflow.com/a/33100538/236830">answer</a>. There is a much faster way using pandas.</p>
