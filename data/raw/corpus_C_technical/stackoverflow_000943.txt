Question: <p>I have been using Python more and more, and I keep seeing the variable <code>__all__</code> set in different <code>__init__.py</code> files.  Can someone explain what this does?</p>

Answer: <p>It also changes what pydoc will show:</p>

<p>module1.py</p>

<pre><code>a = "A"
b = "B"
c = "C"
</code></pre>

<p>module2.py</p>

<pre><code>__all__ = ['a', 'b']

a = "A"
b = "B"
c = "C"
</code></pre>

<p>$ pydoc module1</p>

<pre>
Help on module module1:

<b>NAME</b>
    module1

<b>FILE</b>
    module1.py

<b>DATA</b>
    <b>a</b> = 'A'
    <b>b</b> = 'B'
    <b>c</b> = 'C'
</pre>

<p>$ pydoc module2</p>

<pre>
Help on module module2:

<b>NAME</b>
    module2

<b>FILE</b>
    module2.py

<b>DATA</b>
    <b>__all__</b> = ['a', 'b']
    <b>a</b> = 'A'
    <b>b</b> = 'B'
</pre>

<p>I declare <code>__all__</code> in all my modules, as well as underscore internal details, these really help when using things you've never used before in live interpreter sessions.</p>
