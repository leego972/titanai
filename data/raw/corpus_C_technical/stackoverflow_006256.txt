Question: <p>I want to detect whether module has changed. Now, using inotify is simple, you just need to know the directory you want to get notifications from.</p>

<p>How do I retrieve a module's path in python?</p>

Answer: <h2>Command Line Utility</h2>

<p>You can tweak it to a command line utility,</p>

<pre><code>python-which &lt;package name&gt;
</code></pre>

<p><a href="http://i.stack.imgur.com/pjVSO.png" rel="nofollow"><img src="http://i.stack.imgur.com/pjVSO.png" alt="enter image description here"></a></p>

<hr>

<p>Create <code>/usr/local/bin/python-which</code></p>

<pre><code>#!/usr/bin/env python

import importlib
import os
import sys

args = sys.argv[1:]
if len(args) &gt; 0:
    module = importlib.import_module(args[0])
    print os.path.dirname(module.__file__)
</code></pre>

<p>Make it executable </p>

<pre><code>sudo chmod +x /usr/local/bin/python-which
</code></pre>
