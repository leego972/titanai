Question: <p>How can I call an external command (as if I'd typed it at the Unix shell or Windows command prompt) from within a Python script?</p>

Answer: <p>os.system is OK, but kind of dated.  It's also not very secure.  Instead, try subprocess.  subprocess does not call sh directly and is therefore more secure than os.system.</p>

<p>Get more information at <a href="https://docs.python.org/library/subprocess.html" rel="nofollow">https://docs.python.org/library/subprocess.html</a></p>
