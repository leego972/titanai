Question: <p>Is there any difference between:</p>

<pre><code>if foo is None: pass
</code></pre>

<p>and</p>

<pre><code>if foo == None: pass
</code></pre>

<p>The convention that I've seen in most Python code (and the code I myself write) is the former, but I recently came across code which uses the latter.  None is an instance (and the only instance, IIRC) of NoneType, so it shouldn't matter, right?  Are there any circumstances in which it might?</p>

Answer: <p>The reason <code>foo is None</code> is the preferred way is that you might be handling an object that defines its own <code>__eq__</code>, and that defines the object to be equal to None. So, always use <code>foo is None</code> if you need to see if it is infact <code>None</code>.</p>
