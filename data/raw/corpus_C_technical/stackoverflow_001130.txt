Question: <p>Given a path such as <code>"mydir/myfile.txt"</code>, how do I find the absolute filepath relative to the current working directory in Python? E.g. on Windows, I might end up with:</p>

<pre><code>"C:/example/cwd/mydir/myfile.txt"
</code></pre>

Answer: <p>I prefer to use glob</p>

<p>here is how to list all file types in your current folder:</p>

<pre><code>import glob
for x in glob.glob():
    print(x)
</code></pre>

<p>here is how to list all (for example) .txt files in your current folder:</p>

<pre><code>import glob
for x in glob.glob('*.txt'):
    print(x)
</code></pre>

<p>here is how to list all file types in a chose directory:</p>

<pre><code>import glob
for x in glob.glob('C:/example/hi/hello/'):
    print(x)
</code></pre>
