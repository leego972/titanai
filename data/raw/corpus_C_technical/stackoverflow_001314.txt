Question: <p>Been scouring the net for something like firewatir but for python.  I'm trying to automate  firefox on linux.  Any suggestions?</p>

Answer: <p>I use <a href="http://selenium-rc.openqa.org/python.html" rel="nofollow">Selenium RC</a>. All my tests are written in Python and are run with test suite.</p>

<p>One minor thing is that You either have to start selenium manually and point Your tests to it or start selenium from test suite which requires little bit of coding. But it's doable.</p>

<p>Generally I'm very pleased with this solution.</p>
