Question: <p>I'm developing a website (in Django) that uses OpenID to authenticate users. As I'm currently only running on my local machine I can't authenticate using one of the OpenID providers on the web. So I figure I need to run a local OpenID server that simply lets me type in a username and then passes that back to my main app.</p>

<p>Does such an OpenID dev server exist? Is this the best way to go about it?</p>

Answer: <p>I have no problems testing with <a href="http://myopenid.com" rel="nofollow">myopenid.com</a>. I thought there would be a problem testing on my local machine but it just worked. (I'm using ASP.NET with DotNetOpenId library).</p>

<p>The 'realm' and return url must contain the port number like '<a href="http://localhost:93359" rel="nofollow">http://localhost:93359</a>'.</p>

<p>I assume it works OK because the provider does a client side redirect.</p>
