Question: <p>In ruby the library path is provided in $:, in perl it's in @INC - how do you get the list of paths that Python searches for modules when you do an import?</p>

Answer: <p>I think you're looking for <a href="https://docs.python.org/3/library/sys.html#sys.path">sys.path</a></p>

<pre><code>import sys
print (sys.path)
</code></pre>
