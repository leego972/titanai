Question: <p>Is there a way to access a list(or tuple, or other iterable)'s next, or previous element while looping through with for loop?</p>

<pre><code>l=[1,2,3]
for item in l:
    if item==2:
        get_previous(l,item)
</code></pre>

Answer: <p>The most simple way is to search the list for the item:</p>

<pre><code>def get_previous(l, item):
    idx = l.find(item)
    return None if idx == 0 else l[idx-1]
</code></pre>

<p>Of course, this only works if the list only contains unique items. The other solution is:</p>

<pre><code>for idx in range(len(l)):
    item = l[idx]
    if item == 2:
        l[idx-1]
</code></pre>
