Question: <p>I don't care what the differences are.  I just want to know whether the contents are different.</p>

Answer: <p>I would use a hash of the file's contents using MD5.</p>

<pre><code>import hashlib

def checksum(f):
    md5 = hashlib.md5()
    md5.update(open(f).read())
    return md5.hexdigest()

def is_contents_same(f1, f2):
    return checksum(f1) == checksum(f2)

if not is_contents_same('foo.txt', 'bar.txt'):
    print 'The contents are not the same!'
</code></pre>
