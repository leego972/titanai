Question: <p>How can I do remote debugging of a multi threaded Python application, running on an Embedded Linux based system, from Windows XP or Vista?</p>

<p>So far I have only come across <a href="http://pyscripter.googlepages.com/" rel="nofollow">PyScripter based remote debugging</a>. How does it perform?</p>

Answer: <p>I've never used it except a few quick trial runs, but <a href="http://winpdb.org/" rel="nofollow">winpdb</a> sounds like it does just what you want:</p>

<blockquote>
  <p>Winpdb is a platform independent GPL
  Python debugger with support for
  multiple threads, namespace
  modification, embedded debugging,
  encrypted communication and is up to
  20 times faster than pdb.</p>
</blockquote>
