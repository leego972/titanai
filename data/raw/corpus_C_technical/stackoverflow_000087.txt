Question: <p>What do I need to look at to see if I'm on Windows, Unix, etc?</p>

Answer: <p>/usr/bin/python3.2</p>

<pre><code>def cls():
    from subprocess import call
    from platform import system

    os = system()
    if os == 'Linux':
        call('clear', shell = True)
    elif os == 'Windows':
        call('cls', shell = True)
</code></pre>
