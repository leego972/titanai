Question: <p>I need a way to determine the space remaining on a disk volume using python on linux, Windows and OS X. I'm currently parsing the output of the various system calls (df, dir) to accomplish this - is there a better way?</p>

Answer: <p>Install <a href="http://pythonhosted.org/psutil/">psutil</a> using <code>pip install psutil</code>. Then you can get the amount of free space in bytes using:</p>

<pre class="lang-python prettyprint-override"><code>import psutil
print(psutil.disk_usage(".").free)
</code></pre>
