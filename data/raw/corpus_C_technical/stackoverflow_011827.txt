Question: <p>How do I check whether a file exists, without using the <a href="https://docs.python.org/3.6/reference/compound_stmts.html#try"><code>try</code></a> statement?</p>

Answer: <p>Use <a href="https://docs.python.org/3.3/library/os.path.html?highlight=os.path#os.path.isfile"><code>os.path.isfile()</code></a> with <a href="https://docs.python.org/3.3/library/os.html?highlight=os.access#os.access"><code>os.access()</code></a>:</p>

<pre><code>import os
import os.path

PATH='./file.txt'

if os.path.isfile(PATH) and os.access(PATH, os.R_OK):
    print "File exists and is readable"
else:
    print "Either file is missing or is not readable"
</code></pre>
