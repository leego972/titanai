Question: <p>How would a go about making a program where the user enters a string, and the program generates a list of words beginning with that string?</p>

<p>Ex:<br />
User: "abd"<br />
Program:abdicate, abdomen, abduct...</p>

<p>Thanks!</p>

<p><hr /></p>

<p>Edit:  I'm using python, but I assume that this is a fairly language-independent problem.</p>

Answer: <p>If you really want to be efficient - use suffix trees or suffix arrays - <a href="http://en.wikipedia.org/wiki/Suffix_tree" rel="nofollow">wikipedia article</a>.</p>

<p>Your problem is what suffix trees were designed to handle.
There is even implementation for Python - <a href="http://hkn.eecs.berkeley.edu/~dyoo/python/suffix_trees/" rel="nofollow">here</a></p>
