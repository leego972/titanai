Question: <p>I'm trying to store in a variable the name of the current file that I've opened from a folder...</p>

<p>How can I do that?
I've tried cwd = os.getcwd() but this only gives me the path of the folder, and I need to store the name of the opened file...</p>

<p>Can you please help me?</p>

<p>Thanks.</p>

Answer: <p>One more useful trick to add.  I agree with original correct answer, however if you're like me came to this page wanting the filename only without the rest of the path, this works well.</p>

<pre><code>&gt;&gt;&gt; f = open('/tmp/generic.png','r')
&gt;&gt;&gt; f.name
'/tmp/generic.png'
&gt;&gt;&gt; import os
&gt;&gt;&gt; os.path.basename(f.name)
'generic.png'
</code></pre>
