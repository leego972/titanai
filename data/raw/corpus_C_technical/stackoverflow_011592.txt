Question: <p>Using the Python Documentation I found the <a href="http://docs.python.org/lib/module-HTMLParser.html">HTML parser</a> but I have no idea which library to import to use it, how do I find this out (bearing in mind it doesn't say on the page).</p>

Answer: <p>You may be interested in <a href="http://codespeak.net/lxml/" rel="nofollow">lxml</a>. It is a separate package and has C components, but is the fastest. It has also very nice API, allowing you to easily list links in HTML documents, or list forms, sanitize HTML, and more. It also has capabilities to parse not well-formed HTML (it's configurable).</p>
