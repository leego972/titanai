Question: <p>I want to parse an Apache <strong>access.log</strong> file with a python program in a certain way, and though I am completely new to object-oriented programming, I want to start doing it now.</p>

<p>I am going to create a class <strong>ApacheAccessLog</strong>, and the only thing I can imagine now, it will be doing is '<strong>readline</strong>' method. Is it conventionally correct to inherit from the builtin <strong>file</strong> class in this case, so the class will behave just like an instance of the <strong>file</strong> class itself, or not? What is the best way of doing that?</p>

Answer: <p>Although it is in some cases useful to inherit from builtins, the real question here is what you want to do with the output and what's your big-picture design. I would usually write a reader (that uses a file object) and spit out whatever data class I need to hold the information I just read. It's then easy to design that data class to fit in with the rest of my design.</p>
