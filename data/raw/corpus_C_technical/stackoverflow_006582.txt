Question: <p>I have a file and I don't know how big it's going to be (it could be quite large, but the size will vary greatly).  I want to search the last 10 lines or so to see if any of them match a string.  I need to do this as quickly and efficiently as possible and was wondering if there's anything better than:</p>

<pre><code>s = "foo"
last_bit = fileObj.readlines()[-10:]
for line in last_bit:
    if line == s:
        print "FOUND"
</code></pre>

Answer: <p>I think reading the last 2 KB or so of the file should make sure you get 10 lines, and shouldn't be too much of a resource hog.</p>

<pre><code>file_handle = open("somefile")
file_size = file_handle.tell()
file_handle.seek(max(file_size - 2*1024, 0))

# this will get rid of trailing newlines, unlike readlines()
last_10 = file_handle.read().splitlines()[-10:]

assert len(last_10) == 10, "Only read %d lines" % len(last_10)
</code></pre>
