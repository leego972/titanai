Question: <p>Is it possible to read and write Word (2003 and 2007) files in Python without using a COM object?<br />
I know that I can:</p>

<pre><code>f = open('c:\file.doc', "w")
f.write(text)
f.close()
</code></pre>

<p>but Word will read it as an HTML file not a native .doc file.</p>

Answer: <p>See <a href="https://github.com/python-openxml/python-docx" rel="nofollow">python-docx</a>, its official documentation is available <a href="https://python-docx.readthedocs.org/en/latest/" rel="nofollow">here</a>. </p>

<p>This has worked very well for me.</p>
