Question: <p>I've got a list in a Python program that contains a series of numbers, which are themselves ASCII values.  How do I convert this into a "regular" string that I can echo to the screen?</p>

Answer: <p>Perhaps not as Pyhtonic a solution, but easier to read for noobs like me:</p>

<pre><code>charlist = [34, 38, 49, 67, 89, 45, 103, 105, 119, 125]
mystring = ""
for char in charlist:
    mystring = mystring + chr(char)
print mystring
</code></pre>
