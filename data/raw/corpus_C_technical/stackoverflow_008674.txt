Question: <p>I need to check whether a page is being redirected or not without actually downloading the content. I just need the final URL. What's the best way of doing this is Python?
Thanks!</p>

Answer: <p>If you specifically want to avoid downloading the content, you'll need to use the HEAD request method.  I believe the <code>urllib</code> and <code>urllib2</code> libraries do not support HEAD requests, so you'll have to use the lower-level <code>httplib</code> library:</p>

<pre><code>import httplib

h = httplib.HTTPConnection('www.example.com')
h.request('HEAD', '/')
response = h.getresponse()

// Check for 30x status code
if 300 &lt;= response.status &lt; 400:
    // It's a redirect
    location = response.getheader('Location')
</code></pre>
