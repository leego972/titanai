Question: <p>Is there any lib that convert very long numbers to string just copying the data?</p>

<p>These one-liners are too slow:</p>

<pre><code>def xlong(s):
    return sum([ord(c) &lt;&lt; e*8 for e,c in enumerate(s)])

def xstr(x):
    return chr(x&amp;255) + xstr(x &gt;&gt; 8) if x else ''

print xlong('abcd'*1024) % 666
print xstr(13**666)
</code></pre>

Answer: <p>If you need fast serialization use <a href="http://www.python.org/doc/2.5.2/lib/module-marshal.html" rel="nofollow">marshal</a> module. It's around 400x faster than your methods.</p>
