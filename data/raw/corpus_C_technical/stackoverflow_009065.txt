Question: <p>Is there a way to be <strong>sure</strong> that a page is coming from cache on a production server and on the development server as well?</p>

<p>The solution <strong>shouldn't</strong> involve caching middleware because not every project uses them. Though the solution itself might <strong>be</strong> a middleware.</p>

<p>Just checking if the data is stale is not a very safe testing method IMO.</p>

Answer: <p>The reason you use caches is to improve performance.  Test the performance by running a load test against your server.  If the server's performance matches your needs, then you are all set!</p>
