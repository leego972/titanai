Question: <p>Why won't this work?  I'm trying to make an instance of a class delete itself.</p>

<pre><code>&gt;&gt;&gt; class A():
    def kill(self):
    	del self


&gt;&gt;&gt; a = A()
&gt;&gt;&gt; a.kill()
&gt;&gt;&gt; a
&lt;__main__.A instance at 0x01F23170&gt;
</code></pre>

Answer: <p>You don't need to use del to delete instances in the first place.  Once the last reference to an object is gone, the object will be garbage collected.  Maybe you should tell us more about the full problem.</p>
