Question: <p>Does anyone know how to use the <a href="http://msdn.microsoft.com/en-us/library/ms645543(VS.85).aspx" rel="nofollow">Raw Input</a> facility on Windows from a WX Python application?</p>

<p>What I need to do is be able to differentiate the input from multiple keyboards. So if there is another way to achieving that, that would work too.</p>

Answer: <p>Have you tried using ctypes?</p>

<pre><code>&gt;&gt;&gt; import ctypes
&gt;&gt;&gt; ctypes.windll.user32.RegisterRawInputDevices
&lt;_FuncPtr object at 0x01FCFDC8&gt;
</code></pre>

<p>It would be a little work setting up the Python version of the necessary structures, but you may be able to query the Win32 API directly this way without going through wxPython.</p>
