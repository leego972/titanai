Question: <p>How do I limit <code>os.walk</code> to only return files in the directory I provide it?</p>

<pre><code>def _dir_list(self, dir_name, whitelist):
    outputList = []
    for root, dirs, files in os.walk(dir_name):
        for f in files:
            if os.path.splitext(f)[1] in whitelist:
                outputList.append(os.path.join(root, f))
            else:
                self._email_to_("ignore")
    return outputList
</code></pre>

Answer: <p>There is a catch when using listdir.  The os.path.isdir(identifier) must be an absolute path.  To pick subdirectories you do:</p>

<pre><code>for dirname in os.listdir(rootdir):
  if os.path.isdir(os.path.join(rootdir, dirname)):
     print("I got a subdirectory: %s" % dirname)
</code></pre>
