Question: <p>How do I make icons for my exe file when compiling my Python program?</p>

Answer: <p>I have no experience with py2exe but a quick <a href="http://www.google.com/search?q=py2exe+embed+icon" rel="nofollow">google search</a> found <a href="http://www.py2exe.org/index.cgi/CustomIcons" rel="nofollow">this</a>, if <em>embedding</em> icons in exe files was what you asked for.  </p>

<p>If you want to <em>create</em> .ico files, I'd really suggest you search for a icon designer or finished icons. Sure you <em>can</em> create a Win 3.x style icon fairly easy by creating a 16x16, 32x32, or 64x64 px image in paint, and rename it to .ico. But to create modern multi resolution icons for windows is a lot more complicated.</p>
