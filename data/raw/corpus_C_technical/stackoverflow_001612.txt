Question: <p>I want to take a screenshot via a python script and unobtrusively save it.</p>

<p>I'm only interested in the Linux solution, and should support any X based environment.</p>

Answer: <p>This one works on X11, and perhaps on Windows too (someone, please check). Needs <a href="http://www.riverbankcomputing.co.uk/software/pyqt/intro">PyQt4</a>:</p>

<pre><code>import sys
from PyQt4.QtGui import QPixmap, QApplication
app = QApplication(sys.argv)
QPixmap.grabWindow(QApplication.desktop().winId()).save('test.png', 'png')
</code></pre>
