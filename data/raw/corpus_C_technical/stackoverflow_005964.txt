Question: <p>Any python libs for parsing apache config files or if not python anyone aware of such thing in other languages (perl, php, java, c#)?
As i'll be able to rewrite them in python.</p>

Answer: <p>Red Hat's Emerging Technologies group has <A HREF="http://augeas.net/" rel="nofollow">Augeas</A> (written in C, but with Python bindings available), a generic system configuration tool with "lenses" for reading and writing several different configuration file formats. I would consider investigating the availability of a lens for Apache.</p>
