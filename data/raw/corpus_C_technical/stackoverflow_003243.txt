Question: <p>I have this Python application that gets stuck from time to time and I can't find out where.</p>

<p>Is there any way to signal Python interpreter to show you the exact code that's running? </p>

<p>Some kind of on-the-fly stacktrace?</p>

Answer: <p>In Python 3, pdb will automatically install a signal handler the first time you use c(ont(inue)) in the debugger. Pressing Control-C afterwards will drop you right back in there. In Python 2, here's a one-liner which should work even in relatively old versions (tested in 2.7 but I checked Python source back to 2.4 and it looked okay):</p>

<pre><code>import pdb, signal
signal.signal(signal.SIGINT, lambda sig, frame: pdb.Pdb().set_trace(frame))
</code></pre>

<p>pdb is worth learning if you spend any amount of time debugging Python. The interface is a bit obtuse but should be familiar to anyone who has used similar tools, such as gdb.</p>
