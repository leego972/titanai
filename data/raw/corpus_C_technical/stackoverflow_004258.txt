Question: <p>I seem to only be able to write to the Apache error log via stderr.  Anyone know of a more structured logging architecture that I could use from my python web project, like commons?</p>

Answer: <p>I concur with Blair Conrad's post about the Python logging module. The standard log handlers sometimes drop messages however. It's worth using the logging module's SocketHandler and building a receiver to listen for messages and write them to file.</p>
