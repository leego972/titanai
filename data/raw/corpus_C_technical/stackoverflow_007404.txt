Question: <p>How can I output colored text to the terminal, in Python?
What is the best Unicode symbol to represent a solid block?</p>

Answer: <p>Print a string that starts a color/style, then the string, then end the color/style change with <code>'\x1b[0m'</code>:</p>

<pre><code>print('\x1b[6;30;42m' + 'Success!' + '\x1b[0m')
</code></pre>

<p><a href="http://i.stack.imgur.com/RN3MN.png"><img src="http://i.stack.imgur.com/RN3MN.png" alt="Success with green background example"></a></p>

<p>Get a table of format options for shell text with following code:</p>

<pre><code>def print_format_table():
    """
    prints table of formatted text format options
    """
    for style in range(8):
        for fg in range(30,38):
            s1 = ''
            for bg in range(40,48):
                format = ';'.join([str(style), str(fg), str(bg)])
                s1 += '\x1b[%sm %s \x1b[0m' % (format, format)
            print(s1)
        print('\n')

print_format_table()
</code></pre>
