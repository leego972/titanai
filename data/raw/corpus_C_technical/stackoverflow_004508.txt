Question: <p>I've got a list in a Python program that contains a series of numbers, which are themselves ASCII values.  How do I convert this into a "regular" string that I can echo to the screen?</p>

Answer: <p>Same basic solution as others, but I personally prefer to use map instead of the list comprehension:</p>

<pre><code>
>>> L = [104, 101, 108, 108, 111, 44, 32, 119, 111, 114, 108, 100]
>>> ''.join(map(chr,L))
'hello, world'
</code></pre>
