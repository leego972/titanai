Question: <p>I want to generate a list in C#. I am missing python's list comprehensions. Is there a c# way to create collections on the fly like list comprehensions or generator statements do in python?</p>

Answer: <p>There's this:</p>

<pre class="lang-cs prettyprint-override"><code>new List&lt;FooBar&gt;{new Foo(), new Bar()}
</code></pre>

<p>which is only a little longer than its python equivalent:</p>

<pre class="lang-py prettyprint-override"><code>[Foo(), Bar()]
</code></pre>

<p>And then there is this:</p>

<pre class="lang-cs prettyprint-override"><code>public IEnumerable&lt;FooBar&gt; myFooBarGenerator() {
     yield return new Foo();
     yield return new Bar();
}
</code></pre>

<p>which is the python equivalent of:</p>

<pre class="lang-py prettyprint-override"><code>def myFooBarGenerator():
    yield Foo()
    yield Bar()
</code></pre>
