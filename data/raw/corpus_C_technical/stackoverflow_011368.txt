Question: <p>How do you set up IIS so that you can call python scripts from asp pages?</p>

<p>Ok, so I found the answer to that question here: <a href="http://support.microsoft.com/kb/276494" rel="nofollow">http://support.microsoft.com/kb/276494</a></p>

<p>So on to my next question: How do you call a cgi script from within classic asp (vb) code? Particularly one which is not in the web root directory.</p>

Answer: <p>I don't believe that VBScript as hosted by IIS has any way of executing an external process.  If you are using python as an AXscripting engine then you could just use the sys module.  If the script you're calling is actually meant to be a cgi script you'll have to mimic all the environment variables that the cgi uses.  The alternative is to put the script on the python path, import it and hope that it is modular enough that you can call the pieces you need and bypass the cgi handling code.</p>
