Question: <p>Is it possible to make it appear to a system that a key was pressed, for example I need to  make <kbd>A</kbd> key be pressed thousands of times, and it is much to time consuming to do it manually, I would like to write something to do it for me, and the only thing I know well enough is Python.</p>

<p>A better way to put it, I need to emulate a key press, I.E. not capture a key press.</p>

<p>More Info (as requested):
I am running windows XP and need to send the keys to another application.</p>

Answer: <p>Alternative way to set prefer window into foreground before send key press event.</p>

<pre><code>hwnd = win32gui.FindWindowEx(0,0,0, "App title")
win32gui.SetForegroundWindow(hwnd)
</code></pre>
