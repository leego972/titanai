Question: <p>Let's say I wanted to make a python script interface with a site like Twitter.</p>

<p>What would I use to do that? I'm used to using curl/wget from bash, but Python seems to be much nicer to use. What's the equivalent?</p>

<p>(This isn't Python run from a webserver, but run locally via the command line)</p>

Answer: <p>Python has a very nice httplib module as well as a url module which together will probably accomplish most of what you need (at least with regards to wget functionality).</p>
