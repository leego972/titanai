Question: <p>For example, if passed the following:</p>

<pre><code>a = []
</code></pre>

<p>How do I check to see if <code>a</code> is empty?</p>

Answer: <p>The preferred way to check if any list, dictionary, set, string or tuple is empty in Python is to simply use an if statement to check it.</p>

<pre><code>def is_empty(any_structure):
    if any_structure:
        print('Structure is not empty.')
        return False
    else:
        print('Structure is empty.')
        return True
</code></pre>
