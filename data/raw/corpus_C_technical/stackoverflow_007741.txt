Question: <p>I've got this date time string:</p>

<pre><code>post["date"] = "2007-07-18 10:03:19"
</code></pre>

<p>I'd like to extract just "2007-07-18" as a date. I've seen some reference to <code>strptime</code> but I'm not sure how to use it.  How can I extract the date from this string?</p>

Answer: <p>The other two answers are fine, but if you actually want the date for something else, you can use the <code>datetime</code> module:</p>

<pre><code>from datetime import datetime
d = datetime.strptime('2007-07-18 10:03:19', '%Y-%m-%d %H:%M:%S')
day_string = d.strftime('%Y-%m-%d')
</code></pre>

<p>It might be overkill for now, but it'll come in useful. You can see all of the format specifiers <a href="http://docs.python.org/library/time.html#time.strftime">here</a>.</p>
