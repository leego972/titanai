Answer: <p>I'm not familar with Python, so excuse my incorrect language If I'm saying this wrong... but open two sessions (in separate windows, or from separate Python processes - from separate boxes would work ... )  Then ... </p>

<p>. In Session A:</p>

<pre><code>   Begin Transaction 
      Insert TableA()  Values()...
</code></pre>

<p>. Then In Session B:</p>

<pre><code>Begin Transaction
  Insert TableB() Values()... 
  Insert TableA() Values() ...
</code></pre>

<p>. Then go back to session A</p>

<pre><code>  Insert TableB() Values () ...
</code></pre>

<p>You'll get a deadlock... </p>
