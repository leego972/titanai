Question: <p>I have a script that needs to do some stuff based on file creation &amp; modification dates but has to run on Linux &amp; Windows.</p>

<p>What's the best <strong>cross-platform</strong> way to get file creation &amp; modification date/times in Python?</p>

Answer: <p><code>os.stat</code> returns a named tuple with <code>st_mtime</code> and <code>st_ctime</code> attributes. The modification time is <code>st_mtime</code> on both platforms; unfortunately, on Windows, <code>ctime</code> means "creation time", whereas on POSIX it means "change time". I'm not aware of any way to get the creation time on POSIX platforms.</p>
