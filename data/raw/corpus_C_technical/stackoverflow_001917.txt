Question: <p>How do I check whether a file exists, without using the <a href="https://docs.python.org/3.6/reference/compound_stmts.html#try"><code>try</code></a> statement?</p>

Answer: <p>You can write Brian's suggestion without the <code>try:</code>.</p>

<pre><code>from contextlib import suppress

with suppress(IOError), open('filename'): 
    process()
</code></pre>

<p><code>supress</code> is part of Python 3.4. In older releases you can quickly write your own supress:</p>

<pre><code>from contextlib import contextmanager

@contextmanager
def suppress(*exceptions):
    try:
        yield
    except exceptions:
        pass
</code></pre>
