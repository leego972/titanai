Question: <p>What is the best way to do cross-platform handling of hidden files?
(preferably in Python, but other solutions still appreciated)</p>

<p>Simply checking for a leading '.' works for *nix/Mac, and file attributes work on Windows. However, this seems a little simplistic, and also doesn't account for alternative methods of hiding things (.hidden files, etc.). Is there a standard way to deal with this?</p>

Answer: <p>Incorporating my previous answer as well as that from @abarnert, I've released <a href="https://pypi.python.org/pypi/jaraco.path/1.1" rel="nofollow">jaraco.path 1.1</a> with cross-platform support for hidden file detection. With that package installed, to detect the hidden state of any file, simply invoke <code>is_hidden</code>:</p>

<pre><code>from jaraco import path
path.is_hidden(file)
</code></pre>
