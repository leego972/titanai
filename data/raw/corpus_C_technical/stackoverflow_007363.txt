Question: <p>Should I start a Python program with:</p>

<pre><code>if__name__ == '__main__':
some code...
</code></pre>

<p>And if so, why? I saw it many times but don't have a clue about it.</p>

Answer: <p>This is good practice. First, it clearly marks your module entry point (assuming you don't have any other executable code at toplevel - yuck). Second, it makes your module importable by other modules without executing, which some tools like code checkers, packagers etc. need to do.</p>
