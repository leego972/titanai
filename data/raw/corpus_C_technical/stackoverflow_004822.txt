Question: <p>So what I'm looking for here is something like <a href="http://us2.php.net/print_r">PHP's print_r</a> function. This is so I can debug my scripts by seeing what's the state of the object in question.</p>

Answer: <pre><code>def dump(obj):
  for attr in dir(obj):
    print "obj.%s = %s" % (attr, getattr(obj, attr))
</code></pre>

<p>There are many 3rd-party functions out there that add things like exception handling, national/special character printing, recursing into nested objects etc. according to their authors' preferences. But they all basically boil down to this.</p>
