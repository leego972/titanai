Question: <p>I've written code for communication between my phone and comp thru TCP sockets. When I type out the code line by line in the interactive console it works fine. However, when i try running the script directly through filebrowser.py it just wont work. I'm using Nokia N95. Is there anyway I can run this script directly without using filebrowser.py?
Am new to Python for mobile phones, so any suggestions would be appreciated.
Thanks</p>

Answer: <p>If the code is working in the interactive interpreter when typed, but not when run directly then I would suggest seeing if your code has reached a deadlock on the socket, for example both ends are waiting for data from the other.  When typing into the interactive interpreter there is a longer delay between the execution of each line on code.</p>
