Question: <p>How can I count the number of elements in an array, because contrary to logic array.count(string) does not count all the elements in the array, it just searches for the number of occurrences of string.</p>

Answer: <p>The method len() returns the number of elements in the list.</p>

<p>Syntax:</p>

<pre><code>len(myArray)
</code></pre>

<p>Eg:</p>

<pre><code>myArray = [1, 2, 3]
len(myArray)
</code></pre>

<p>Output:</p>

<pre><code>3
</code></pre>
