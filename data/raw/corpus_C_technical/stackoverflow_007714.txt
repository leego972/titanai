Question: <p>I have a unicode string like "TanÄ±m" which is encoded as "Tan%u0131m" somehow. How can i convert this encoded string back to original unicode. 
Apparently urllib.unquote does not support unicode.</p>

Answer: <p>This will do it if you absolutely have to have this (I really do agree with the cries of "non-standard"):</p>

<pre><code>from urllib import unquote

def unquote_u(source):
    result = unquote(source)
    if '%u' in result:
        result = result.replace('%u','\\u').decode('unicode_escape')
    return result

print unquote_u('Tan%u0131m')

&gt; TanÄ±m
</code></pre>
