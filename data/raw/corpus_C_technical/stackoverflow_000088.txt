Question: <p>What do I need to look at to see if I'm on Windows, Unix, etc?</p>

Answer: <p>For Jython the only way to get os name I found is to check <code>os.name</code> Java property (tried with <code>sys</code>, <code>os</code> and <code>platform</code> modules for Jython 2.5.3 on WinXP):</p>

<pre><code>def get_os_platform():
    """return platform name, but for Jython it uses os.name Java property"""
    ver = sys.platform.lower()
    if ver.startswith('java'):
        import java.lang
        ver = java.lang.System.getProperty("os.name").lower()
    print('platform: %s' % (ver))
    return ver
</code></pre>
