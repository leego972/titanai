Question: <p>How do I make icons for my exe file when compiling my Python program?</p>

Answer: <p>Linking the icons is answered in other answers. Creating the thing is as easy as using <a href="http://winterdrache.de/freeware/png2ico/" rel="nofollow">png2ico</a>. It creates an ico file from 1 or more png's and handles multiple sizes etc, like:</p>

<pre><code>png2ico myicon.ico logo16x16.png logo32x32.png
</code></pre>

<p>Will create myicon.ico with sizes 16x16 and 32x32. Sizes must be multiples of 8 squares, and no larger than 256x256.</p>
