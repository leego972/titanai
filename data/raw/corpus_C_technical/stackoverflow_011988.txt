Question: <p>How can I call an external command (as if I'd typed it at the Unix shell or Windows command prompt) from within a Python script?</p>

Answer: <p>import subprocess</p>

<pre><code>p = subprocess.Popen("df -h", shell=True, stdout=subprocess.PIPE, stderr=subprocess.PIPE).communicate()[0]
print p.split("\n")
</code></pre>
