Question: <p>How do I find the location of my site-packages directory?</p>

Answer: <p>Let's say you have installed the package 'django'. import it and type in dir(django). It will show you, all the functions and attributes with that module. Type in the python interpreter - </p>

<pre><code>&gt;&gt;&gt; import django
&gt;&gt;&gt; dir(django)
['VERSION', '__builtins__', '__doc__', '__file__', '__name__', '__package__', '__path__', 'get_version']
&gt;&gt;&gt; print django.__path__
['/Library/Python/2.6/site-packages/django']
</code></pre>

<p>You can do the same thing if you have installed mercurial.</p>

<p>This is for Snow Leopard. But I think it should work in general as well.</p>
