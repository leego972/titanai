Question: <p>If there will be a small number of files it should be easy with a recursive function to pass through all the files and add the size but what if there are lots of files, and by lots i really mean lots of files.</p>

Answer: <p>If you are on a posix system that provides du, you should be able to use <code>pexpect.run</code> or <code>subprocess</code> to execute <code>du &lt;path to folder&gt;</code> to get the size of the folder and subfiles.  Keep in mind it will output a string with each file listed and each folder totaled.  (Look at the du manpage to see what you can do to limit that).</p>
