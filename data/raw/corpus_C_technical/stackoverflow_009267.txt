Question: <p>I'm wondering where I find the source to show how the operator ** is implemented in Python.  Can someone point me in the right direction?  </p>

Answer: <p>There are two different implementations one for int (long in 3.0) objects and another one for float objects. </p>

<p>The float pow is the float_pow(PyObject *v, PyObject *w, PyObject *z) function defined in Objects/floatobject.c file of the Python source code. This functions calls pow() from C stdlib's math.h</p>

<p>The int pow has its own implementation, is the function int_pow(PyIntObject *v, PyIntObject *w, PyIntObject *z) defined in Objects/intobject.c (longobject.c for 3.0) of the Python source code.</p>
