Question: <p>I am looking to format a number like 188518982.18 to Â£188,518,982.18 using Python.</p>

<p>How can I do this?</p>

Answer: <p>See the <a href="https://docs.python.org/2/library/locale.html">locale</a> module.</p>

<p>This does currency (and date) formatting.</p>

<pre><code>&gt;&gt;&gt; import locale
&gt;&gt;&gt; locale.setlocale( locale.LC_ALL, '' )
'English_United States.1252'
&gt;&gt;&gt; locale.currency( 188518982.18 )
'$188518982.18'
&gt;&gt;&gt; locale.currency( 188518982.18, grouping=True )
'$188,518,982.18'
</code></pre>
