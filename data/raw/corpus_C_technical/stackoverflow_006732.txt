Question: <p>It seems like there should be a simpler way than:</p>

<pre><code>import string
s = "string. With. Punctuation?" # Sample string 
out = s.translate(string.maketrans("",""), string.punctuation)
</code></pre>

<p>Is there?</p>

Answer: <p>Do search and replace using the regex functions, as seen <a href="http://www.amk.ca/python/howto/regex/regex.html#SECTION000620000000000000000" rel="nofollow">here.</a>. If you have to repeatedly perform the operation, you can keep a compiled copy of the regex pattern (your punctuation) around, which will speed things up a bit.</p>
