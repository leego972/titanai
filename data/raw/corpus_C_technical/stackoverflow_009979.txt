Question: <p>In Python, how can I parse a numeric string like <code>"545.2222"</code> to its corresponding float value, <code>542.2222</code>? Or parse the string <code>"31"</code> to an integer, <code>31</code>?</p>

<p>I just want to know how to parse a float string to a float, and (separately) an int string to an int.</p>

Answer: <p>This is another method which deserves to be mentioned here, <a href="http://docs.python.org/library/ast.html#ast.literal_eval">ast.literal_eval</a>:</p>

<blockquote>
  <p>This can be used for safely evaluating strings containing Python expressions from untrusted sources without the need to parse the values oneself.</p>
</blockquote>

<p>That is, a safe 'eval'</p>

<pre><code>&gt;&gt;&gt; import ast
&gt;&gt;&gt; ast.literal_eval("545.2222")
545.2222
&gt;&gt;&gt; ast.literal_eval("31")
31
</code></pre>
