Question: <p>How do I read text from the (windows) clipboard from python?</p>

Answer: <p>I found out this was the easiest way to get access to the clipboard from python:</p>

<p>1) Install pyperclip:
<code>pip install pyperclip</code></p>

<p>2) Usage:</p>

<pre><code>import pyperclip

s = pyperclip.paste()
pyperclip.copy(s)

# the type of s is string
</code></pre>

<p>Tested on Win10 64-bit, Python 3.5. Seems to work with non-ASCII characters, too.
