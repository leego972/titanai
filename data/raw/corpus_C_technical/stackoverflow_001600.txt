Question: <p>Is it possible to have static class variables or methods in python? What syntax is required to do this?</p>

Answer: <p>You could also enforce a class to be static using metaclass.</p>

<pre><code>class StaticClassError(Exception):
    pass


class StaticClass:
    __metaclass__ = abc.ABCMeta

    def __new__(cls, *args, **kw):
        raise StaticClassError("%s is a static class and cannot be initiated."
                                % cls)

class MyClass(StaticClass):
    a = 1
    b = 3

    @staticmethod
    def add(x, y):
        return x+y
</code></pre>

<p>Then whenever by accident you try to initialize <strong>MyClass</strong> you'll get an StaticClassError.</p>
