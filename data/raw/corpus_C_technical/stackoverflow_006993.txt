Question: <p>What is the Python equivalent of Perl's <code>chomp</code> function, which removes the last character of a value?</p>

Answer: <p>Try the <a href="http://docs.python.org/2/library/stdtypes.html#str.rstrip">rstrip</a> method.</p>

<pre><code>&gt;&gt;&gt; 'test string\n'.rstrip()
'test string'
</code></pre>

<p>Note that Python's rstrip method strips <em>all</em> kinds of trailing whitespace by default, not just one newline as Perl does with chomp. To strip only newlines:</p>

<pre><code>&gt;&gt;&gt; 'test string \n\n'.rstrip('\n')
'test string '
</code></pre>

<p>There is also the <code>lstrip</code> and <code>strip</code> methods.</p>

<pre><code>&gt;&gt;&gt; s = " \n  abc   def   "
&gt;&gt;&gt; s.strip()
'abc   def'
&gt;&gt;&gt; s.rstrip()
' \n  abc   def'
&gt;&gt;&gt; s.lstrip()
'abc   def   '
&gt;&gt;&gt;
</code></pre>
