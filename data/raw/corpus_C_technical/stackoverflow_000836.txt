Question: <p>I am learning Python for a class now, and we just covered tuples as one of the data types. I read the Wikipedia page on it, but, I could not figure out where such a data type would be useful in practice. Can I have some examples, perhaps in Python, where an immutable set of numbers would be needed? How is this different from a list?</p>

Answer: <p>I like <a href="http://jtauber.com/blog/2006/04/15/python_tuples_are_not_just_constant_lists/">this explanation</a>.</p>

<p>Basically, you should use tuples when there's a constant structure (the 1st position always holds one type of value and the second another, and so forth), and lists should be used for lists of homogeneous values.</p>

<p>Of course there's always exceptions, but this is a good general guideline.</p>
