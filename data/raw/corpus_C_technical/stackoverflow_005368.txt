Question: <p>I have a django application that I'd like to add some rest interfaces to.  I've seen <a href="http://code.google.com/p/django-rest-interface/">http://code.google.com/p/django-rest-interface/</a> but it seems to be pretty simplistic.  For instance it doesn't seem to have a way of enforcing security.  How would I go about limiting what people can view and manipulate through the rest interface?  Normally I'd put this kind of logic in my views.  Is this the right place or should I be moving some more logic down into the model?  Alternatively is there a better library out there or do I need to roll my own?</p>

Answer: <p>I would look into using django-piston <a href="http://bitbucket.org/jespern/django-piston/wiki/Home">http://bitbucket.org/jespern/django-piston/wiki/Home</a> application if security is your main concern. </p>

<p>I have used django-rest-interface in the past, its reliable and though simple can be quite powerful, however django-piston seems more flexible going forward.</p>
