Question: <p>Is it possible to have static class variables or methods in python? What syntax is required to do this?</p>

Answer: <p>When define some member variable outside any member method, the variable can be either static or non-static depending on how the variable is expressed. </p>

<ul>
<li>CLASSNAME.var is static variable</li>
<li>INSTANCENAME.var is not static variable. </li>
<li>self.var inside class is not static variable. </li>
<li>var inside the class member function is not defined.</li>
</ul>

<p>For example:</p>

<pre><code>#!/usr/bin/python

class A:
    var=1

    def printvar(self):
        print "self.var is %d" % self.var
        print "A.var is %d" % A.var


    a = A()
    a.var = 2
    a.printvar()

    A.var = 3
    a.printvar()
</code></pre>

<p>The results are</p>

<pre><code>self.var is 2
A.var is 1
self.var is 2
A.var is 3
</code></pre>
