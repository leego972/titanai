Question: <p>Based on <a href="http://stackoverflow.com/questions/6209/split-a-string-ignoring-quoted-sections#6243">"Split a string by spaces in Python"</a>, which uses <em>shlex.split</em> to split a string with quotes smartly, I would be interested in hearing about other common tasks solved by non-obvious standard library functions.  </p>

<p>If this turns into <a href="http://www.doughellmann.com/projects/PyMOTW/" rel="nofollow">Module of The Week</a>, that's fine too.  </p>

Answer: <p>One function I've come to appreciate is string.translate.  Its very fast at what it does, and useful anywhere you want to alter or remove characters in a string. I've just used it in a seemingly inapplicable <a href="http://stackoverflow.com/questions/89909/in-python-how-to-i-verify-that-a-string-only-contains-letters-numbers-underscor#92000">problem</a> and found it beat all the other solutions handily.</p>

<p>The downside is that its API is a bit clunky, but this is improving in Py2.6 / Py3.0.</p>
