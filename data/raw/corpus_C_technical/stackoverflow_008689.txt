Question: <p>How do you change the size of figure drawn with matplotlib?</p>

Answer: <p>Please try a simple code as following:</p>

<pre><code>from matplotlib import pyplot as plt
plt.figure(figsize=(1,1))
x = [1,2,3]
plt.plot(x, x)
plt.show()
</code></pre>

<p>You need to set the figure size before you plot.</p>
