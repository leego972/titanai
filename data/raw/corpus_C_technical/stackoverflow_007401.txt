Question: <p>How can I output colored text to the terminal, in Python?
What is the best Unicode symbol to represent a solid block?</p>

Answer: <p>I have wrapped @joeld answer into a module with global functions that I can use anywhere in my code.</p>

<p>file: log.py     </p>

<pre><code>HEADER = '\033[95m'
OKBLUE = '\033[94m'
OKGREEN = '\033[92m'
WARNING = '\033[93m'
FAIL = '\033[91m'
ENDC = '\033[0m'
BOLD = "\033[1m"

def disable():
    HEADER = ''
    OKBLUE = ''
    OKGREEN = ''
    WARNING = ''
    FAIL = ''
    ENDC = ''

def infog( msg):
    print OKGREEN + msg + ENDC

def info( msg):
    print OKBLUE + msg + ENDC

def warn( msg):
    print WARNING + msg + ENDC

def err( msg):
    print FAIL + msg + ENDC
</code></pre>

<p>use as follows:</p>

<pre><code> import log
    log.info("Hello World")
    log.err("System Error")
</code></pre>
