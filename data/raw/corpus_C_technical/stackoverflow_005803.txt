Question: <p>How do I force Python's print function to output to the screen?</p>

Answer: <p>Loved Dan's solution! For python3 do:</p>

<pre><code>import io,sys
class flushfile:
    def __init__(self, f):
        self.f = f
    def write(self, x):
        self.f.write(x)
        self.f.flush()
sys.stdout = flushfile(sys.stdout)
</code></pre>
