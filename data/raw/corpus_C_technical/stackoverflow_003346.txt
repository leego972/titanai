Question: <p>In python, under what circumstances is SWIG a better choice than ctypes for calling entry points in shared libraries? Let's assume you don't already have the SWIG interface file(s). <br><br>What are the performance metrics of the two?</p>

Answer: <p>You can also use <a href="http://www.cosc.canterbury.ac.nz/greg.ewing/python/Pyrex/" rel="nofollow">Pyrex</a>, which can act as glue between high-level Python code and low-level C code. <a href="http://codespeak.net/lxml/" rel="nofollow">lxml</a> is written in Pyrex, for instance.</p>
