Question: <p>which would you recommend?
which is faster, reliable?
apache mod_python or nginx/lighttpd FastCGI?</p>

Answer: <p>I'm using it with nginx.  not sure if it's really faster, but certainly less RAM/CPU load.  Also it's easier to run several Django processes and have nginx map each URL prefix to a different socket.  still not taking full advantage of nginx's memcached module, but first tests show <em>huge</em> speed advantage.</p>
