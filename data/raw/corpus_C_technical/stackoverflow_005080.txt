Question: <p>Using the PHP <a href="http://www.php.net/pack" rel="nofollow">pack()</a> function, I have converted a string into a binary hex representation:</p>

<pre><code>$string = md5(time); // 32 character length
$packed = pack('H*', $string);
</code></pre>

<p>The H* formatting means "Hex string, high nibble first".</p>

<p>To unpack this in PHP, I would simply use the <a href="http://www.php.net/unpack" rel="nofollow">unpack()</a> function with the H* format flag.</p>

<p>How would I unpack this data in Python?</p>

Answer: <p>In Python you use the <a href="http://www.python.org/doc/2.5.2/lib/module-struct.html" rel="nofollow">struct</a> module for this.</p>

<pre><code>&gt;&gt;&gt; from struct import *
&gt;&gt;&gt; pack('hhl', 1, 2, 3)
'\x00\x01\x00\x02\x00\x00\x00\x03'
&gt;&gt;&gt; unpack('hhl', '\x00\x01\x00\x02\x00\x00\x00\x03')
(1, 2, 3)
&gt;&gt;&gt; calcsize('hhl')
8
</code></pre>

<p>HTH</p>
