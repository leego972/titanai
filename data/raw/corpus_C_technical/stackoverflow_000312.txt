Question: <p>What's the <strong>easiest, tersest, and most flexible</strong> method or library for parsing Python command line arguments?</p>

Answer: <p>I prefer <a href="http://click.pocoo.org/" rel="nofollow">Click</a>. It abstracts managing options and allows "(...) creating beautiful command line interfaces in a composable way with as little code as necessary".</p>

<p>Here's example usage:</p>

<pre><code>import click

@click.command()
@click.option('--count', default=1, help='Number of greetings.')
@click.option('--name', prompt='Your name',
              help='The person to greet.')
def hello(count, name):
    """Simple program that greets NAME for a total of COUNT times."""
    for x in range(count):
        click.echo('Hello %s!' % name)

if __name__ == '__main__':
    hello()
</code></pre>

<p>It also automatically generates nicely formatted help pages:</p>

<pre><code>$ python hello.py --help
Usage: hello.py [OPTIONS]

  Simple program that greets NAME for a total of COUNT times.

Options:
  --count INTEGER  Number of greetings.
  --name TEXT      The person to greet.
  --help           Show this message and exit.
</code></pre>
