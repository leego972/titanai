Question: <p>I tried to package a Twisted program with py2exe, but once I run the exe file I built, I got a "No module named resource" error. </p>

<p>And I found the py2exe said:</p>

<blockquote>
  <p>The following modules appear to be missing ['FCNTL', 'OpenSSL', 'email.Generator', 'email.Iterators', 'email.Utils', 'pkg_resources', 'pywintypes', 'resource', 'win32api', 'win32con', 'win32event', 'win32file', 'win32pipe', 'win32process', 'win32security']</p>
</blockquote>

<p>So how do I solve this problem?</p>

<p>Thanks.</p>

Answer: <p>I've seen this before... py2exe, for some reason, is not detecting that these modules are needed inside the ZIP archive and is leaving them out.</p>

<p>You can explicitly specify modules to include on the py2exe command line:</p>

<pre><code>python setup.py py2exe -p win32com -i twisted.web.resource
</code></pre>

<p>Something like that. Read up on the options and experiment.</p>
