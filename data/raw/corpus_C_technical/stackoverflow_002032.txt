Question: <p>If I have this string:</p>

<blockquote>
  <p>2+24*48/32</p>
</blockquote>

<p>what is the most efficient approach for creating this list:</p>

<blockquote>
  <p>['2', '+', '24', '*', '48', '/', '32']</p>
</blockquote>

Answer: <p>It just so happens that the tokens you want split are already Python tokens, so you can use the built-in <code>tokenize</code> module.  It's almost a one-liner:</p>

<pre><code>from cStringIO import StringIO
from tokenize import generate_tokens
STRING = 1
list(token[STRING] for token 
     in generate_tokens(StringIO('2+24*48/32').readline)
     if token[STRING])
['2', '+', '24', '*', '48', '/', '32']
</code></pre>
