Question: <p>How would one create an iterative function (or iterator object) in python?</p>

Answer: <p>I see some of you doing <code>return self</code> in <code>__iter__</code>. I just wanted to note that <code>__iter__</code> itself can be a generator (thus removing the need for <code>__next__</code> and raising <code>StopIteration</code> exceptions)</p>

<pre><code>class range:
  def __init__(self,a,b):
    self.a = a
    self.b = b
  def __iter__(self):
    i = self.a
    while i &lt; self.b:
      yield i
      i+=1
</code></pre>

<p>Of course here one might as well directly make a generator, but for more complex classes it can be useful.</p>
