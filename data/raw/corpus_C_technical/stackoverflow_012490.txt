Question: <p>How would a go about making a program where the user enters a string, and the program generates a list of words beginning with that string?</p>

<p>Ex:<br />
User: "abd"<br />
Program:abdicate, abdomen, abduct...</p>

<p>Thanks!</p>

<p><hr /></p>

<p>Edit:  I'm using python, but I assume that this is a fairly language-independent problem.</p>

Answer: <p>If your dictionary is really big, i'd suggest indexing with a python text index (PyLucene - note that i've never used the python extension for lucene)  The search would be efficient and you could even return a search 'score'.</p>

<p>Also, if your dictionary is relatively static you won't even have the overhead of re-indexing very often.</p>
