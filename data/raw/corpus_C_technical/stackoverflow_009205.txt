Answer: <p>The trick is in noticing which patterns emerge as you run the string through each iteration. Try evaluating <code>iterate(D,n)</code> for n between 1 and 10 and see if you can spot them. Also feed the string through a function that calculates the end position and the number of steps, and look for patterns there too.</p>

<p>You can then use this knowledge to simplify the algorithm to something that doesn't use these strings at all.</p>
