Question: <p>I've got this python dictionary "mydict", containing arrays, here's what it looks like :</p>

<pre><code>mydict = dict(
    one=['foo', 'bar', 'foobar', 'barfoo', 'example'], 
    two=['bar', 'example', 'foobar'], 
    three=['foo', 'example'])
</code></pre>

<p>i'd like to replace all the occurrences of "example" by "someotherword". </p>

<p>While I can already think of a few ways to do it, is there a most "pythonic" method to achieve this ?</p>

Answer: <p>Here's another take:</p>

<pre><code>for key, val in mydict.items():
    mydict[key] = ["someotherword" if x == "example" else x for x in val]
</code></pre>

<p>I've found that building lists is <strong>very</strong> fast, but of course profile if performance is important.</p>
