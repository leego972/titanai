Answer: <p>The standard python library is fairly well documented. Try jumping into python and importing a module say "os" and running:</p>

<pre><code>import os   
help(os)
</code></pre>

<p>This reads the doc strings on each of the items in the module and displays it. This is exactly what pydoc will do too.</p>
