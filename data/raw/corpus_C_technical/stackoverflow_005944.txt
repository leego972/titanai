Question: <p>I have a script that needs to do some stuff based on file creation &amp; modification dates but has to run on Linux &amp; Windows.</p>

<p>What's the best <strong>cross-platform</strong> way to get file creation &amp; modification date/times in Python?</p>

Answer: <p><code>os.stat</code> does include the creation time.  There's just no definition of st_anything for the element of <code>os.stat()</code> that contains the time.</p>

<p>So try this:</p>

<p><code>os.stat('feedparser.py')[8]</code></p>

<p>Compare that with your create date on the file in ls -lah</p>

<p>They should be the same.</p>
