Question: <p>Is there a framework equivalent to Guice (<a href="http://code.google.com/p/google-guice">http://code.google.com/p/google-guice</a>) for Python?</p>

Answer: <p>If you want a guice like (the new new like they say), I recently made something close in Python 3 that best suited my simple needs for a side project.</p>

<p>All you need is an <strong>@inject</strong> on a method (__init__ included of course).
The rest is done through annotations.</p>

<pre><code>from py3njection import inject
from some_package import ClassToInject

class Demo:
    @inject
    def __init__(self, object_to_use: ClassToInject):
        self.dependency = object_to_use

demo = Demo()
</code></pre>
