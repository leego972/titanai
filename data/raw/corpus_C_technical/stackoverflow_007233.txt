Answer: <p>Perhaps the problem is not with the firewall per se, but with the fact that you need to use an HTTP proxy. If you do need to use a proxy, try setting the http_proxy environment variable. It might be that your firewall uses NTLM proxy authentication (which Python doesn't support); in this case, try setting up an <a href="http://ntlmaps.sourceforge.net/" rel="nofollow">APS proxy server</a> on your local machine, and point http_proxy to localhost.</p>
