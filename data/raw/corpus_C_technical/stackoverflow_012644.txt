Question: <p>I'm searching a wsgi middleware which I can warp around a wsgi applications and which lets me monitor incoming and outgoing http requests and header fields.</p>

<p>Something like firefox live headers, but for the server side.</p>

Answer: <p>The mod_wsgi documentation provides various tips on debugging which are applicable to any WSGI hosting mechanism and not just mod_wsgi. See:</p>

<p><a href="http://code.google.com/p/modwsgi/wiki/DebuggingTechniques" rel="nofollow">http://code.google.com/p/modwsgi/wiki/DebuggingTechniques</a></p>

<p>This includes an example WSGI middleware that captures request and response.</p>
