--- ADVANCED HEURISTICS AND BIASES ---

AVAILABILITY CASCADE:
EXAMPLE 1: Shark attacks vs vending machines
- Media coverage: Shark attacks get massive coverage
- Public perception: Sharks are deadly threat
- Reality: Vending machines kill more people annually (13 vs 4)
- SOLUTION: Seek base rates, not just vivid examples

EXAMPLE 2: Plane crashes vs car accidents
- Availability: Plane crashes are dramatic, widely reported
- Fear: Many fear flying more than driving
- Statistics: Driving is 100x more dangerous per mile
- APPLICATION: Always check statistical base rates

CONFIRMATION BIAS DEEP DIVE:
CASE STUDY: Intelligence analysis Iraq WMDs
- Initial hypothesis: Iraq has WMDs
- Evidence filtering: Only accepted confirming intelligence
- Dissent suppression: Analysts pressured to conform
- Result: Catastrophic decision based on biased analysis
- LESSON: Actively seek disconfirming evidence

TECHNIQUE: Pre-mortem analysis
- Imagine project failed in future
- Work backward: What went wrong?
- Identify failure modes before they occur
- EXAMPLE: New product launch
  * Failure: Product flopped
  * Reasons: Wrong market, poor timing, bad pricing
  * Mitigation: Market research, soft launch, A/B testing

--- ADVANCED DEDUCTIVE REASONING ---

SYLLOGISMS AND LOGICAL FALLACIES:

VALID SYLLOGISM:
Premise 1: All humans are mortal
Premise 2: Socrates is human
Conclusion: Socrates is mortal

FORM: All A are B. C is A. Therefore C is B.

INVALID (Undistributed Middle):
Premise 1: All cats are mammals
Premise 2: All dogs are mammals
Conclusion: All cats are dogs (FALLACY)

REAL-WORLD APPLICATION - SECURITY:
Premise 1: All APTs use custom malware
Premise 2: This attack uses custom malware
Conclusion: This is an APT (FALLACY - undistributed middle)
CORRECT: Some custom malware users are APTs. This uses custom malware. Therefore this might be an APT (probability, not certainty)

FALLACY EXAMPLES IN MEDIA:
1. Ad hominem: "He's wrong because he's stupid"
   - Reality: Intelligence doesn't determine truth
   
2. Slippery slope: "If we ban assault rifles, next they'll ban all guns"
   - Reality: Each policy stands on own merits
   
3. False dichotomy: "You're either with us or against us"
   - Reality: Multiple positions exist
   
4. Post hoc: "After the ritual, it rained. The ritual worked!"
   - Reality: Correlation ≠ causation
   
5. Straw man: Misrepresenting opponent's argument
   - EXAMPLE: "They want to defund police" vs "reallocate resources"

--- ADVANCED INDUCTIVE REASONING ---

MILL'S METHODS:

METHOD OF AGREEMENT:
EXAMPLE: Food poisoning investigation
- Cases: 5 people sick
- Common factor: All ate at same restaurant
- Conclusion: Restaurant is source
- LIMITATION: Could be coincidence

METHOD OF DIFFERENCE:
EXAMPLE: Software bug isolation
- Working system: Version A
- Broken system: Version B
- Single change: Database driver updated
- Conclusion: Driver update caused bug

METHOD OF CONCOMITANT VARIATION:
EXAMPLE: Server performance
- Observation: CPU usage correlates with response time
- As CPU ↑ 10%, latency ↑ 15%
- Conclusion: CPU is bottleneck
- APPLICATION: Scale CPU to improve performance

JOINT METHOD (Agreement + Difference):
EXAMPLE: Cancer cluster investigation
- Agreement: All patients lived near factory
- Difference: Control group didn't live near factory
- Combined: Factory exposure likely cause
- CAUTION: Still need biological mechanism

--- ADVANCED GAME THEORY ---

NASH EQUILIBRIUM:

EXAMPLE 1: Prisoner's Dilemma
Two prisoners, choices: Cooperate or Defect
Payoff matrix:
- Both cooperate: 1 year each
- Both defect: 2 years each
- One defects, other cooperates: Defector goes free, cooperator gets 3 years

NASH EQUILIBRIUM: Both defect
- Neither can improve by unilaterally changing
- INDIVIDUALLY RATIONAL, COLLECTIVELY SUBOPTIMAL

REAL WORLD: Price wars
- Both companies could maintain high prices (cooperate)
- Incentive to undercut competitor (defect)
- Result: Race to bottom, both lose profit

SOLUTION: Repeated games, reputation, tit-for-tat strategy

EXAMPLE 2: Chicken game
Two drivers head toward each other
Choices: Swerve or Straight
- Both swerve: Tie, both "chicken"
- Both straight: Crash, both lose big
- One swerves, other straight: Swerver loses face, "wins"

APPLICATION: Nuclear brinkmanship, business negotiations
STRATEGY: Credible commitment to not swerve (remove steering wheel)

ZERO-SUM vs NON-ZERO-SUM:

ZERO-SUM: Poker
- One player's gain = another's loss
- Total constant
- Strategy: Maximize own gain, minimize opponent's

NON-ZERO-SUM: Trade
- Both parties can gain
- Value creation
- Win-win possible
- Strategy: Find mutually beneficial outcomes

NEGATIVE-SUM: War
- Both parties lose
- Destruction of value
- Avoid if possible

--- ADVANCED DECISION ANALYSIS ---

EXPECTED VALUE CALCULATION:

EXAMPLE: Startup investment decision
Option A: Safe investment (Bonds)
- Probability: 100%
- Return: 5%
- Expected value: 0.05

Option B: Risky startup
- Probability success: 20%
- Return if success: 1000% (10x)
- Return if failure: -100%
- Expected value: (0.2 × 10) + (0.8 × -1) = 2 - 0.8 = 1.2

DECISION: Startup has higher expected value (1.2 vs 0.05)
BUT: Risk tolerance matters, diversification, bankroll size

Stage 3: FDA approval ($20M, 1 year)
- Option to manufacture

EPISTEMOLOGY FOR ANALYSTS:

TYPES OF KNOWLEDGE:
1. A priori: True by definition (all bachelors are unmarried)
2. A posteriori: True by observation (sky is blue)

--- CELLULAR NETWORK EVOLUTION - TECHNICAL SPECIFICATIONS ---

1G ANALOG SYSTEMS:
AMPS (Advanced Mobile Phone System):
- Frequency: 824-849 MHz (up), 869-894 MHz (down)
- Channel spacing: 30 kHz
- Duplex: FDD (Frequency Division Duplex)
- Modulation: FM
- Capacity: 1 call per channel
- Handoff: Hard handoff (break before make)
- Security: None (scanners could eavesdrop)

TACS (Total Access Communication System):
- Frequency: 890-915 MHz (up), 935-960 MHz (down)
- Used in: UK, Europe, Asia
- Similar to AMPS technically

2G DIGITAL SYSTEMS:

GSM (Global System for Mobile Communications):
- Frequency bands:
  * GSM-900: 890-915 MHz (up), 935-960 MHz (down)
  * GSM-1800 (DCS): 1710-1785 MHz (up), 1805-1880 MHz (down)
  * GSM-1900 (PCS): 1850-1910 MHz (up), 1930-1990 MHz (down)
- Multiple access: TDMA + FDMA
- Time slots: 8 per carrier (200 kHz channels)
- Frame structure: 4.615 ms (8 time slots)
- Modulation: GMSK (Gaussian Minimum Shift Keying)
- Speech coding: RPE-LTP (Regular Pulse Excitation), 13 kbps
- Security: A5/1, A5/2 (compromised), A5/3 (KASUMI)

GPRS (General Packet Radio Service):
- "2.5G"
- Coding schemes: CS-1 to CS-4 (trade robustness for speed)
- Theoretical max: 171.2 kbps
- Latency: ~600ms

EDGE (Enhanced Data rates for GSM Evolution):
- "2.75G"
- Modulation: 8-PSK (Phase Shift Keying)
- Theoretical max: 384 kbps
- 3x faster than GPRS

CDMA (Code Division Multiple Access):
- IS-95 standard
- Multiple access: CDMA (spread spectrum)
- Chip rate: 1.2288 Mcps
- Soft handoff (make before break)
- Better capacity than GSM
- Security: More resistant to eavesdropping

3G UMTS/HSPA:

UMTS (Universal Mobile Telecommunications System):
- Frequency: 2100 MHz (core band), others added later
- Multiple access: CDMA (W-CDMA)
- Channel bandwidth: 5 MHz
- Chip rate: 3.84 Mcps
- Duplex: FDD and TDD variants
- Modulation: QPSK
- Voice codec: AMR (Adaptive Multi-Rate)

HSDPA (High Speed Downlink Packet Access):
- "3.5G"
- Peak rate: 14.4 Mbps
- 16-QAM modulation
- Fast scheduling: Every 2ms
- Hybrid ARQ

HSUPA (High Speed Uplink Packet Access):
- Peak rate: 5.76 Mbps
- Improved uplink

HSPA+ (Evolved HSPA):
- "3.9G"
- Peak rate: 42 Mbps (downlink), 11 Mbps (uplink)
- 64-QAM, MIMO, dual carrier

4G LTE ADVANCED:

LTE (Long Term Evolution):
- Frequency: Flexible (700 MHz to 2.6 GHz)
- Multiple access: OFDMA (downlink), SC-FDMA (uplink)
- Channel bandwidth: 1.4, 3, 5, 10, 15, 20 MHz
- Modulation: QPSK, 16-QAM, 64-QAM
- MIMO: Up to 4x4
- Peak rate: 150 Mbps (down), 50 Mbps (up) with 20MHz, 2x2 MIMO

LTE-Advanced:
- Carrier aggregation: Combine multiple carriers
- Peak rate: 1 Gbps (down), 500 Mbps (up)
- Enhanced MIMO: Up to 8x8
- HetNets: Heterogeneous networks (macro + small cells)
- eICIC: Enhanced Inter-Cell Interference Coordination

5G NR (NEW RADIO):

FR1 (Sub-6 GHz):
- Frequency: 450 MHz - 6 GHz
- Channel bandwidth: 5, 10, 15, 20, 25, 30, 40, 50, 60, 80, 100 MHz
- Modulation: Up to 256-QAM
- Subcarrier spacing: 15, 30, 60 kHz
- MIMO: Massive MIMO (64+ elements)

FR2 (mmWave):
- Frequency: 24.25 GHz - 52.6 GHz
- Channel bandwidth: 50, 100, 200, 400 MHz
- Modulation: Up to 64-QAM (higher SNR requirements)
- Subcarrier spacing: 60, 120 kHz

--- SS7/DIAMETER SECURITY DEEP DIVE ---

SS7 MESSAGE STRUCTURE:
MTP Level 2:
- Flag: 01111110 (start/end)
- SIF (Signaling Information Field):
  * Routing label: OPC (Origin Point Code), DPC (Destination Point Code), SLS
  * Signaling information
- CRC: Cyclic redundancy check

MTP Level 3:
- Service indicator: Which user (SCCP, ISUP, etc.)
- SIO (Service Information Octet)

SCCP (Signaling Connection Control Part):
- Global Title Translation: Map phone number to point code
- Subsystem numbers:
  * SSN 6: HLR
  * SSN 7: VLR
  * SSN 8: MSC
  * SSN 147: CAP

TCAP (Transaction Capabilities Application Part):
- Component portion: Invoke, Return Result, Return Error, Reject
- Transaction portion: Begin, Continue, End, Abort

MAP (Mobile Application Part):
- Operations:
  * updateLocation: Register with network
  * cancelLocation: Deregister
  * provideRoamingNumber: Get number for incoming call
  * insertSubscriberData: Update subscriber info
  * deleteSubscriberData: Remove subscriber info
  * sendAuthenticationInfo: Get authentication vectors
  * checkIMEI: Verify device
  * sendRoutingInfoForSM: Get SMS routing info
  * reportSM-DeliveryStatus: SMS delivery report

SS7 ATTACKS IN DETAIL:

1. LOCATION TRACKING:
Attack: sendRoutingInfoForSM (SRI-for-SM)
- Attacker sends SRI-for-SM with target MSISDN
- HLR returns IMSI and VLR address
- Attacker knows which VLR/VMSC serves target
- Precision: Cell tower level (hundreds of meters to km)

2. SMS INTERCEPTION:
Attack: updateLocation to rogue MSC
- Attacker sets up fake MSC with SS7 connectivity
- Sends updateLocation for target IMSI
- HLR updates location to attacker MSC
- All SMS to target routed to attacker
- Attacker forwards (or doesn't) to real destination

3. CALL REDIRECT:
Attack: provideRoamingNumber manipulation
- Attacker intercepts PRN request for target
- Returns fake roaming number
- Incoming calls routed to attacker
- Attacker bridges to real destination (man-in-the-middle)

4. DENIAL OF SERVICE:
Attack: Cancel location
- Attacker sends cancelLocation for target
- HLR removes location info
- Target cannot receive calls/SMS
