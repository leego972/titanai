That would be

\\pard(?:(?!\\intbl)[^ ])*[ ]

Explanation:

\\pard       # Match "\pard".
(?:          # Try to match...
(?!\\intbl) #  (unless we're at the start of the string "\intbl")
[^ ]        #  any character except space
)*           # ...any number of times.
[ ]          # Then match a space.

In your example file, this matches \pard\li-30\cf0\lang0\f0\fs24\par only.
