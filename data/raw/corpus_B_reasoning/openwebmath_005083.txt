a'd + bd + b'c + ab'd
= a'd + d(b+ab') + b'c
= a'd + d(a + b) + b'c
= a'd + ad + db + b'c
= d(a' + a) + db + b'c
= d + db + b'c
= d(1 + b) + b'c
= d + b'c
