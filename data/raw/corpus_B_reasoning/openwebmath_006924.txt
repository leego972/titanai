You'll need to specify your smtp server in the file

webwork2/conf/site.conf

There is a section on configuring the mail capabilities.

It should be pretty easy.

-- Mike
$mail{smtpSender}='mailserver.mail.com --login=myname --pass=mypasswod --port=11111' or, if I'm using nullmailer, something like $mail{smtpSender}=nullmailer
