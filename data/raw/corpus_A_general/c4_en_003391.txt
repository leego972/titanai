Function: The class for a character map in DynaPDF.
This class contains several duplicate fields because CMap files contain usually a DSC comment section which provides Postscript specific initialization code. With exception of DSCResName the strings in the DSC section should not differ from their CMap counterparts. The Identity mapping of a character collection should contain the DSC comment "%%BeginResource: CMap (Identity)". Otherwise the string should be set to the CMap name.
