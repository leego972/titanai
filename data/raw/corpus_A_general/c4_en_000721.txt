ATS PageSpeed is an open-source PageSpeed optimization plugin for the ATS proxy server.
Apache Traffic Server (ATS) is a fast, scalable and extensible HTTP caching proxy server. Formerly a commercial product, Yahoo! donated it to the Apache Foundation, and it is now an Apache TLP. Google PageSpeed tools analyze and optimize a website's performance following web best practices.
We-Amp created a open-source web server module which automatically applies the PageSpeed best practises to a website served by Apache Traffic Server.
More information available on www.atspagespeed.com.
