How to upgrade to version 8.1 from version 7.5 of NetIQ Security Solutions for iSeries?
Can the upgrade to version 8.0 be skipped if our system is on 7.5 and want to go to 8.1?
If you have not previously enrolled for a MYNetIQ account and received a password, complete the Technical Support Access Request and Contact Form: https://www.netiq.com/support/contacts.asp.
Select either the NetIQ Security Solutions for iSeries 8.1 Single file download or ISO image download and follow the additional instructions.
On the NetIQ Security Solutions for iSeries Upgrades web page, select either the NetIQ Security Agent for iSeries 8.0 Single file download or ISO image download and follow the additional instructions.
Follow the instructions in the Installation Guide to upgrade to NetIQ Security Solutions for iSeries v8.1. The Installation and User Guide files are located by default in C:\Program Files\NSSi81Setup\documentation.
