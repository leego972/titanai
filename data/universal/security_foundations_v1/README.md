# Titan Defensive Security Foundations v1

Status: in development — not for marketplace sale until validation and packaging complete.

## Goal
Create a broadly useful defensive-security SFT/evaluation dataset for secure software, cloud, identity, incident triage and resilience.

## Record design
Every record must include:
- scenario or evidence
- question/task
- best supported answer
- concise rationale
- defensive recommendation where appropriate
- difficulty: medium / hard / expert
- skill tags
- provenance class
- verification method
- safety classification

## Scope
Included:
- authentication and authorization
- secrets management
- phishing/social engineering recognition
- secure configuration
- vulnerability triage
- logging/monitoring
- incident analysis
- cloud security hygiene
- backups and recovery
- secure SDLC
- defensive network analysis

Excluded:
- instructions for malware, persistence or evasion
- credential theft
- exploit weaponisation
- destructive payloads
- phishing kit construction
- bypass instructions intended to defeat safeguards

## Initial quality target
First milestone: 300 manually reviewed seed records before any scale-up. The seed set will be used to test diversity, answer quality and validation logic before larger generation.
