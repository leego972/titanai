# Titan General Knowledge Core v1

Status: in development — not for marketplace sale until validation and packaging complete.

## Goal
Build a broad, internationally balanced general-knowledge dataset that improves factual grounding, explanation quality, context and practical literacy rather than trivia recall alone.

## Coverage
- world geography
- civics and institutions
- science fundamentals
- technology fundamentals
- economics fundamentals
- arts and culture
- environment and climate fundamentals
- major international organisations
- everyday quantitative literacy
- media and information literacy

## Quality standard
Every factual record must be traceable to a stable, reputable source class and include a verification method. The corpus should avoid culturally narrow overrepresentation, ambiguous trivia, ephemeral facts and unsupported claims.

The target mix is not pure recall. Records should include:
- direct factual grounding
- compare/contrast
- classification
- causal context
- misconception correction
- evidence-based explanation
- practical application

## Initial milestone
First milestone: 500 reviewed seed records distributed across all major subject areas. Scale-up occurs only after coverage, factual accuracy, difficulty balance and duplication tests pass.
