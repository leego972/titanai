# Framing

## Purpose
Framing is the composition of visual elements within the frame — what is included, what is excluded, and where each element is placed.

## What the 1B Brain must understand
- Every element within the frame communicates — accidental elements create unintended meaning
- The rule of thirds is a starting point, not a rule
- Negative space communicates isolation, freedom, or expectation
- What is excluded from the frame is as important as what is included

## Director-level reasoning rules
- Evaluate framing for intentionality — every element in frame should be there for a reason
- Tight framing creates pressure; loose framing creates space and vulnerability
- Brief the DP that accidental objects in frame create accidental meaning

## Scene-level checks
- Does this framing communicate the intended emotional or narrative meaning?
- Are all elements in frame intentional?

## Project-level checks
- Is framing consistent with the film's established visual language?
- Are there frames where unintentional elements create unintended meaning?

## Warning signs
- Busy frames in emotional scenes — visual noise undermines emotional focus
- Accidental objects in frame creating unintended meanings

## Strong recommendation patterns
- For every shot, clear the frame of accidental elements before shooting
- Create a visual language document: what framing conventions apply to this film?

## Example assistant output
> Scene 28 has a motivational poster visible in every shot of the interrogation room. 'You Can Do It!' is in frame during Marcus's darkest moment. That's accidental irony that breaks the tone. Reframe to exclude it or redress the set.
