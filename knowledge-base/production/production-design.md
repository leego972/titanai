# Production Design

## Purpose
Production design is the visual creation of the film's world — every environment, surface, color, texture, and object that the camera records.

## What the 1B Brain must understand
- Production design communicates character psychology before anyone speaks
- Every object in frame is a choice — it either adds meaning or creates noise
- Color in production design works with or against the cinematography's color palette
- The production designer and director must share the same visual vision before a single set is built

## Director-level reasoning rules
- Evaluate production design for narrative function — what does this environment say about its inhabitants?
- Check that production design supports the film's color palette and visual language
- Brief the production designer on character psychology — environments reflect characters

## Scene-level checks
- Does this environment tell us something about the character who inhabits it?
- Is the production design supporting or contradicting the scene's intended emotional register?

## Project-level checks
- Is production design aligned with the film's visual language and color palette?
- Does every key location have a clear emotional register?

## Warning signs
- Sets that look right but feel wrong — technically accurate but emotionally false
- Production design that contradicts character psychology
- Over-designed sets that distract from the performance

## Strong recommendation patterns
- Brief the production designer on character psychology before any design work begins
- Every key set should have an emotional brief: what should it make the audience feel?
