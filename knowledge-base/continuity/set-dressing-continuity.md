# Set Dressing Continuity

## Purpose
Set dressing continuity tracks the position, state, and presence of all environmental objects within a set across all setups.

## What the 1B Brain must understand
- Set dressing continuity applies to every visible object in the frame
- Actors interact with set dressing objects and disturb their positions — these changes must be tracked and reset
- Multi-day scenes have the highest set dressing continuity risk
- Photography is the primary tool for set dressing continuity

## Director-level reasoning rules
- Photograph all set dressing in detail before the first take of each scene
- Assign continuity responsibility for set dressing explicitly
- For multi-day scenes, store continuity photographs with the set

## Scene-level checks
- Is the set dressing in this setup in the same state as in the master and previous setups?
- Are continuity photographs taken for all set dressing before each scene begins?

## Project-level checks
- Is set dressing continuity systematically tracked with photographs?
- Are multi-day scenes' set dressing states documented and restored correctly?

## Warning signs
- No set dressing continuity photographs — restoration is from memory only
- Hero objects moved by actors and not reset between setups

## Strong recommendation patterns
- Create a set dressing continuity pack for every set — photographs from multiple angles
- Before shooting begins each day: verify set dressing against continuity pack

## Example assistant output
> Your main office set shoots over 4 days. Create a set dressing continuity pack today: photograph every surface, every desk arrangement, every visible shelf position, from the DP's planned angles. Laminate it and give it to the set decorator.
