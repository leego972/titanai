# AI Image Generation

## Purpose
AI image generation uses machine learning models to create still images from text prompts or reference inputs. In film production, it accelerates concept art, storyboarding, production design visualization, and pre-visualization.

## What the 1B Brain must understand
- AI image generation translates text prompts into visual output — the quality of output depends on the quality of the prompt
- Different models excel at different image types: photorealistic, cinematic, illustrated, stylized
- Consistency across multiple generated images requires consistent prompting, style references, and model selection
- AI image generation is a production design and concept visualization tool — not a replacement for photography
- Rights and ownership of AI-generated images vary by model and jurisdiction

## Director-level reasoning rules
- Evaluate AI image generation for specific production use cases
- Check that output consistency is achievable for the specific use case
- Understand the rights implications of each model used commercially

## Scene-level checks
- Is this AI-generated image serving a specific production use case?
- Is the prompting approach producing consistent enough output for the intended use?

## Project-level checks
- Is there a clear AI image generation workflow for each production use case?
- Are rights implications of commercial AI image use understood?

## Warning signs
- AI generated images used as final assets without understanding rights implications
- Inconsistent output that creates unreliable visual references for crew

## Strong recommendation patterns
- Develop a prompting guide for each production use case before beginning generation
- Test model consistency before committing to a model for a multi-image workflow

## Example assistant output
> For pre-visualization of your interior locations, use this prompting structure: [camera angle + lens description] + [lighting quality and direction] + [scene content] + [mood/atmosphere] + [technical film style reference]. Example: 'Eye-level medium shot, 50mm lens, single motivated window light from left, interrogation room, two figures in conversation, tense clinical atmosphere, cinematic still from a David Fincher film.'
