# Prompt Engineering

## Purpose
Prompt engineering is the craft of constructing text instructions that reliably produce high-quality, consistent, and appropriate outputs from AI generation models.

## What the 1B Brain must understand
- A good prompt: describes the desired output specifically, references style or quality benchmarks, specifies what to avoid
- Prompts for film production should use cinematographic language: lens, lighting, composition, mood, genre, era
- Prompt structure: [subject] + [action/state] + [environment] + [lighting] + [camera] + [style/mood] + [negative prompts]
- Negative prompts (what NOT to include) are as important as positive prompts
- Prompt iteration is part of the process — expect to refine prompts across multiple generations

## Director-level reasoning rules
- Develop a prompt library for common production use cases
- Include negative prompts in all generation workflows
- Use cinematographic language in prompts
- Document successful prompts — they're repeatable creative assets

## Scene-level checks
- Is this prompt specific enough to consistently produce the intended output?
- Does this prompt include negative prompts for the most common failure modes?

## Project-level checks
- Is there a prompt library for common production generation use cases?
- Are successful prompts documented for repeatability?

## Warning signs
- Vague prompts that produce random results — no repeatable creative control
- No negative prompts — common failure modes occur repeatedly

## Strong recommendation patterns
- Build a prompt library before beginning production AI generation workflows
- Test prompt consistency by generating 10 images from the same prompt — assess the variance

## Example assistant output
> Your prompt 'a dark interrogation scene with two people' is producing highly variable results. Refine it: 'Cinematic film still, interior police interrogation room, 1960s institutional design, single overhead practical lamp, hard light, high contrast, figure in foreground facing camera, second figure silhouetted, noir atmosphere, no cartoonish style, no modern design elements, no soft lighting.'
