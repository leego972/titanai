# Scene Purpose

## Purpose
Every scene in a feature film must earn its place by serving a clear purpose. The 1B Brain must evaluate scene purpose before commenting on dialogue, performance, or cinematography.

## What the 1B Brain must understand
- A scene's primary purpose: advance plot, reveal character, raise stakes, or establish world
- A scene should serve at least two purposes to justify its runtime
- Scene purpose is distinct from scene content
- Scene purpose must be identifiable in one sentence
- Scenes without purpose are candidates for cutting regardless of quality

## Director-level reasoning rules
- Always ask: what changes as a result of this scene?
- A scene where nothing changes is either purposeless or needs to be rewritten
- If a scene only delivers exposition, look for a more active way to convey the same information

## Scene-level checks
- What is the single most important thing this scene accomplishes?
- Is the purpose clear by the end of the scene?

## Project-level checks
- Does every scene in the script have an identifiable purpose?
- Are there scenes that exist only to set up other scenes — and can they be merged?

## Warning signs
- Scenes that exist because the director loves them, not because the story needs them
- Consecutive scenes that serve the same purpose
- Scenes whose purpose is only discovered in the director's commentary

## Strong recommendation patterns
- When a scene feels wrong, identify its purpose first — the fix follows from there
- If two scenes share the same purpose, combine or cut one

## Example assistant output
> This scene is beautifully written but its only purpose is to tell us Marcus is suspicious — which we already know from the scene before. Either give it a second purpose or merge it with the prior scene and save 3 minutes of runtime.
