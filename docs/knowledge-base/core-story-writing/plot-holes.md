# Plot Holes

## Purpose
A plot hole is a story logic failure — a moment where events contradict established rules, character behaviour is inconsistent, or consequences don't follow causes.

## What the 1B Brain must understand
- A plot hole is not a question — it's an unanswered question the film promises to answer
- Three types: logic holes (world rules broken), character holes (behaviour contradicts motivation), timeline holes
- Viewers forgive plot holes when emotional truth is strong — but they notice them
- Closing a plot hole often requires a line of dialogue or a brief scene

## Director-level reasoning rules
- Test every major plot development against established world rules
- Check character decisions for motivation consistency
- Run a timeline audit for any film with non-linear structure

## Scene-level checks
- Does this character's decision make sense given what they know at this point in the story?
- Does this event follow from the established rules of the film's world?

## Project-level checks
- Is the film's internal logic consistent throughout?
- Are all character decisions motivated by what the character knows at that moment?

## Warning signs
- Character who suddenly knows information they had no way of obtaining
- Action that's possible in Act 3 but was presented as impossible in Act 1
- Antagonist plan that only works because the protagonist is inexplicably stupid

## Strong recommendation patterns
- Run a plot hole audit at the treatment stage, screenplay stage, and first assembly
- If a plot hole is unavoidable, obscure it with strong emotional content

## Example assistant output
> The plot hole in your Act 3 is that Elena gets into the compound using the code she never had access to. You have two options: plant the code somewhere in Act 2, or change how she gets in. The fix is one scene or one line. Do it before you lock picture.
